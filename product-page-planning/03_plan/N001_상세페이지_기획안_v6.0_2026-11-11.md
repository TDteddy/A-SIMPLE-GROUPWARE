# N001 상세페이지 기획안 v6.0 — 바리에이션판 (2026-11-11)

> **작성 기준**: `01_guide/문제해결형_기획안_가이드.md` v1.3 (변주 엔진 Part V). 목표는 구매욕구를 끌어올리는 것이며, 미사여구는 자제하지 않았다[V0].
> **읽는 법**: 모든 카피 자리에 **3안**을 두었다. **A 선명**(자신감 있고 또렷), **B 강렬**(선언·속도·감정), **C 담백**(단정·여백)[V4]. 안마다 소구 각도[V2]를 괄호에 적었다. ★은 추천안이다. 세 안은 단어만 바꾼 변형이 아니라 각도가 다르다[V6].
> **지킨 것**[V0]: 하지 않은 시험의 결과·인증·측정 수치를 사실처럼 쓰지 않았다. 후기는 재구성 고지를 유지한다. 안전 보장·주행 중 조작 권유 없음.
> **구조**: 조립 스튜디오 표준 템플릿 14영역 순서. 이미지·스크린 설계·보류 레지스터·슬롯 실측은 v5.0과 같다(변동분만 적음). 제품: N001 맥세이프 차량용 거치대(다이얼 락 진공 압착 베이스 + 듀얼 힌지 암 + 마그네틱 링 헤드, 충전 없음).

## 4. 사람 검토 (광고주 선택 요청)
1. **세트 선택**: 1·2·3 중 하나 또는 섞어 쓰기 권장안. 영역별로 다른 안을 골라도 된다.
2. **`3초`, `1초 탈부착`, `처음이어도 30초`**: 체감형 표현이다. 측정값이 아님을 전제로 쓴다. `1초`·`30초`를 새로 쓸지 판단 필요.
3. **새 기능 이름 `프리 앵글`, `클린 리무브`**: 이름을 붙이면 기능이 특별해 보이지만 페이지 전체 용어표에 추가해야 한다.
4. **04 수치 3칸, 05 별점, 08 배지 `N001`**: v5.0의 H1·H2·H4와 같다.
5. **Q3·Q5 B안**: 약점(여름·충전 없음)을 조치와 장점으로 돌려 말한 안이다. 사실은 그대로 두었다.
