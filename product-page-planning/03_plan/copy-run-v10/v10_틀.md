제품: NORVEC N001. 다이얼로 조여 붙이는 흡착 베이스, 접히는 관절, 링형 자석 헤드로 된 맥세이프 호환 거치대. 충전 기능은 없다.

## 0. 이번 판의 기준

| 구분 | 무엇 | 어떻게 썼나 |
|---|---|---|
| 반드시 지킨 것 | **스튜디오 템플릿 규격** — 14영역, 칸 번호, 놓인 사진, 한 줄 용량 | 칸과 사진은 그대로 두고 문구만 썼다. 한 줄 용량은 실제 글꼴(Noto Sans KR)로 재서 맞췄다(제목 한 줄은 대부분 한글 9자 폭) |
| 영역별 소구 방향 | 주신 **14영역 레이아웃 규격**의 '무엇을 소구할까', 'N001 방향', '주의' | 작성자 세 명이 전문을 읽고 썼다 |
| 제품 사실 | 대시보드 **소싱 탭** | 없는 기능·수치·실적은 쓰지 않았다 |
| 재료 | **자료수집 탭** 16건과 연결 원자료(판매처 상세, 리뷰 299건) | 고객이 실제로 쓰는 말과 장면을 가져왔다 |
| 참고만 한 것 | 대시보드 문제해결형 가이드 | 금지 조항에 묶이지 않았다 |

- 쓰는 방식: 팔리는 페이지의 광고 문안. 제목은 얻는 것·장면·감각, 기능과 방법은 본문과 칩.
- 문장 규칙은 그대로다. 본문 합쇼체, `A가 아닙니다. B입니다`와 쉼표 대구 금지, 보장하는 말(`절대`, `어디든`, `안 떨어집니다`) 금지, 모호한 제목 금지.
- 세 작성자는 메인에서 서로 다른 매력을 앞세운다.

| 작성자 | 메인이 앞세우는 것 |
|---|---|
| 선명 | 보기 편한 자리 — 내비 화면이 내 눈높이, 내 쪽으로 |
| 강렬 | 붙는 순간 — 타자마자 대면 착 |
| 담백 | 단단한 고정 — 다이얼을 돌려 조이면 자리가 잡힌다 |
