## 1. 소비자 상황 [C1]

### 1-1 구매 전 행동·환경 표 [C1-1]
| 집단 | 지금 하는 방식 | 겪는 것(리뷰 표현) | 이 제품으로 바뀌는 동작 | 근거(리뷰 299건 키워드) |
|---|---|---|---|---|
| A 거치대 없음 | 조수석·무릎·도어 포켓에 두거나 손에 듦 | 손 닿는 곳의 휴대폰을 찾게 됨, 시선이 아래로 | 출발 전 한 번 붙여 두고 시야 안에서 봄 | 공공 안전 자료, "차에서 폰 놓고 찾느라" |
| B 송풍구 그립형 | 날개에 걸고 양옆 그립을 벌려 끼움 | "벌리기 번거로움", 날개 처짐 | 한 손으로 대면 붙음 | 그립 37 |
| C 송풍구 마그네틱 | 날개에 끼운 헤드에 부착 | 바람이 막히고 겨울엔 뜨거움, 높이·각도가 날개에 매임 | 송풍구를 비우고 원하는 높이·각도 | 송풍구 19 |
| D 부착형(접착) | 테이프로 붙이고 하루 대기 | 떨어짐, 떼면 흔적, 다시 못 붙임 | 다이얼로 그 자리에서 고정, 풀어서 옮김 | 위치 옮김 17 |
| E 같은 구조 실패 경험 | 가죽·패턴·곡면에 붙였다가 실패 | "대시보드엔 약해서", 여름 탈락 | 구매 전 설치면 확인, 보조패드 | 설치면 20·여름 4 |
- 비율은 리뷰 키워드 빈도이며 시장 대표값이 아니다. 열람 기기는 모바일 앱 전제.

### 1-2 이점 선정 [C1-2]
다수 집단(A·B·C)과의 차이 셋을 축으로 둔다: **끼우지 않고 댄다(B) / 송풍구를 비우고 원하는 높이·각도(C) / 출발 전에 붙여 두고 시야 안에서 본다(A)**. D·E에만 닿는 차이(당일 사용·재부착)는 비교표와 Q&A로 보낸다. '받은 날 설치' 같은 당연한 장점은 키 카피에 쓰지 않는다.

### 1-3 보편성 테스트 결과 [C1-3]
- 통과: 송풍구 바람 막힘, 그립 벌려 끼우기, 좌석 옆 휴대폰을 찾는 손, 여름 탈락.
- 제외: '컵홀더에 둔 휴대폰으로 길 안내'(리뷰 1건, 물리적으로 보이지 않음) → `손 닿는 곳`, `좌석 옆`으로.

### 1-4 명칭 [C1-4]
소싱명 `맥세이프 차량용 거치대` / 범주 명사 `맥세이프 거치대`(키 카피에 사용) / 판매용 고유명 미확정(Q8) / SKU 코드 N001은 소비자 화면 미노출(비교 카드 배지 제외 — §7 사람 검토).

### 1-5 근거 범위 [C1-5]

|---|---|---|

## 3. 영역별 기획 (게시 순서 = 표준 템플릿 14영역) [C7-1]

> 굵은 줄 = KEY, 그 아래 = 설명·서브, `[ ]` = 라벨. 글자 수 상한은 템플릿 슬롯 원문 실측값[C7-2]. 이미지 비율은 슬롯 실측값[C6-5].

### 00 브랜드 소개 (대시보드 12 · 고정) [S12]
- **구매 질문**: 이 브랜드가 지키는 기준은.
- **카피**: `A better everyday` / `매일 쓰는 물건에 취향을 더합니다.` / `매일 손이 가는 물건을 고르고,` `그중 그냥 만든 곳이 없는 것만 소개합니다.`
- **화면**: 템플릿 원본 이미지 유지. **확인**: 승인 공용 원고 대조.

### 01 정품 인증 (고정) [S01]
- **구매 질문**: 누구에게서 사는가.
- **카피**: `노르벡 (NORVEC) 공식판매처 정품입니다.` + 템플릿 저작권 고지 원문.
- **보류**: 교환·보증 조건(Q7)은 승인 전 미게시.

### 02 메인 키비주얼 [S02]
- **구매 질문**: 무엇을 먼저 보고 기억할 것인가.
- **훅 / 결과** [S02-1]: 훅 = 돌려서 고정하는 다이얼(사진에 보이고 송풍구형·부착형이 말할 수 없음). 결과 = 출발 전 3초면 고정되고, 휴대폰은 대면 붙음.
- **카피**
  - 아이브로 `NORVEC 맥세이프 차량용 거치대` (21자 이내)
  - **`3초 다이얼 고정`** / **`맥세이프 거치대`** (각 9·10자 이내)
  - `휴대폰은 대면 붙고,` `내릴 땐 들면 됩니다.`
  - 아이콘 라벨 `원터치 부착` · `다이얼 고정` · `각도 조절 · 폴딩`
- **점검** [S02-2]: 스왑 2중 통과(같은 구조 경쟁품은 '3초'를 쓸 수 있으나 훅+범주 조합은 대체 구조가 못 씀 — 같은 금형 상품의 한계로 감수) / 체감형 과장 `3초` 1개 / 장소·타 제품 명사 없음.
- **화면·이미지**: 9:16 한 장. 어두운 스튜디오 톤, **제품+휴대폰은 텍스트 끝과 아이콘 띠 사이**에만 둔다[C6-2]. 상단 45%는 빈 차콜 배경. 점유는 띠를 뺀 면적의 75%[C6-1]. 파일 `02_main_9x16`(재구도본).
- **옮긴 것**: 조건 라벨 `매끈하고 단단한 설치면 기준 · 무선충전 미지원`은 슬롯이 없어 제품정보·Q&A로[S02-5].
- **확인**: Q8.

### 03 타겟·사용 상황 [S03]
- **구매 질문**: 내게 언제 필요한가.
- **카피**
  - **`운전할 때 휴대폰은`** / **`어디에 두세요?`** (미사용자 포괄 질문[S03-2])
  - `송풍구 거치대` — 바람은 막히고 휴대폰은 뜨거워요
  - `그립형 거치대` — 탈 때마다 양손으로 벌려 끼워요
  - `거치대 없이` — 손 닿는 곳의 휴대폰을 찾게 돼요
  - `떨어진 거치대` — 여름에 떨어지거나 안 붙어요
- **점검**: 축 = 지금 쓰는 방식(행동표 C·B·A·D/E) / 미사용 집단 포함 / 카드 안에서 해결을 말하지 않음 / 서브는 해요체 한 줄(14~16자) / 2×2 격자라 제목 3~6자[S03-3].
- **화면·이미지**: 8:9 장면 사진 4장(카드당 1장). 한국 승용차 실내, 손만, 무지 타사 제품. '대상물+손' 묶음 60~70%.

### 04 위험소구 [S04]
- **구매 질문**: 준비하지 않으면 어떤 위험을 만나는가.
- **카피**
  - **`내려다보는 동안`** / **`앞차가 안 보입니다.`** (늘 참인 사실 문장[S04-1]. 원안 `앞차는 보이지 않습니다.`를 슬롯 13자에 맞춰 축약)
  - 수치 3칸: `2초` 시선이 도로를 떠나는 시간 / `28m` 시속 50km로 그사이 달리는 거리 / `15점` 운전 중 휴대전화 조작 벌점 · 범칙금 6만 원
  - 히어로 캡션 `휴대폰이 낮을수록` `고개는 더 내려갑니다` (제품이 바꾸는 변수 = 휴대폰의 높이[S04-2])
  - 패널 `좌석 옆 휴대폰을 찾는 손` / `여름에 떨어지는 거치대` / `휴대폰 자리는 출발 전에`
- **점검**: 빈도어·결과 단정 없음 / 제품의 사고 예방 효과 미언급 / 독자를 위험 운전자로 규정하지 않음 / 위험 쪽 과장 없음.
- **예외 표기** [S04-5, C7-1]: 템플릿의 수치 3칸 구조 때문에 수치와 법정 벌점을 04에 썼다. 가이드 원칙(법령 문구는 Q&A 한 번[C4-3])의 예외이므로 §7 사람 검토에 올린다. `28m`는 50km/h × 2초 산술값(13.9m/s × 2).
- **화면·이미지** [C6-4]: 전부 **사진**(선화 없음). 히어로 16:9 정차 중 운전석 시점(앞차 제동등, 좌석 옆 휴대폰, 중앙은 캡션 자리로 어둡게). 패널 21:9 ×3(손 뻗는 장면 / 들뜬 부착형 베이스 / 출발 전 거치대에 휴대폰을 올리는 손), 하단 1/3은 캡션 자리.
- **근거**: 시선 이탈·반응 지연에 관한 공공 안전 자료. **확인**: Q9.

### 05 구매 후기 [S05]
- **구매 질문**: 실제 사용·평가 자료는 무엇을 말하는가.
- **카피**
  - 아이브로 `REVIEW` / **`먼저 써 본 분들의`** / **`한마디`**
