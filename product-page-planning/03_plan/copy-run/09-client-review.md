# 광고주 리뷰 — 사실·규제 검수와 선택

검수 기준: 대시보드 기획안 가이드라인 Part A(영역 역할·경계, 시험 결과 미주장, 조건 병기, 주행 중 조작·주시 금지, 공통 기능의 독점 표현 금지), 상품마스터 사실, 가이드 D6 게이트(AI 티·swap). 법적 판단이 아니라 위험 표시다. 후보 밖의 줄은 고르지 않았고 줄을 고치지 않았다(자리 이동만 했다).

## 구조 변경 메모
플래너가 07을 "매일 뭐가 편해지는가"로 재정의했으므로 07의 배치를 바꾼다: **핵심 SP = 폰만 탈부착(놓는 법)**, SP01 = 손동작, SP02 = 설치(다이얼), SP03 = 각도. 접이 구조는 대시보드 `usage`대로 보관 기능이라 09 '보관할 때'에만 둔다(SP 4개 채우기 금지 [A3-07]).
