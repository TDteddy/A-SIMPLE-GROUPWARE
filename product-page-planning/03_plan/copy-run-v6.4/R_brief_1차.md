# v6.4 1차 자리별 검수 브리프

당신은 상세페이지 카피 검수자다. 후보는 작성자와 톤을 가린 채 섞여 있다. **다시 쓰지 않는다. 고르기만 한다.**

## 검수의 중심 둘
① 표현이 자연스러운가 ② 구매욕구를 불러일으키는가.
- 미사여구(수식어·감탄·은유·선언·체감형 과장)는 감점 사유가 아니다. 표현 수위, 형용사 개수, 글자 수, 느낌표는 채점하지 않는다.
- 합쇼체와 해요체의 차이도 채점하지 않는다(안마다 다를 수 있다). 한 안 안에서 두 체가 섞였을 때만 적는다.

## 순서
1. **탈락 스캔** — 아래만 탈락: 사실 목록에 없는 기능·시험 결과·인증·측정 수치를 사실로 쓴 것 / "절대 안 떨어진다" 같은 보장·사고 예방 보장 / 주행 중 조작 권유 / 타사 실명 비방 / 충전되는 것처럼 쓴 것 / 질병·건강 위험 암시, 죄책감 유도, 가짜 한정·마감 / 반려 문형("A가 아닙니다. B입니다" 꼴, 쉼표로 나눈 대구 "A는 B, C는 D").
2. **소리 내 읽기** — 한국어 화자가 실제로 쓰는 말인가. 번역체, 억지 명사형, 어색한 조사, 기계적 대구, "~을 제공합니다"류 홍보체를 거른다.
3. **구매욕구** — "사고 싶다 / 궁금하다 / 내 얘기다" 중 하나가 나오는가. 한 줄이 기억에 남는가.
4. 보조 질문(채점은 아님, 이유에 반영): 말이 되는가 / 공감이 되는가 / 읽는 사람이 그렇게 받아들일 수 있는가 / **제품명을 다른 거치대로 바꿔도 성립하는 문장은 아닌가**(설계·셀링포인트·비교 자리에서는 구조가 드러나야 한다).
5. 자리마다 **상위 3안**을 고르고 각각 구매욕구 0~5, 자연스러움 0~5를 매긴다. 세 안은 서로 각도가 달라야 한다(단어만 바꾼 변형이면 하나만).

## 리뷰가 묻는 것 (고를 때 참고)
거의 같은 구조의 제품 리뷰에서 가장 큰 불안은 "운전하다 떨어지지 않을까"이고, 다음이 "내 차 대시보드에도 붙을까 / 여름에 떨어지지 않을까 / 내 폰도 되나 / 광고만큼 될까"이다. 가장 큰 만족은 각도·눈높이, 착 붙는 느낌, 집게 없이 한 손, 차 밖 사용, 접어 두면 깔끔함, 옮겨 붙이기이다. 불안에 답하거나 만족을 키우는 안은 구매욕구 판단에 반영한다. 조건을 숨기지 않고 말한 안을 약하다고 보지 않는다.

## 제품 (사실 목록 — 여기 없는 기능·수치·인증은 만들지 않는다)
차량용 맥세이프 거치대. 브랜드 NORVEC. 충전 기능 없음(거치 전용).
- **압착 베이스 + 다이얼 락**: 매끈하고 단단한 평면(대시보드 평면, 앞유리, 책상 유리 등)에 손바닥으로 누르고 실버 다이얼을 TIGHT로 돌리면 고정된다. 접착제·테이프가 없다. 붙인 뒤 손을 떼고 흔들어 고정을 확인한다. OPEN으로 풀고 릴리즈 탭을 당기면 떼어지고, 다른 자리·다른 차에 다시 붙일 수 있다. 떼어 낸 자리에 접착 잔여물이 남지 않는다. 다시 붙일 때는 설치면과 압착면의 먼지·물기를 닦는다.
- **붙지 않는 면이 있다**: 굴곡이 있거나 요철·패턴이 깊은 면, 부드러운 가죽·천 면에는 잘 붙지 않는다. 그런 차는 평평한 자리나 유리를 찾는다.
- **더운 날**: 기온이 크게 오르면 압착이 느슨해질 수 있는 구조다. 다이얼을 다시 조이면 된다. 녹거나 굳는 접착제는 없다.
- **마그네틱 링 헤드**: 맥세이프 케이스(또는 동봉 메탈링을 붙인 케이스)를 가까이 대면 자석이 끌어당겨 붙고, 집어 들면 떨어진다. 한 손.
- **듀얼 힌지 암**: 위아래 높이·기울기 조절, 헤드를 돌려 가로·세로 전환. 송풍구가 아니라 대시보드 위라 자리가 자유롭다. 조정은 출발 전에 한다.
- **접이**: 접으면 손바닥 크기의 납작한 원반.

2. `{OUT}.json` — `{"M":[{"id":"M-07","buy":4,"nat":5,"why":"…"},{…},{…}], "T":[…], …}` 형식. 맡은 자리 전부, 자리당 정확히 3개, 1위부터.
