# v6.4 재작성 브리프 (2차 검수가 "재작성 필요"로 넘긴 다섯 자리)

먼저 `00_brief.md`(제품 사실·고정 문단·공통 지침·반려 문형)와 문장 은행 파일을 읽는다. 아래는 2차 검수가 고른 채택 조합의 주변 문장이다. 이 페이지에 끼워 넣을 줄을 쓴다. **종결은 해요체**로 통일한다. 자리마다 **5안**, 각도를 달리해서.

## 주변 문장 (바꾸지 않는다)
- 메인 제목: 돌려 조이면 끝! / 흔들어도 그 자리
- 메인 아이콘: 대면 착 부착 | 3초 다이얼 고정 | 눈높이 조절·접이
- 타겟 카드 넷째: 한여름 테이프 — 주차장 더위에 먼저 떨어졌어요
- 위험소구 제목: 봐야 할 화면이 / 봐야 할 길 아래에 있어요
- 위험소구 캡션: "잠시 후 우회전" / 어디서 도는지 보려면 고개를 숙여야 해요 | 조수석으로 뻗는 손 | (여기 한 줄) | 시동 걸고 내비 켜고 착. 이제 눈높이에 있어요
- 설계 제목: 자석이 잡고 힌지가 세우고 / 다이얼이 조여요
- SP01: 테이프 대신 / 공기를 빼요 — 설명에 "누르고, 돌리고, 흔들어 보면 3초 만에 답이 나와요"가 있다
- SP02 설명: 출발 전에 암을 세워 높이를 맞추고 헤드를 기울여요. / 화면이 앞유리 바로 아래, 시선이 멀리 가지 않는 자리에 서요.
- SP03 설명: 대시보드를 비워 두고 싶은 날엔 납작하게 접어 눕히세요. / 아예 치우고 싶은 날엔 다이얼을 풀면 돼요. 떼어 낸 자리는 깨끗해요.
- 비교 헤더: 녹을 접착이 없고 / 벌릴 집게가 없어요
- Q&A Q4 답: 붙이고 나서 잡고 흔들어 보세요, 그게 답이에요.

## 쓸 자리
| 코드 | 자리 | 무엇이 필요한가 |
|---|---|---|
| MS | 메인 보조문 2줄(줄당 10~16자) | `맥세이프 거치대`라는 말이 글자 그대로 들어간다. 대면 붙고 들면 뗀다는 원터치를 말하되 **"떨어지다"라는 단어를 쓰지 않는다**(쓱, 집어 들면 등). 가능하면 타는 순서(내비 켜고 착)나 떼는 장면(잠깐 내릴 때, 전화 올 때) 중 하나 |
| RC3 | 위험소구 작은 사진 캡션 한 줄(8~16자) | 여름에 떨어진 거치대가 **아닌** 다른 위험 장면 하나. 휴대폰이 낮은 곳·먼 곳에 있어서 생기는 일(컵홀더, 무릎, 도어 포켓, 신호 대기 중 찾기 등). 공포·비난 없이 |
| S2 | SP02 제목 1~2줄 | 힌지가 꺾인다는 구조와 **"내 눈높이"**가 한 제목 안에 있다. 다른 거치대 페이지에 붙지 않는 줄 |
| S2X | SP02 설명에 덧붙일 한 줄(14~24자) | 헤드를 돌려 세로↔가로 전환, 또는 조수석 사람 쪽으로 돌려 주는 장면. 주행 중 조정으로 읽히면 안 된다 |
| S3 | SP03 제목 1~2줄 | **접어 두면 대시보드가 깔끔해진다**는 것을 받는다. 쉼표 대구와 "A가 아닙니다. B입니다" 금지. 옮겨 붙이기까지 함께 받아도 되고 접이만 받아도 된다 |
| DP3 | 설계 부품 중 베이스 한 줄: 라벨(3~8자) — 설명(12~22자) | "흔들어 보세요"라는 권유 없이(페이지에 이미 두 번 있다) 붙은 뒤의 믿음이나 구조를 말한다. "테이프"라는 단어도 피한다(바로 아래 SP01 제목에 있다) |
