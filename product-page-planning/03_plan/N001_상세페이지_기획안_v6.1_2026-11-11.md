# N001 상세페이지 기획안 v6.1 — 작성·검수 에이전트 채택판 (2026-11-11)

> **작성 기준**: `문제해결형_기획안_가이드` v1.3. 가이드 V5 절차대로 **작성 에이전트 3명(선명·강렬·담백) → 가림 풀 → 검수 에이전트 2명 → 통합**을 실제로 돌린 결과다. 과정 기록은 `copy-run-v6/`(브리프, 작성 3, 풀, 검수 2, 통합 기록).
> **검수 기준**: 표현이 자연스러운가 · 구매욕구를 불러일으키는가(각 0~5). 표현 수위와 글자 수는 채점하지 않았다.
> **결과 한 줄**: 핵심 9자리 모두 새 후보가 기존 확정안을 이겼다. 아래 "채택"은 검수 채택안을 페이지로 이어 읽어 겹침만 조정한 조합이며, **최종 선택은 광고주가 한다.**
> **v6.0과의 관계**: 핵심 9자리의 3안을 에이전트 채택 결과로 교체했다. 나머지 자리(카드·후기 본문·부품 설명·비교 항목·제품정보·Q&A)의 3안과 스크린·이미지·보류 항목은 v6.0·v5.0 그대로다.

## 1. 핵심 9자리 — 채택 1 + 대안 2 + 기존안

### M 메인 키비주얼
| 구분 | 큰 제목 | 보조 | 각도 · 톤 |
|---|---|---|---|
| ★ 채택 | **붙였다. 돌렸다. / 끝났다.** | 설치가 이렇게 싱거워도 되나 싶은 3초. / 그런데 손으로 흔들어 보면 생각이 달라집니다. | 리듬·반전 · 강렬 |
| 대안 1 | **타면 착 / 내리면 쏙** | 대기만 하면 붙는 마그네틱 헤드. / 벌리고 끼우고 조이는 일은 이제 없습니다. | 감각·일상 리듬 · 선명 |
| 대안 2 | **바람은 송풍구로 / 화면은 눈높이로** | 송풍구를 막지 않고 대시보드 위에 섭니다. / 높이와 각도는 운전자가 정합니다. | 대비 · 담백 |
| 기존 | 3초 다이얼 고정 / 맥세이프 거치대 | 휴대폰은 대면 붙고, / 내릴 땐 들면 됩니다. | 숫자 · 선명 (8위 밖) |
- 검수 평: 세 박자가 설치 동작과 그대로 겹쳐 읽는 것만으로 속도가 느껴진다. 보조문의 "흔들어 보면"이 싱거움을 믿음으로 뒤집는다.
- 주의: 채택안에는 범주 명사(맥세이프 거치대)가 없다. 아이브로 `NORVEC 맥세이프 차량용 거치대`가 그 역할을 맡는다. 대안 2의 `눈높이`는 용어표상 `시야 안`이 원칙이라 쓸 경우 판단 필요.

### T 타겟 헤더
| 구분 | 카피 | 각도 · 톤 |
|---|---|---|
| ★ 채택(페이지 조합) | **송풍구, 그립, 테이프, 조수석. / 어디까지 써 보셨어요?** | 질문·디테일 나열 · 선명 |
| 대안 1 (검수 최고점 10) | **익숙해졌을 뿐, / 편했던 적은 없습니다.** | 반전 · 강렬 |
| 대안 2 | **매일 타는 차인데 / 매일 한 번씩 거슬렸습니다.** | 일상 리듬 · 담백 |
| 기존 | 운전할 때 휴대폰은 / 어디에 두세요? | 질문 (8위) |
- 통합 조정: 최고점은 대안 1이지만 비교 헤더 채택안과 같은 발상이고 바로 뒤 위험소구와 뒤집기 구조가 겹쳐 대안과 자리를 바꿨다. 비교 헤더를 다른 안으로 고르면 대안 1을 올려도 된다.
- 조판 메모: 채택안 첫 줄이 16자라 표준 템플릿 헤더(100px)에서는 글자 크기를 한 단계 줄이거나 두 줄로 나눠야 한다.

## 2. 채택안으로 이어 읽은 페이지

| 영역 | 카피 |
|---|---|
| 메인 | **붙였다. 돌렸다. / 끝났다.** — 설치가 이렇게 싱거워도 되나 싶은 3초. / 그런데 손으로 흔들어 보면 생각이 달라집니다. |
| 타겟 | **송풍구, 그립, 테이프, 조수석. / 어디까지 써 보셨어요?** |

| 후기 | **좋다는 말 말고, / 어디가 좋았는지.** |
| 설계 | **잘 만든 물건은 / 속을 보여 줄 수 있습니다.** |
| SP 01 | **설치요? / 방금 끝났는데요.** |
| SP 02 | **화면이 / 나한테 옵니다.** |
| SP 03 | **안 쓰는 날엔 / 없던 것처럼** |
| 비교 | **익숙한 것과 / 편한 것은 다릅니다.** |

- 톤 분포: 강렬 4 · 선명 3 · 담백 2. 유입 구간(메인·SP)은 강렬, 신뢰 구간(위험·설계·비교)은 선명 쪽으로 자연스럽게 나뉘었다.

## 3. 사람 검토 (광고주 선택 요청)
| # | 자리 | 선택지 |
|---|---|---|
| 1 | 메인 | 채택안에는 `3초 다이얼 고정`과 범주 명사가 제목에서 빠진다. 새 채택안 / 기존안 유지 / 새 제목 + 기존 범주 줄 병기 |

| 3 | 후기 | 페이지 조합안 `좋다는 말 말고, 어디가 좋았는지.` / 최고점 `달아 본 사람들은 말이 많아집니다.` |

| 5 | 위험소구 | 채택안의 "A가 아닙니다. B입니다" 문형 수용 여부. 꺼려지면 대안 1 `길 안내를 보려고 길에서 눈을 뗍니다.` |
