# N001 상세페이지 기획안 v6.2 — 권고 조합판 (2026-11-11)

> v6.1(에이전트 채택판)을 자체 검토한 뒤, 가이드 v1.4의 **V7 페이지로 읽기** 규칙으로 조합을 다시 짠 판이다. 후보는 전부 v6.1 런의 검수 상위안에서 골랐고 새로 쓴 문장은 없다. 본문 자리(서브·카드·후기·부품 설명·비교 항목)는 이 제목들에 맞춰 2차 런을 돌리는 중이며 결과는 v6.3에 싣는다.

## 1. 제목 조합

| 영역 | v6.2 채택 | v6.1 채택 | 바꾼 이유 (V7) |
|---|---|---|---|

## 2. V7 점검
| 점검 | 결과 |
|---|---|
| 자리의 역할 | 메인에 품목·기능 ○ / 설계에 제품 고유 사실 ○ / SP 01은 제목만으로는 '설치' 이야기임을 알 수 있음 ○ / SP 02·03은 이미지와 설명이 기능을 받쳐야 함 △ |
| 핵심어 | `맥세이프 거치대` 1 · `다이얼` 1 · `3초` 1 (메인). 본문 2회 이상은 2차 런에서 확보 |
| 기법 횟수 | 뒤집기 2(설계 · SP 02) · 대화체 1(SP 01) · 질문 2(타겟 · SP 01) — 기준 이내 |
| 반려 문형 | 없음 |
| 같은 어미 3연속 | 없음(…써 보셨어요? / 뗍니다. / 좋았는지. / 설계했습니다. / 끝났는데요. / 옵니다. / 없던 것처럼 / 세워 보세요.) |
| 약속 문장 | 제목에는 없음. 메인 보조 후보 `흔들어 보면 생각이 달라집니다`는 약속 문장으로 표시[V7-4] |

## 3. 남은 선택
- 메인 보조문에 `붙였다. 돌렸다. 끝났다.`를 쓸지는 2차 런 결과와 함께 정한다.
- 타겟 헤더 첫 줄(16자)은 표준 템플릿에서 글자 크기를 한 단계 줄여야 한다.
- 설계 제목의 `설계했습니다`는 개발 어휘 허용 방침에 따라 채택했다.
