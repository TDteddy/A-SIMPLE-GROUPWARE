- **대안 1 — P-S3-33** `렌터카에도 / 내 거치대를 답니다.` ‖ `접어서 가방에 넣어 가면 여행지에서도 쓰던 그대로. / 반납할 땐 흔적 없이 떼어 오면 됩니다.`
  - 각도: 장면(여행·렌터카) · 문형: 서술문 · 톤: 선명
  - 이유: 이 자리의 세 가지 역할을 빠짐없이 담은 유일한 안이다. S2를 서술문이 아닌 안으로 바꾸면 채택으로 올릴 수 있다.
- **대안 2 — P-S3-41** `뗀 자리를 / 손으로 쓸어 보세요.` ‖ `끈적임이 없습니다. 처음부터 테이프를 쓰지 않았으니까요.`
  - 각도: 감각(손바닥 감촉) · 문형: 권유 · 톤: 강렬
  - 이유: 자국 걱정으로 망설이는 사람에게 가장 세게 닿는다. 깨끗함 하나에 집중하고 싶을 때 쓴다.

### (d) 총평
접이·이동·깨끗함 가운데 하나만 말하는 안이 대부분이고, 둘 이상을 한 장면에 묶은 안이 확실히 앞선다. 기존 확정안은 이 풀에서 가장 약한 축에 든다.

## C · 비교 영역 헤더 (42안)

### (a) 탈락
- 탈락 없음. 타사 실명을 든 안이 없고, 송풍구·집게·테이프는 방식 이름이다.
- 같은 안으로 묶어 본 것: P-C-04와 P-C-37(완전 동일), P-C-03(줄바꿈만 다름). 줄바꿈은 "익숙한 것과 / 편한 것은 다릅니다."가 호흡이 낫다.

### (c) 채택 1 + 대안 2

- **채택 — P-C-04** `익숙한 것과 / 편한 것은 다릅니다.`
  - 각도: 대비(선언) · 문형: 서술문 · 톤: 선명
  - 이유: 불만 없이 쓰던 사람도 자기 거치대를 의심하게 해 표로 눈이 내려간다. 짧고 한 호흡이라 헤더로 기억에 남는다.
- **대안 1 — P-C-12** `"거치대가 다 거기서 거기지." / 나란히 놓으면 생각이 달라집니다.`
  - 각도: 반전(속말 뒤집기) · 문형: 대화체 인용 + 서술 · 톤: 강렬
  - 이유: 살 마음이 없던 사람의 핑계를 정면으로 받는다. 타겟 영역에 따옴표 인용 카피가 채택되면 겹치니 그때는 피한다.
- **대안 2 — P-C-42** `내 거치대 옆에 / 한번 세워 보세요.`
  - 각도: 장면(나란히 세우기) · 문형: 권유 · 톤: 담백
  - 이유: 비교하라는 말을 눈에 보이는 동작으로 바꿨다. 기존 확정안과 역할은 같고 그림이 더 생긴다.

### (d) 총평
"나란히 놓으면/표로 보면" 식 안내형이 많아 서로 비슷하고, 지금 쓰는 것을 다시 보게 만드는 안이 드물어 그만큼 두드러진다.

## 네 자리 채택안 이어 읽기 점검

| 자리 | 채택안 | 각도 | 문형 | 제목 끝말 |
|---|---|---|---|---|
| S1 | 설치요? / 방금 끝났는데요. | 반전 | 대화체 문답 | ~는데요 |
| S2 | 화면이 / 나한테 옵니다. | 결과 | 서술문 | ~ㅂ니다 |
| S3 | 안 쓰는 날엔 / 없던 것처럼 | 일상 리듬 | 한 구 | ~처럼 |
| C | 익숙한 것과 / 편한 것은 다릅니다. | 대비 | 서술문 | ~ㅂ니다 |

- 각도: 네 자리가 모두 다르다(4종). 겹침 없음.
- 문형: 문답 · 서술문 · 한 구 3종. 서술문이 S2와 C 두 번이지만 사이에 S3가 끼어 있어 이어지지 않는다.
- 같은 어미 3연속: 없음. 제목 끝말은 `~는데요 → ~ㅂ니다 → ~처럼 → ~ㅂ니다` 순이다.
- 설명 줄 어미: S1 `~뿐입니다 / 민망합니다`, S2 `올리세요 / 맞춰 줍니다`, S3 `넣어 두세요 / 돌아갑니다`. `~ㅂ니다`가 많지만 권유형이 섞여 3연속은 아니다.
- 같은 말 반복: 네 채택안 사이에 되풀이되는 핵심어가 없다. `3초`는 이 네 자리에 쓰지 않았다.
- 세 셀링포인트 조정 내역: S2는 P-S2-42와 P-S2-15가, S3는 P-S3-16·33·41이 동점이었고, 문형이 서로 겹치지 않는 조합으로 골랐다.
- 다른 자리와 맞춰 볼 것(내가 보지 않은 M·T·R·V·D 결과에 따라):
  - S2 설명의 "고개를 숙이는 대신"은 위험소구(R) 채택안이 '고개 숙임'을 쓰면 말이 겹친다.
  - S1 대안 1(오늘 받아서 오늘 달고)은 메인(M)에 같은 발상이 채택되면 쓸 수 없다.
  - C 대안 1(따옴표 인용)은 타겟(T)·후기(V)에 인용형이 채택되면 피한다.
- 기존 확정안 대비: 네 자리 모두 새 후보가 확정안을 이겼다(S1 9.5 대 6.5, S2 9.5 대 7, S3 9.5 대 5.5, C 9.5 대 8). 교체를 권고하며 최종 선택은 광고주 몫이다.
