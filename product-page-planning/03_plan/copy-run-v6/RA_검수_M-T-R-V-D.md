※ 기존 문형 `먼저 써 본 분들의 / 한마디`(P-V-32)는 자연스러우나 표지판에 그쳐 8위 밖(구매욕구 2 · 자연스러움 5).

### (c) 채택 1 + 대안 2
- **채택 P-V-03** `달아 본 사람들은 / 말이 많아집니다.` — 각도: 결과(써 본 뒤의 변화) / 톤: 선명
  후기가 길다는 사실 하나로 만족을 암시해, 과장 없이도 읽고 싶게 만든다. 어떤 후기가 실려도 어긋나지 않는다.
- **대안 P-V-01** `진짜 안 떨어지냐고요? / 써 본 분들께 물었습니다.` — 각도: 질문(의심 정면 돌파) / 톤: 강렬
  흡착식에 대한 불신을 헤더가 먼저 말해 준다. 고정력을 다룬 실제 후기가 확보되면 채택안보다 셀 수 있다.
- **대안 P-V-21** `좋다는 말 말고, / 어디가 좋았는지.` — 각도: 디테일 집착 / 톤: 담백
  구체적인 후기만 골라 실었다는 인상을 준다. 평서형이 이어지는 페이지에서 어미를 끊어 주는 역할도 한다.

### (d) 총평
"저희 말보다 써 본 분들 말"과 "써 본 사람들의 꾸밈없는 이야기" 계열이 과반이었고, 특정 사용 장면(장거리·여름·차 두 대)을 걸고 후기를 여는 안은 P-V-10 하나뿐이었다.

- **채택 P-D-38** `잘 만든 물건은 / 속을 보여 줄 수 있습니다.` — 각도: 선언(정체성) / 톤: 강렬

- **대안 P-D-05** `바닥에서 헤드까지, / 전부 이유가 있습니다.` — 각도: 디테일 집착 / 톤: 담백
  아래로 이어지는 부품별 설명을 하나의 주장으로 묶어 준다. 기존 문형(P-D-15)과 같은 뜻을 더 매끄럽게 말한다.

## 페이지 점검 — 다섯 채택안 이어 읽기

> M `붙였다. 돌렸다. / 끝났다.`
> T `익숙해졌을 뿐, / 편했던 적은 없습니다.`
> R `문제는 휴대폰이 아닙니다. / 휴대폰이 놓인 높이입니다.`
> V `달아 본 사람들은 / 말이 많아집니다.`
> D `잘 만든 물건은 / 속을 보여 줄 수 있습니다.`

| 점검 항목 | 결과 | 내용 |
|---|---|---|
| 각도 4종 이상 | 충족 | 숫자·체감(M) / 반전(T) / 대비·원인 재정의(R) / 결과(V) / 선언(D) — 5종 |
| 같은 어미 3연속 | **미충족** | T·R·V·D 네 자리가 모두 `~습니다/~입니다` 평서로 끝난다. M만 `~다` 반말 단문. |
| 같은 말 반복 | 대체로 충족 | 자리 간 겹치는 낱말은 없다. R 안에서 '휴대폰'이 두 번 나오는 것은 의도된 반복. 다만 T와 R이 연달아 "~은 아니다/없다 → 사실은 ~다" 부정-뒤집기 구조라 붙여 읽으면 같은 수법으로 들린다. |
| 문형 3종 이상 | 미흡 | 단문 나열(M) + 평서 서술문(T·R·V·D) 2종. 질문·권유가 없다. |

**해소 방법(다시 쓰지 않고 대안으로 교체)**
- T를 대안 **P-T-02** `송풍구, 집게, 테이프, 조수석. / 어디까지 써 보셨어요?`로 바꾸면 질문형이 들어오고 T–R의 부정-뒤집기 겹침도 사라진다.
- V를 대안 **P-V-21** `좋다는 말 말고, / 어디가 좋았는지.`로 바꾸면 R·V·D의 평서 3연속이 끊긴다.
- 이 둘을 바꾼 조합(M-34 / T-02 / R-03 / V-21 / D-38)은 어미가 `~다 / ~어요? / ~입니다 / ~는지 / ~습니다`로 문형 4종, 3연속 없음.
- 실제 페이지에서는 이 다섯 자리 사이에 S1·S2·S3·C가 끼므로, 다른 검수자의 채택안과 합쳐 읽은 뒤 T와 V 중 어느 쪽을 바꿀지 정하면 된다. 한 줄의 힘만 보면 T-28과 V-03이 각 자리 최고점이다.

**기존 문형과의 비교**: 다섯 자리 모두 새 후보가 이겼다(M-03, T-42, R-16, V-32, D-15 → 각각 8위 밖 / 8위 / 3위 / 8위 밖 / 6위). 교체 권고이며 최종 선택은 광고주 몫이다.
