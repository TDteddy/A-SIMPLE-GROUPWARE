# N001 카피 런 v6 — 공통 브리프 (모든 에이전트가 먼저 읽는다)

## 고정 문단
1. 목표는 구매욕구를 끌어올리는 것이다. 제품이 평범해도 기능을 가장 좋은 모습으로 극대화해 쓴다.
2. 미사여구는 자제하지 않는다. 수식어·형용사·감탄·은유·선언·체감형 과장을 마음껏 쓴다.
3. 자제하는 것은 하나다. 하지 않은 시험의 결과, 받지 않은 인증, 측정하지 않은 수치(유지 시간·하중·자력·온도 한계)를 사실처럼 쓰지 않는다. `3초`, `1초`, `한 손` 같은 체감 표현은 된다.
4. 그 밖의 탈락 사유: 사고 예방 보장·주행 중 휴대폰 조작 권유 / 타사 실명 비방 / 충전 기능이 있는 것처럼 쓰기.
5. 자료는 발상의 재료이지 한계가 아니다.

## 제품
차량용 맥세이프 거치대(판매명 미확정, 브랜드 NORVEC). 충전 기능 없음.
- 진공 압착 베이스 + 다이얼 락: 대시보드 평면에 누르고 실버 다이얼을 TIGHT로 돌리면 고정. 접착제·테이프 없음. OPEN으로 풀고 릴리즈 탭을 당기면 떼어지고, 다른 자리·다른 차·책상 유리에 다시 붙일 수 있다. 떼어 낸 자리에 끈적임이 없다.
- 마그네틱 링 헤드: 휴대폰(맥세이프 케이스 또는 메탈링 붙인 케이스)을 대면 붙고 들면 떨어진다. 한 손.
- 듀얼 힌지 암: 위아래 기울기와 가로·세로 전환. 송풍구가 아니라 대시보드 위라 높이·각도가 자유롭다.
- 접으면 납작한 원반 모양(손바닥 크기).

## 이 제품을 보는 사람 (지금 쓰는 방식 → 겪는 것)
- 송풍구 거치대: 에어컨 바람이 막히고 겨울엔 히터에 휴대폰이 뜨거워진다. 높이·각도가 날개에 매인다.
- 그립(집게)형 거치대: 탈 때마다 양손으로 벌려 끼운다.
- 거치대 없음: 조수석·무릎·도어 포켓에 두고, 울리면 손을 뻗고 내려다본다.
- 테이프로 붙이는 부착형: 하루 기다려야 하고, 여름에 떨어지고, 떼면 자국, 다시 못 붙인다.
