# N001 카피 런 v6 — 2차 페이지 검수 (RE)

- 기준: `카피_작성·검수_2에이전트_프로세스.md` 개정 3의 점검 7개, 보편 가이드 v1.4 V7.
- 입력: 제목 RA·RB(자리당 상위 8안), 제목 통합안 v6.2, 본문 RC·RD(자리당 상위 3안).
- 후보는 다시 쓰지 않았다. 카피는 1차 검수 문서의 원문 그대로다.
- 표기: **[약속]** 고객이 받아서 직접 확인하게 되는 문장 / **[경계]** 반려 문형과 뼈대가 닮았거나 1차에서 조건이 붙은 문장 / **[확인]** 사실 확인이 필요한 문장.
- 타겟 헤더는 RA 원문이 `집게`, v6.2 표가 `그립`이다. 본문 후보(타겟 카드·후기·비교)가 모두 `집게`로 쓰여 있어 원문 `집게`로 적었다(5-2 참조).

## 1. 채택 조합 — 품목 직진 메인 + 말맛·동작 본문

### 메인
- 제목 **P-M-03** `3초 다이얼 고정 / 맥세이프 거치대` [약속: 3초]
- 보조 **Q-MS-19** `갖다 대면 착 붙고 / 집어 들면 톡 떨어집니다.` [약속]
- 아이콘 **Q-MI-22** `대고 떼고 / 누르고 돌리고 / 세우고 접고`
- 이유: 제목 한 줄에 품목·기능·숫자가 다 있고, 제목이 마른 명사형이라 보조문의 손맛(착·톡)이 갖고 싶은 마음을 맡는다. 아이콘은 `착`·`한 손`이 없는 동사형으로 골라 바로 위 보조문과 말이 겹치지 않게 했다.

### 타겟
- 헤더 **P-T-02** `송풍구, 집게, 테이프, 조수석. / 어디까지 써 보셨어요?`
- 카드 **Q-TC-05**
  - 송풍구 거치대: `히터 바로 앞` / `겨울엔 히터가 휴대폰을 데워요`
  - 그립형 거치대: `잠깐, 두 손 좀` / `짐을 내려놓아야 끼울 수 있어요`
  - 거치대 없이: `어디 뒀더라` / `신호 대기마다 휴대폰을 찾아요`
  - 떨어진 부착형: `하루 기다린 테이프` / `더운 날이면 접착이 먼저 지쳐요`
- 이유: 헤더가 네 방식을 호명하고 카드가 그 사람의 혼잣말로 받는다. Q-TC-12는 헤더와 더 매끄럽게 이어지지만 `무릎 위에 / 내려다보게 돼요`가 바로 아래 위험소구와 같은 발상이라 내렸다.

### 위험소구
- 제목 **P-R-33** `길 안내를 보려고 / 길에서 눈을 뗍니다.`
- 캡션 **Q-RC-09**
  - 큰 사진: `화면이 무릎 높이에 있으면 / 눈도 무릎까지 내려갔다 옵니다.`
  - 작은 사진: `좌석 틈으로 손을 뻗는 사이` / `더운 날 바닥에서 발견한 거치대` / `시동 걸기 전, 한 손으로 대면 착` [약속]
- 이유: 제목에는 '높이'가 없는데 큰 캡션이 무릎이라는 높이로 받아 제품이 바꾸는 변수를 채운다. 겁주는 말이 없고 마지막 캡션이 출발 전 동작으로 끝난다.

### 후기
- 헤더 **P-V-21** `좋다는 말 말고, / 어디가 좋았는지.` [경계: "A 말고, B" 대조 구문 — 5-1 참조]
- ① **Q-VR1-01** 송풍구에 꽂아 쓸 땐 에어컨을 틀면 바람이 다 휴대폰한테 가서 한쪽을 아예 닫고 다녔거든요. **대시보드로 올리고 나니까 바람이 제 얼굴까지 와요.** 겨울에 히터 틀어도 폰이 안 뜨거운 게 제일 좋네요. [확인: 온도 효능으로 읽힐 수 있음]
- ② **Q-VR2-05** 집게형은 탈 때마다 두 손으로 벌려서 끼워야 했잖아요. **이건 그냥 갖다 대면 착 하고 붙어서 처음엔 좀 웃었어요.** 내릴 때도 들고 나오면 끝이라 가방 멘 채로도 돼요.
- ③ **Q-VR3-03** 아이 어린이집 데려다주는 길에 폰을 늘 조수석에 던져 놨었어요. 브레이크 밟으면 바닥으로 떨어지고, 전화 오면 손으로 더듬고. **지금은 타자마자 붙여 두니까 폰이 어디 있는지 찾을 일이 없어요.**
- ④ **Q-VR4-02** 화상회의할 때 폰을 책 더미에 기대 놓던 사람입니다. 이건 세로로 세웠다 가로로 눕혔다가 되니까 회의도 보고 영상도 봐요. **뗐을 때 유리가 말끔한 게 제일 신기했어요.** [약속]
- ⑤ **Q-VR5-03** 부모님 차에 달아 드리려고 하나 더 주문했어요. 누르고 다이얼 돌리는 게 전부라 설명드릴 것도 없더라고요. **아버지가 "이게 다냐" 하시던 게 아직도 생각나요.**
- 이유: 헤더가 "구체적인 말만 골랐다"고 약속하고 다섯 장이 바람·원터치·제자리·책상과 깨끗한 분리·설치 속도로 하나씩 갈린다. 여는 방식(고백 / 동의 구함 / 장면 / 자기소개 / 구매 목적)과 말버릇이 모두 달라 다섯 사람으로 읽힌다.

### 설계
- 제목 **P-D-16** `잘 붙는 건 기본. / 잘 떨어지는 것까지 설계했습니다.` [약속] [경계: RA 1차에서 '자체 설계 주장'으로 탈락, v6.2에서 개발 어휘 허용 방침으로 복귀]
- 부품 **Q-DP-17**
  - `링 헤드` / `마그네틱이 폰을 먼저 마중 나옵니다` [약속]
  - `힌지 암` / `접으면 손바닥만 한 원반이 됩니다`
  - `압착 베이스` / `실버 다이얼 하나로 붙이고 뗍니다` [확인: 뗄 때는 릴리즈 탭도 쓴다]
- 이유: 붙고 떨어지는 구조는 이 제품에만 붙는 사실이고, 베이스 줄이 제목의 "떨어지는 것까지"를 다이얼로 받친다. Q-DP-03은 헤드 줄이 메인 보조문과 같은 문장이라 내렸다.

### SP 01 (다이얼 고정)
- 제목 **P-S1-19** `설치요? / 방금 끝났는데요.`
- 설명 **Q-S1D-06** `손바닥으로 한 번 누르고 다이얼을 TIGHT까지. / 읽는 것보다 붙이는 게 빠릅니다.` [약속]
- 이유: 제목이 능청이고 설명 첫 줄이 누르기·다이얼·TIGHT라는 동작이다. 둘째 줄이 제목의 농담을 한 번만 이어받는다.

### SP 02 (높이·각도)
- 제목 **P-S2-42** `화면이 / 나한테 옵니다.`
- 설명 **Q-S2D-11** `출발 전에 눈높이까지 올리고 내 쪽으로 기울이세요. / 듀얼 힌지가 그 자리에 화면을 세워 둡니다.` [약속: 맞춘 자리를 유지] [확인: '눈높이까지' — 브리프는 '눈높이 가까운']
- 이유: 제목의 감정을 "올리고, 기울인다"는 동작으로 풀고 "출발 전에"가 맨 앞에 있어 주행 중 조정으로 읽히지 않는다.

### SP 03 (접이·이동)
- 제목 **P-S3-16** `안 쓰는 날엔 / 없던 것처럼` [약속]
- 설명 **Q-S3D-01** `대시보드를 비워 두고 싶은 날엔 납작하게 접어 눕히세요. / 아예 치우고 싶은 날엔 다이얼을 풀면 됩니다. 떼어 낸 자리는 깨끗합니다.` [약속]
- 이유: 제목의 "안 쓰는 날"을 접는 날과 떼는 날로 나눠 답하고, 접이·분리·깨끗함이 순서대로 다 있다.

### 비교
- 헤더 **P-C-42** `내 거치대 옆에 / 한번 세워 보세요.`
- 카드 **Q-CR-13** — 왼쪽 `쓰던 방식` · 오른쪽 `NORVEC 방식`
  - 설치: `하루 뒤에야 쓸 수 있음` / `붙인 자리에서 바로 출발` [약속]
  - 휴대폰 거치: `끼우는 데 양손이 필요` / `커피 든 채 한 손으로`
  - 자리 이동: `떼는 순간 테이프는 끝` / `풀어서 옮기고 다시 붙임` [약속: 재부착]
- 이유: 오른쪽 세 줄이 내가 하게 될 행동이고 다른 영역과 말이 겹치지 않는다. Q-CR-05는 `다이얼 3초`를 살리지만 `대면 붙고 들면 끝`이 메인 보조문을, 왼쪽 제목이 타겟 헤더를 되풀이한다.

### 차 밖 사용
- 헤더 **Q-LH-08** `주차하고 떼어 왔습니다. / 지금은 책상 위에서 근무 중.`
- 이유: 떼어서 옮긴다는 구조가 문장 안에 있고, 페이지 끝에서 한 번 웃게 만든다.

### 제품정보
- 헤더 **Q-PH-09** `다이얼 방향만 기억하시면 됩니다.`
- 이유: 이 제품에만 붙는 문장이고 설치·분리 그림 앞에서 "어렵지 않다"를 먼저 만든다.

## 2. 대안 조합 — 숫자·사실 직진판

채택과 다른 자리만 적는다. 적지 않은 자리(타겟, 위험소구, 후기 헤더, 후기 ①③⑤, SP 01, SP 03)는 채택과 같다.

| 영역 | 대안 | 이유 |
|---|---|---|
| 메인 제목 | **P-M-33** `붙이는 데 3초 / 떼는 데 1초` + 딸린 보조 `다이얼로 잠그는 맥세이프 거치대. / 뗀 자리에는 아무것도 남지 않습니다.` [경계: 두 줄 대구 뼈대] [약속: 3초·1초·남지 않음] | 숫자 둘로 붙이는 쪽과 떼는 쪽을 한 번에 팔고, 바로 붙은 줄에 품목·다이얼이 있다. 대구 뼈대라 채택에는 올리지 않았다 |
| 메인 아이콘 | **Q-MI-03** `착 붙는 헤드 ‖ 꽉 잠그는 다이얼 ‖ 납작 접는 암` | 이 메인은 원터치를 말하는 보조문이 없어 아이콘이 헤드를 짚어 줘야 한다 |
| 후기 ② | **Q-VR2-06** 케이스 바꿀 때마다 집게 폭 다시 맞추던 게 은근 스트레스였어요. 맥세이프 케이스 끼우고 대기만 하면 되니까 그런 게 없어요. **"착" 하고 붙는 그 느낌이 은근히 기분 좋더라고요.** | 본문에서 `맥세이프`를 한 번 되살리고 케이스 전제를 후기가 대신 말한다 |
| 후기 ④ | **Q-VR4-08** 유리 상판 책상인데 꾹 누르고 다이얼만 돌리면 서 있어요. **각도가 잡히니까 폰이 작은 보조 모니터가 됐어요.** 접으면 납작해져서 노트북 파우치에 같이 넣고 다닙니다. | 메인이 이미 "뗀 자리"를 말하므로 후기는 쓰임새 쪽으로 돌렸다 |
| 설계 | **P-D-30** `손바닥만 한 원반 안에 / 이만큼 들어 있습니다.` + **Q-DP-05** `원터치 헤드` / `끼우는 동작을 통째로 지웠습니다` ‖ `자유 각도 암` / `송풍구 날개 대신 내가 정합니다` ‖ `무접착 베이스` / `테이프 없이 붙고 자국 없이 뗍니다` [약속] | 메인이 떼는 이야기를 했으니 설계는 생김새(접힌 원반)로 간다. `설계했습니다` 주장이 빠지고 본문에 `원터치`가 낱말로 들어온다 |
| SP 02 | **P-S2-10** `키가 달라도, / 시트가 달라도.` + **Q-S2D-18** `키 큰 사람도 시트를 바짝 당겨 앉는 사람도 맞는 자리가 있습니다. / 힌지 두 개가 높이와 기울기, 가로·세로까지 받아 줍니다.` [확인: 언제 맞추는지가 문장에 없어 사진에서 출발 전임을 보여야 함] | 뒤집기 하나를 줄이고 사람·사실로 말한다. 설명은 제목 42에 맞춰 쓴 안이지만 이 제목과 말이 그대로 이어진다 |
| 비교 카드 | **Q-CR-05** `테이프·집게·송풍구` · `NORVEC` ‖ 설치: `테이프 붙이고 하루 대기` · `꾹 누르고 다이얼 3초` ‖ 휴대폰 거치: `벌리고 끼우고 맞추고` · `대면 붙고 들면 끝` ‖ 자리 이동: `한 번 붙이면 그 자리뿐` · `차에서 책상까지 그대로` [경계: 왼쪽 제목이 타겟 헤더와 같은 나열] | `3초`를 본문에서 한 번 살린다. 이 조합에는 메인 보조문이 없어 `대면 붙고 들면 끝`이 겹치지 않는다 |
| 차 밖 사용 | **Q-LH-11** `차에만 두기엔 / 이 다이얼이 너무 아깝습니다.` | 위트 대신 자부심. 책상·주방은 사진이 받쳐야 한다 |
| 제품정보 | **Q-PH-14** `붙이는 법과 떼는 법, 둘 다 짧습니다.` | 메인의 "붙이는 데 / 떼는 데"를 페이지 끝에서 되받는다 |

대안 조합의 약점: 메인에 `원터치`가 아이콘 한 줄뿐이고, 경계 표시가 세 곳(메인 제목, 후기 헤더, 비교 왼쪽 제목)이다. `떼기·흔적 없음`이 메인·설계 부품·SP 03·제품정보에 네 번 나온다.

## 3. 점검표

| 점검 | 채택 조합 | 대안 조합 |
|---|---|---|
| ① 반려 문형 | "A가 아닙니다. B입니다" 없음. 쉼표 대구 없음. **경계 1**: 후기 헤더 `좋다는 말 말고, / 어디가 좋았는지.` | 경계 3: 메인 제목(두 줄 대구), 후기 헤더, SP 02 제목 `키가 달라도, / 시트가 달라도.`(쉼표 나열) |
| ② 자리의 역할 | 메인 ○(품목·기능·숫자) / 타겟 ○ / 위험소구 △(제목에 높이가 없고 캡션이 채움) / 설계 ○ / SP 01 ○ / SP 02·03 △(제목만으로는 기능이 안 보이고 설명이 받침) / **비교 헤더 △**(다른 거치대 페이지에도 붙는 문장, 카드가 받침) | 메인 ○(바로 붙은 줄에 품목) / 설계 ○(접힌 원반) / 비교는 카드에 `다이얼 3초`가 있어 채택보다 나음 |

**채택 조합의 약속 문장(광고주 확인)**
1. 메인 `3초` — 누르고 다이얼을 끝까지 돌리는 데 실제로 그 정도인가.
2. 메인 보조 `갖다 대면 착 붙고 / 집어 들면 톡 떨어집니다` — 메탈링 케이스에서도 같은 손맛인가.
3. 위험소구 캡션 `한 손으로 대면 착`.
4. 설계 제목 `잘 떨어지는 것까지 설계했습니다` — 떼기 쉬움과 자체 설계 근거.
5. 설계 부품 `마그네틱이 폰을 먼저 마중 나옵니다` — 가까이 대면 끌려가는 느낌이 있는가.
6. SP 01 `읽는 것보다 붙이는 게 빠릅니다`.
7. SP 02 `그 자리에 화면을 세워 둡니다` — 맞춘 각도가 주행 중에도 유지되는가.
8. SP 03 `없던 것처럼`, `떼어 낸 자리는 깨끗합니다`, 후기 ④ `뗐을 때 유리가 말끔한 게`.
9. 비교 `붙인 자리에서 바로 출발`, `풀어서 옮기고 다시 붙임`.

## 5. 재작성이 필요한 자리와 광고주가 골라야 할 것

### 5-1. 재작성 필요
1. **본문의 핵심어 두 개** — `맥세이프 거치대`가 본문 상위안 어디에도 없고(`맥세이프`는 후기 Q-VR2-06 한 곳), `3초`는 Q-CR-05 한 곳뿐이다. 조합을 바꿔서는 "본문 2회 이상"을 채울 수 없다. 넣기 좋은 자리는 제품정보 헤더, 비교 오른쪽 카드 제목, 설계 부품 라벨이다.
2. **후기 헤더(조건부)** — `좋다는 말 말고, / 어디가 좋았는지.`를 광고주가 반려한 대조 뒤집기로 읽으면 대신할 후보가 없다. P-V-03·P-V-22는 제목 `~ㅂ니다` 3연속을 만들고, P-V-40·P-V-01은 질문이 세 번이 된다. 그 경우 평서 `~ㅂ니다`가 아니고 질문도 아닌 헤더를 새로 써야 한다.
3. **비교 헤더** — 상위 8안에 이 제품 고유의 사실이 든 헤더가 없다. 지금은 카드가 대신 받치고 있다. 다이얼이나 원터치가 든 헤더를 한 번 더 받아 보는 것을 권한다.

### 5-2. 광고주가 골라야 할 것
- **후기 다섯 장은 작성된 문장이다.** 실제 구매 후기로 게시할 수 없다. 실후기를 모아 같은 다섯 유형으로 바꾸거나, 체험단 후기를 받을 때 방향 예시로만 써야 한다.
- 설계 제목의 `설계했습니다` — 자체 설계 근거가 없으면 대안 P-D-30(`손바닥만 한 원반 안에 / 이만큼 들어 있습니다.`)으로 간다.
- 타겟 헤더의 `집게`와 `그립` — 본문이 모두 `집게`라 `집게`를 권한다. `그립`으로 가면 타겟 카드·후기 ②·비교도 맞춰야 한다.
- 메인: 채택(품목 직진)과 대안(`붙이는 데 3초 / 떼는 데 1초`) 중 하나. 대안은 두 줄 대구 뼈대이고 `1초`가 약속 문장이다.
- `착` 세 번을 줄이고 싶으면 위험소구 캡션을 Q-RC-05로 바꾼다(큰 캡션이 길어진다).
- v6.2에 남아 있던 `붙였다. 돌렸다. 끝났다.`를 메인 보조로 쓰는 안은 권하지 않는다. 제목이 이미 다이얼 설치를 말했고, 보조에서 원터치가 빠진다.
- 약속 문장 9항목과 [확인] 표시 세 곳(후기 ① 히터, 설계 부품 `다이얼 하나로`, SP 02 `눈높이까지`).

## 6. 총평

읽히는 순서와 말의 겹침은 정리됐고, 타겟 카드·위험소구 캡션·SP 설명은 사람 말로 자연스럽게 읽힌다. 다만 메인 제목은 1차 검수에서 구매욕구 2점을 받은 줄이라 첫 화면의 끌림은 보조문 한 줄에 기대고 있고, 비교 헤더도 이 제품만의 말이 아니다. 구매욕구는 SP 세 영역과 후기에서 가장 높은데, 후기는 실제 후기로 바꾸는 순간 지금의 완성도가 보장되지 않는다.
