## 사실 차이
- 조작부 명칭: 실물 자산 대조는 `은색 잠금 링`·`분리 탭`으로 적었고, 브리프 제품 절은 `실버 다이얼`·`릴리즈 탭`이다. 브리프를 따랐다.
- 분리 동작: 자산 대조는 탭을 "들어" 분리, 브리프는 탭을 "당기면" 떼어진다. 브리프를 따랐다.
- 가로·세로 전환: 자산 대조는 헤드 회전인지 암 축 회전인지 미확인(T6)이라 "관절과 헤드로 방향 전환"으로 완화했고, 브리프는 "헤드를 돌려 가로·세로 전환"이다. 브리프를 따랐다(S2D, DP, TC).
- 구성품: 같은 금형의 경쟁 판매처는 흡착 보조패드(접착식)를 동봉하지만, 브리프는 접착제·테이프가 없고 동봉품은 메탈링만 언급한다. 보조패드와 메탈링 정착 시간은 쓰지 않았다.
- 설치 위치: 자산 대조의 판매처 표기에는 앞유리·센터 디스플레이 옆이 있으나, 브리프는 앞유리 부착 권장 여부를 미확인으로 둔다. `유리`까지만 썼다.
- 더운 날 관리: 경쟁 상세는 "며칠 간격 재흡착"으로 안내하고, 브리프는 "다이얼을 다시 조이면 된다"이다. 브리프를 따랐다.
- 색상: 자산 대조는 검정 본체에 은색 링만 확인(흰색 미확인). 브리프에 색상 항목이 없어 쓰지 않았다.
