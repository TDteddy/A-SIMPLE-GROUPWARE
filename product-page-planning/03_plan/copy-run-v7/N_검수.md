# 자연스러움 검수 결과 (v7)

## 선명

### 손봄 (8건)
- **선명-MS** 끌어당겨 붙습니다 → 끌어당겨 붙입니다 — 주어가 '자석 헤드'인데 서술어가 '붙습니다'라 주술이 어긋난다
- **선명-DP** 휴대폰을 끌어당겨 붙이고 한 손으로 뗍니다 → 휴대폰을 대면 붙고 한 손으로 뗍니다 — 앞 절은 헤드가, 뒤 절은 사람이 주어라 한 문장 안에서 주어가 바뀐다
- **선명-DE** 한 동작처럼 → 하나로 — '부품이 동작처럼 이어진다'는 결합이 어색하다
- **선명-S2D** 주차 중 영상은 → 주차 중에 영상은 — '주차 중 영상'이 한 덩어리(주차 영상)로 읽힌다
- **선명-S2D** 힌지 암이 맞춘 기울기로 화면을 → 맞춘 기울기 그대로 힌지 암이 화면을 — '힌지 암이 맞춘'으로 읽혀 누가 맞췄는지 헷갈린다
- **선명-QA** 충전 기능은 없는 → 충전 기능이 없는 — 관형절 안의 '은'이 어색하다
- **선명-QA** 다시 고정합니다 → 다시 고정해 주세요 — 바로 앞 문장까지 '~해 주세요'인데 혼자 평서형이라 말투가 튄다
- **선명-QC** 변경과 재거치는 → 바꾸거나 다시 달 때는 — '재거치'는 실제로 쓰지 않는 말이다

### 다시 (3건)
- **선명-S1** 조인 뒤 흔들어 확인하는 고정 — '확인하는 고정'은 억지 명사형이다. 관형절을 '고정'으로 받아 끝내서 말이 되지 않는다
- **선명-S1D** 면에 누르고 다이얼을 TIGHT로 돌리면 컵이 조여 밀착됩니다. — 무엇을 누르는지 빠져 있고, 설명 없이 나온 '컵'이 '조여 밀착된다'는 것도 주술이 맞지 않는다
- **선명-L** 원래 있던 것처럼 놓인 자리 — 놓인 것은 거치대인데 '놓인'이 '자리'를 꾸며 뜻이 한 번에 잡히지 않는다

### 이어 읽은 인상
동작을 차례로 적는 문장은 대체로 잘 읽히지만, 08 설치 자리에서 제목과 본문이 연달아 걸리고 12 제목도 뜻이 흐리다.

## 강렬

### 손봄 (9건)
- **강렬-TC** 다른 차에 다시 조입니다 → 다른 차에 다시 조여 답니다 — '차에 조인다'는 결합이 어색하다
- **강렬-VR** 대기만 하면 → 갖다 대기만 하면 — '대기(待機)만 하면'으로 읽힌다
- **강렬-DP** 휴대폰을 가져가면 → 휴대폰을 가까이 대면 — 어디로 가져가는지 빠져 있다
- **강렬-DE** 한 동작처럼 → 한 몸처럼 — '부분이 한 동작처럼 움직인다'는 결합이 어색하다
- **강렬-S3D** 떼지 않고 정리합니다 → 떼지 않고 정리할 수 있습니다 — 앞 절 주어는 제품, 뒤 절은 사람이라 '정리합니다'가 붕 뜬다
- **강렬-CR** 같은 자석 방식입니다 → 같은 자석 방식 — 표 칸이 명사형인데 이 칸만 합쇼체 문장이다
- **강렬-CR** 제품에 따라 다릅니다 → 제품에 따라 다름 — 표 칸이 명사형인데 이 칸만 합쇼체 문장이다
- **강렬-L** 일부처럼 → 일부였던 것처럼 — '처음부터'를 받는 서술어가 없다
- **강렬-QC** 변경과 재거치는 → 바꾸거나 다시 달 때는 — '재거치'는 실제로 쓰지 않는 말이다

### 다시 (0건)
- 없음

### 이어 읽은 인상
짧게 끊는 제목과 본문이 무리 없이 이어지고, 걸리는 곳은 낱말 하나씩 손보면 되는 정도다.

## 담백

### 손봄 (5건)
- **담백-V** 샀다가 남긴 말 → 산 분들이 남긴 말 — '샀다가 남긴'의 '-다가' 연결이 어색하고 누가 남겼는지 빠져 있다
- **담백-S1D** 누른 다음 다이얼을 → 베이스를 누른 다음 다이얼을 — 본문 첫 문장인데 무엇을 누르는지 빠져 있다
- **담백-CR** 빼서 옮김 → 빼서 옮기기 — 같은 표의 다른 칸은 '-기'로 끝나는데 이 칸만 '-ㅁ'이다
- **담백-CR** 탭 들어 분리 → 탭 들어 떼기 — 같은 표의 다른 칸은 '-기'로 끝나는데 이 칸만 명사로 끝난다
- **담백-QC** 변경과 재거치는 → 바꾸거나 다시 달 때는 — '재거치'는 실제로 쓰지 않는 말이다

### 다시 (1건)
- **담백-C** 끼우던 손과 대는 손의 차이 — '끼우던 손', '대는 손'이 무엇을 가리키는지 제목만 읽어서는 잡히지 않는다

### 이어 읽은 인상
가장 말하듯 읽히며 후기와 Q&A에 걸리는 곳이 없고, 11 비교 제목만 뜻이 잡히지 않는다.
