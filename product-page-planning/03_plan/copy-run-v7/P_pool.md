# v7 가림 풀 r2 (작성자·입장 가림, 자리별 무작위 순서)

글자 수는 공백·문장부호 포함, 줄바꿈 제외로 기계가 센 값이다(각주 `*…` 제외). 세트 자리는 세지 않았다. 세트의 칸 구분은 ` | `, 줄 구분은 ` / `, 칸 안 제목과 설명 구분은 ` — `이며 작성자마다 표기가 조금 다를 수 있다.
