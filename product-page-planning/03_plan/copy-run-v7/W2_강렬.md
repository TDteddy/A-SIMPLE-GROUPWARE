## 질문
1. CR은 `대상명 A | 대상명 B / 항목명 — A의 칸 | B의 칸 / …`으로 적었다(줄 구분 ` / `, 칸 구분 ` | `). 7절 형식에 표를 적는 법이 따로 없어 이렇게 정했다.
2. S1 5 `조인 다음 흔들어 보세요 / 손이 먼저 압니다`와 D 4 `돌려 보면 압니다`는 받아서 직접 확인하게 되는 약속 문장이다(가이드 V7-4). 실물의 조임 체감이 받쳐 주는지 확인한 뒤 써야 한다.
3. CR 2는 접착식과 견주어 휴대폰 고정 칸을 `같은 자석 방식입니다`로 적었다. 우위가 없는 칸을 그대로 두어도 되는지, 아니면 비교 대상을 집게형(CR 1) 하나로 고정할지 판단이 필요하다.
4. `접착제 없이`, `공구도 테이프도 없이`(S1 2, S1D 3, DP 2)는 본체 고정 방식에 한해 썼다(2-3). 금속 링이 접착식이어서 페이지 전체로 읽으면 "테이프가 하나도 없다"로 오해될 수 있는지 확인이 필요하다.
5. TC 2 `옆자리와 함께`는 "방향을 돌려"까지만 썼다. 조수석 쪽으로 돌아가는 범위가 실물에서 확인되지 않으면 이 카드는 빼야 한다.
6. VR의 "붙였던 자리에 자국이 안 보여서", "전에 붙였던 자리가 말끔해서"는 리뷰(자국 11건)를 한 사람의 장면으로 옮긴 것이다. 내장재에 따라 눌린 자국이 남을 수 있다는 원자료 메모가 있어 이 두 장을 그대로 실어도 되는지 확인이 필요하다.
7. 브리프 2-1은 분리를 "탭을 들어"로만 적는다. PR 2의 `분리 탭을 들어 공기를 넣으면`은 구조 설명을 덧붙인 것이라, 실물 동작과 다르면 PR 1을 쓰면 된다.
