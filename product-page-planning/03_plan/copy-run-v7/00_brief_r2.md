# N001 카피 런 v7 — 작성 브리프 (r2, 다시 씀)

> r1의 문제: 제품 사실을 원자료가 아니라 기억으로 적어 다섯 곳이 실물 대조 자료와 달랐고, 확정되지 않은 것(메탈링 동봉 등)을 사실처럼 적었다. 용어가 섞였고, 읽을 자료를 도중에 덧붙였고, 자리 표 한 칸에 지시를 몰아넣었고, 광고주 지시와 통합 담당의 판단이 구분되지 않았다. r2는 원자료에서 다시 뽑아 구조를 나눴다.

## 0. 이 브리프를 읽는 법
- 지시가 서로 다르면 이 순서로 따른다: **① 광고주 지시(3절) → ② 레이아웃 규격 → ③ 보편 가이드 → ④ 참고 자료.**
- 표의 '상태'가 **확인**인 사실만 단정해서 쓴다. **판매처 표기**는 조건을 붙여 쓰고, **미확정**은 쓰지 않는다.
- 이 브리프에 없는 판단이 필요하면 지어내지 말고 산출물 끝 `## 질문`에 적는다.

## 2. 제품 사실 (출처: `00_source/N001_실물_자산_대조`, `N001_자료_신뢰도_점검`, 대시보드 레코드)

### 2-1. 구조와 동작
| 항목 | 내용 | 상태 | 카피에서 |
|---|---|---|---|
| 베이스 | 둥근 고무 컵 위에 은색 널링 잠금 링(다이얼). 링에 `TIGHT ▪▪▪▪ OPEN ▶` 각인. 가장자리에 분리 탭 | 확인(도해·자산) | 그대로 쓴다 |
| 고정 원리 | 면에 누르고 다이얼을 TIGHT로 돌리면 컵이 조여져 밀착·고정 | 확인 | 그대로 쓴다. "눌러 공기를 빼고 조인다"도 된다 |
| 분리 | OPEN으로 풀고 **탭을 들어** 분리 | 확인(도해). 실물 조작감은 미확인 | "다이얼을 풀고 탭을 들어 올립니다". `당긴다`로 쓰지 않는다 |
| 암 | 짧은 금속 암. 베이스 쪽 힌지 + 헤드 쪽 힌지, 두 개 | 확인 | 높이·기울기 조절로 쓴다 |

## 3. 광고주 지시 (그대로 따른다)
1. 목표는 구매욕구다. 제품이 평범해도 기능을 가장 좋은 모습으로 극대화한다. 자료·증명에 얽매이지 않는다.
2. 미사여구는 자제하지 않는다. `강력한` 정도의 세기 표현은 된다.
3. `절대`, `~없음`처럼 **단정하는 어휘는 지양**한다(무조건, 100%, 완벽, 어디든, 모든 기종, 전혀, 걱정 끝).
4. 시험 결과·인증·수치를 사실처럼 쓰는 것은 자제한다. `3초`, `한 손` 같은 체감 표현은 된다.
5. **본문은 합쇼체.** 해요체는 평상문 같아서 쓰지 않는다. (예외: 후기는 고객 말투, Q&A 질문은 고객 말투)
6. 제목은 명사형·직관. `A가 아닙니다. B입니다` 꼴과 쉼표로 나눈 대구(`A는 B, C는 D`)는 쓰지 않는다.
7. 유사 제품 리뷰는 우리 제품의 리뷰로 본다. **리뷰의 궁금증과 불안을 해소하고, 만족한 부분을 극대화한다.**
8. 재구성 후기를 쓴다.
9. 레이아웃은 14영역 기본안 규격을 따른다.
10. 소비자 상황·배경을 먼저 생각하고, 보편적인 사람 기준으로 쓴다.
- 통합 담당이 지키는 선(광고주 지시 아님): 사고 예방 같은 안전 보장, 주행 중 휴대폰 조작을 편리함으로 말하기, 타사 실명 비방, 충전되는 것처럼 쓰기는 하지 않는다. 후기 영역에는 재구성임을 알리는 한 줄이 붙는다.

### 03 메인

- 주의: `어디든 설치`, `모든 기종 호환`, `절대 떨어지지 않음`, `사고 예방`.

- 주의: 운전 중 알림 확인·조작을 편리함으로 말하지 않는다. 모든 카드를 "편리하다"로 끝내지 않는다.

## 6. 광고주에게 확인할 것 (답이 오기 전에는 표의 기본값으로 쓴다)
1. **부품 용어**: 규격은 `자석 헤드 / 관절 / 흡착 베이스`, 이전 결정은 고정 방식에 `압착`, 가이드는 `관절` 같은 신체 비유어를 피한다. 기본값: `자석 헤드 / 힌지 암 / 흡착 베이스`, 고정 방식 서술에는 `압착`.
2. **가로·세로 전환이 어느 부위에서 되는가**(헤드 회전인지 암 축 회전인지). 기본값: 부위를 쓰지 않는다.
3. **메탈링·보조패드의 동봉 여부.** 기본값: 동봉이라고 쓰지 않는다.
4. **분리 탭은 드는가 당기는가.** 기본값: 든다.
5. **앞유리 부착을 권해도 되는가.** 기본값: 쓰지 않는다.

## 7. 산출 형식
```
### M
1. 첫째 줄 / 둘째 줄 ⟨받는 줄: 각도·눈높이⟩
```
- 5절의 코드 29개를 `### 코드`로, 번호 목록 한 줄에 한 안. 줄바꿈 ` / `, 세트의 칸 구분 ` | `, 칸 안 제목과 설명 구분 ` — `.
- `⟨받는 줄⟩`에는 4절 표의 어느 줄을 받는지. 글자 수는 적지 않는다(기계가 센다).
- 끝에 `## 내 페이지`(자리마다 고른 번호), `## 질문`(브리프로 판단할 수 없었던 것).
- 입장(선명·강렬·담백)은 작성자마다 따로 받는다. 이 브리프에는 없다.
