## 검수의 중심 둘
① 표현이 자연스러운가 ② 구매욕구를 불러일으키는가.
- 미사여구(수식어·감탄·은유·선언)는 감점 사유가 아니다. **`강력한`, `단단한` 같은 세기의 말도 감점하지 않는다.** 느낌표, 형용사 개수도 채점하지 않는다.
- **`3초`, `한 손` 같은 체감 표현은 측정 수치가 아니며 허용이다.** "눌러 공기를 빼고 다이얼로 조인다"는 이 제품의 구조 사실이다. 이 둘로 탈락시키지 않는다.
- 글자 수가 권장 범위를 벗어난 것은 탈락이 아니다. 풀에 (넘침/모자람)이 표시돼 있으니 비슷한 안이면 범위 안의 것을 고른다. 안전·호환 조건 때문에 넘친 것은 불이익을 주지 않는다.

## 순서
1. **탈락 스캔** — 아래만 탈락: 아래 제품 사실 표에서 **미확정**인 것을 사실로 쓴 것(가로·세로 전환을 어느 부위로 하는지, 금속 링·보조패드 '동봉', 색상, 치수·무게, 앞유리 부착, 무거운 기기·폴드 거치, 주방 등 물기 있는 곳) / 사실 목록에 없는 기능·시험 결과·인증·측정 수치(하중·자력·유지 시간·온도·부피 감소율·치수) / 사고 예방 같은 안전 보장 / 주행 중 휴대폰 조작을 편리함으로 말하기 / 타사 실명 비방 / 충전되는 것처럼 쓴 것 / 질병·건강 위험 암시, 죄책감 유도, 가짜 한정·마감 / 반려 문형("A가 아닙니다. B입니다" 꼴, 쉼표로 나눈 대구 "A는 B, C는 D") / 본문이 해요체인 것(후기와 Q&A 질문은 예외).
2. **표시만 하고 넘기는 것** — 단정 어휘(`절대`, `무조건`, `100%`, `완벽`, `어디든`, `모든 기종`, `~없음`, `전혀`, `걱정 끝`): 탈락시키지 않고 이유 칸에 [단정]이라고 적는다. 비슷한 안이 있으면 단정 없는 쪽을 고른다. / 사실 확인이 필요한 문장: [확인].
3. **소리 내 읽기** — 한국어 화자가 실제로 쓰는 말인가. 번역체, 억지 명사형, 어색한 조사, 기계적 대구, "~을 제공합니다/자랑합니다" 홍보체를 거른다.
4. **영역의 소구와 맞는가** — 레이아웃 문서가 그 영역에 정한 소구를 말하는가(예: SP03은 정리·보관, 타겟 카드는 상황 하나 + 하려는 일 하나, 라이프스타일은 기능 설명이 아님, 위험소구는 제품이 사고를 막는다고 말하지 않음). 본문은 제목에 없는 정보를 더하는가.
5. **구매욕구** — "사고 싶다 / 궁금하다 / 내 얘기다" 중 하나가 나오는가. 리뷰의 불안(운전 중 탈락, 내 차 면, 여름, 내 폰, 광고만큼 될까)에 답하거나 만족(각도·눈높이, 착, 내비, 한 손, 차 밖, 접어 두기, 옮겨 붙이기, 떼는 순간)을 키우는 안은 여기에 반영한다. 조건을 숨기지 않은 안을 약하다고 보지 않는다.
6. 보조 질문(이유에 반영): 말이 되는가 / 공감이 되는가 / 읽는 사람이 그렇게 받아들일 수 있는가 / 제품명을 다른 거치대로 바꿔도 성립하는 문장은 아닌가(설계·셀링포인트·비교).
7. 자리마다 **상위 3안**을 고르고 구매욕구 0~5, 자연스러움 0~5를 매긴다. 세 안은 각도가 달라야 한다(단어만 바꾼 변형이면 하나만).

## 2. 제품 사실 (출처: `00_source/N001_실물_자산_대조`, `N001_자료_신뢰도_점검`, 대시보드 레코드)

### 2-1. 구조와 동작
| 항목 | 내용 | 상태 | 카피에서 |
|---|---|---|---|
| 베이스 | 둥근 고무 컵 위에 은색 널링 잠금 링(다이얼). 링에 `TIGHT ▪▪▪▪ OPEN ▶` 각인. 가장자리에 분리 탭 | 확인(도해·자산) | 그대로 쓴다 |
| 고정 원리 | 면에 누르고 다이얼을 TIGHT로 돌리면 컵이 조여져 밀착·고정 | 확인 | 그대로 쓴다. "눌러 공기를 빼고 조인다"도 된다 |
| 분리 | OPEN으로 풀고 **탭을 들어** 분리 | 확인(도해). 실물 조작감은 미확인 | "다이얼을 풀고 탭을 들어 올립니다". `당긴다`로 쓰지 않는다 |
| 암 | 짧은 금속 암. 베이스 쪽 힌지 + 헤드 쪽 힌지, 두 개 | 확인 | 높이·기울기 조절로 쓴다 |
| 접이 | 접으면 **헤드가 베이스 위에 포개져** 납작한 원형. 붙인 채로도 접힌다 | 확인(접힘 도해) | "접어 눕힌다 / 포갠다". `분리한 뒤 접는다`로 한정하지 않는다 |
| 헤드 | 가운데가 뚫린 링형 자석 헤드 | 확인 | 그대로 |
| **가로·세로 전환** | 헤드 윗면에 `OPEN ↔` 표시가 있으나 기능 미확인. 판매처 도해는 **암 축 회전**으로 표기 | **미확정** | "방향을 가로·세로로 바꾼다"까지만. **어느 부위를 돌리는지는 쓰지 않는다** |
| 충전 | 없음(거치 전용) | 확인 | 필요한 자리에서 분명히 알린다. 저발열 장점으로 돌리지 않는다 |
| 색상 | 검정 본체 + 은색 다이얼. 판매 색상 옵션은 미확정 | 미확정 | 색상을 말하지 않는다. `실버 다이얼`은 된다 |
