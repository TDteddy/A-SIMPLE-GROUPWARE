## 할 일
### 1. 페이지 가·나·다를 각각 이어 읽고 평가
페이지마다 구매욕구 0~5, 자연스러움 0~5, 한 문단 평(읽고 남는 것, 걸리는 곳).

### 2. 채택 조합 1개 (A의 상위 3안에서 자리마다 하나)
점수만 따라가지 않고 이어 읽었을 때를 본다. 순서대로 점검한다.
1. **묶음으로 고르는 자리**: 비교의 C·CR·CE는 같은 상대(집게형/접착식 등)를 말하는 한 묶음으로. 타겟 T와 TC(제목이 카드 전부를 받는가). 위험소구 R·RD·RC(같은 말을 두 번 하지 않는가). 설치 PI와 분리 PR(같은 표기 방식).
2. **영역의 소구**: 레이아웃 문서가 정한 그 영역의 소구를 말하는가. 각 영역이 서로 다른 구매 질문에 답하는가. 같은 장점을 세 번 말하지 않는가. 본문이 제목에 없는 정보를 더하는가.
3. **메인의 핵심 메시지가 하나로 읽히는가.** 무엇을 파는지(품목)가 메인 영역(M·MS·MB) 안에 있는가.
4. **반려 문형 제외**: "A가 아닙니다. B입니다" 꼴, 쉼표로 나눈 대구.
5. **기법 횟수**: 뒤집기·대화체·질문형은 페이지 전체에서 각각 두 번까지.
6. **핵심어**: `맥세이프 거치대`, `다이얼`이 메인 영역에 한 번, 본문에 두 번 이상.
7. **같은 발상·같은 어미**: 두 자리에 같은 발상이 겹치지 않는가. 같은 어미가 세 번 이어지지 않는가.
8. **제목과 본문의 온도**: 제목이 감정·선언이면 본문이 동작·사실로 받치는가.
9. **리뷰 응답 표 대조**: 불안 다섯(운전 중 탈락 / 내 차 면 / 여름 / 내 폰 / 광고만큼 될까)과 만족 상위(각도·눈높이, 착 붙는다, 내비, 한 손·떼는 순간, 차 밖, 접어 두기, 옮겨 붙이기)가 각각 어느 자리의 어느 문장에서 받아지는지 표로. 불안은 Q&A보다 앞에서 받는 자리가 있는지. 받는 자리가 없으면 "빈 줄".
10. **표시**: 고객이 받아서 직접 확인하게 되는 체험 문장에 [약속], 제품 사실 확인이 필요한 문장에 [확인](제품 사실 표의 '미확정'·'판매처 표기'에 기댄 문장 포함), 단정 어휘가 남은 문장에 [단정]. 보장으로 읽힐 수 있는 문장은 따로 모아 수위 의견을 한 줄씩.
11. **글자 수**: A의 안에 표시된 글자 수를 보고, 채택 조합에서 권장 범위를 벗어난 자리를 목록으로.

### 3. 대안 조합 1개
채택과 **결이 다른** 조합(예: 채택이 눈높이·각도를 메인에 두면 대안은 착 붙는 순간이나 고정의 믿음을 메인에). 채택과 다른 자리만 적고, 얻는 것과 잃는 것을 두세 줄로.

### 4. 풀리지 않는 것
상위 3안 어느 것으로도 풀리지 않는 겹침·빈 줄·어긋난 묶음은 "이 자리는 재작성 필요"로 적고 무엇이 필요한지 한 줄로.
