# N001 기획안 소비자 카피 한국어 점검 (fluent-korean 지침 적용)

- 점검일: 2026-11-09
- 적용 지침: [snflkd/fluent-korean](https://github.com/snflkd/fluent-korean) `fluent-korean-not-coding.md`. 저장소를 내려받아 지침 전문을 읽고, 기획안의 **소비자 카피(copy 필드)**에만 적용했습니다. message·evidence·productionBrief 같은 내부 기록은 대상에서 뺐습니다.
- 적용 방식: 지침은 요약하지 않고 조항별로 대조했습니다. 헤더와 목록에는 2번 조항(서술어로 문장 끝맺기)을 강제하지 않는다는 지침의 예외를 따르되, 광고 제목이라도 **의미 성분이 빠져 뜻이 갈리는 경우**(1번 조항)는 고쳤습니다.

## 적용한 조항

| 코드 | 조항 요지 |
|---|---|
| 문1 | 의미가 있는 문장 성분(주어·목적어·장소 등)을 생략하지 않는다. 관형격 '~의'를 과하게 쓰지 않는다 |
| 문2 | 명사구·부사구·연결어미로 끝내지 말고 서술어와 종결어미로 끝맺는다 (헤더·목록은 예외) |
| 구1 | 조사와 어미를 생략하지 않는다. 보조사·부사·보조 용언을 적극적으로 쓴다 |
| 구2 | 구체적 한자어와 자연스러운 통사 구조를 결합하고, 조사·어미로 어휘 관계를 드러낸다 |
| 구3 | 일반 어휘 자리에 비유적 어휘를 쓰지 않는다 |
| 구4 | 엠대시(—)를 자제하고 콜론이나 접속사로 대체한다 |
| 어휘 | (추가) '폰'처럼 구어 축약형은 '휴대폰'으로 통일해 격을 맞춘다 |

## 02 메인 키비주얼 (이번 디벨롭의 중심)

| 구분 | 수정 전 | 수정 후 | 조항 | 이유 |
|---|---|---|---|---|
| 제목 | 다이얼로 고정하고, / 자석으로 붙입니다. | **거치대는 다이얼로 고정하고, / 휴대폰은 자석으로 붙입니다.** | 문1, 구1 | 두 절의 목적어가 서로 다른데(거치대 / 휴대폰) 둘 다 빠져 있어, 한 대상에 대한 연속 동작으로 읽힐 수 있었습니다. 보조사 '는'으로 대조 구조를 만들어 "차에 고정하는 것 / 폰을 붙이는 것"이 다른 부위·다른 동작임을 제목만으로 전달합니다. 06 기술 보드의 베이스/헤드 구분과도 대응됩니다 |
| 조건 라벨 | — 충전 기능 없음 · 거치 전용 | **충전 기능이 없는 거치 전용 제품입니다.** | 구4, 구1, 문2 | 엠대시와 가운뎃점으로 이어 붙인 명사 나열을 조사와 종결어미가 있는 한 문장으로 바꿨습니다. 뜻은 같고, 읽는 사람이 관계를 추론할 필요가 없어집니다 |

조판 영향: 제목이 10자에서 13자로 늘어 64px에서는 780px 폭을 넘칩니다(700px). **52px로 낮추고 좌우 여백을 56px로 조정**했습니다. 모바일 390px에서는 제목 26px, 라벨 15px로 렌더링되어 가독 하한을 지킵니다. 시안: `kv_mockup/N001_KV_layout_780_grid.png`, `kv_mockup/N001_KV_layout_390_check.png`

## 고치지 않은 것과 이유
- **04 제목 "휴대폰을 찾는 사이, 앞차가 멈춘다면."**: 연결어미로 끝나지만 헤더이고, 대시보드 가이드 04 작성 예시 원문 그대로입니다. 상황형 제목으로서 뒤 본문이 서술을 이어받습니다.
- **08 제목 "설치 방식이 다르면, / 놓을 자리도 달라집니다."**: 주어·서술어가 갖춰진 완결문입니다.
- **12 브랜드 문구**: 승인 공용 원고이므로 손대지 않았습니다.
- **(보류)로 비워 둔 원고**: 확정 뒤 작성 시 같은 지침으로 점검합니다.
