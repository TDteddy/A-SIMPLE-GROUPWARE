# N001 상세페이지 기획안 v6.4 — 리뷰 응답판 (2026-11-11)

> 무엇이 달라졌나: v6.3은 설치의 **속도**를 팔았다. 리뷰가 묻는 것은 붙은 뒤의 **믿음**이었다. v6.4는 유사 제품 리뷰 299건의 **불안 다섯 가지를 전부 Q&A보다 앞에서 받고**, 고객이 쓴 말(착, 쓱, 눈높이, 돌려 조인다, 흔들어 본다)로 썼다.
> 어떻게 만들었나: 보편 가이드 v1.5(C1-7 리뷰 응답 표, V4-2 세 입장, C3-5 한 안 한 체)와 프로세스 개정 4를 처음 적용했다. 작성 3명(선명·강렬·담백)이 22자리 286안 → v6.3 채택안 19개를 더한 292안(자리 추가분 제외)을 작성자 가림 풀로 → 1차 자리별 검수 2명 → 2차 페이지 검수 1명 → 재작성 6자리 30안 → 2차 검수자가 판정 → 통합. 기록은 `copy-run-v6.4/`.
> 종결: **해요체로 통일**(후기는 구어 해요체). 표기: [약속] 고객이 받아서 직접 확인하게 되는 문장 / [확인] 제품 사실 확인이 필요한 문장 / [수위] 보장으로 읽힐 수 있어 광고주 판단이 필요한 문장.
> v6.3의 레이아웃·이미지·고지 위치는 그대로다. 달라진 것은 카피와, 비교 카드의 '더운 날' 항목, 차 밖 장면 3컷, Q&A의 '운전 중' 문항이다.

### 후기 (재구성 후기 — 고지 유지)
- **떨어질까 걱정했던 사람들이 / 붙여 보고 남긴 말이에요.**
- ① 송풍구에서 전환 — 송풍구 거치대는 폰 무게에 자꾸 고개를 숙였어요. 흡착식은 떨어진다길래 망설였는데, 평평한 데 붙이고 다이얼을 조이니 단단하더라고요. **이제 화면이 제 눈높이에 있어요.**
- ② 그립형에서 전환 — 그립형은 내릴 때도 양손이었거든요. 지금은 **잠깐 내릴 때 쓱 떼서 들고 나가요.** 타면 다시 착이고요.
- ③ 거치대 없이 다니던 분 — 등원길에 방지턱이 다섯 개예요. 흡착이라 떨어질 줄 알았는데 **덜컹거려도 화면이 크게 안 흔들려요.** 뒷자리 아이가 내비를 구경해요. [수위]
- ④ 주방에서 쓰는 분 — 요리 영상 없이는 요리를 못 해서 주방에 하나 더 뒀어요. 받자마자 식탁 유리에 붙여 봤는데 잘 붙더라고요. **폰을 양념통에 기대 세우던 일이 없어졌어요.**
- ⑤ 가족 차에 달아 준 분 — 엄마 차에 달아 드렸다가 주말에 제 차로 옮겨 봤어요. 다이얼 풀고 탭을 당기니까 떨어졌고 **뗀 자리에 자국이 없었어요.** 엄마가 도로 가져가셨어요. [확인]

## 2. 대안 조합 — 만족을 앞세우는 쪽 (채택과 다른 자리만)
채택은 믿음을 메인에 올렸다. 대안은 **착·한 손·떼는 장면**을 메인에 올리고 믿음은 SP01 제목에서 받는다.

| 자리 | 대안 |
|---|---|
| 메인 제목 | **착 붙고 꽉 조인다 / 맥세이프 차량 거치대** |
| 메인 보조문 | 탈 때 한 손으로 착 붙이고 / 내릴 때 쓱 집어 들면 돼요 |
| 설계 부품 | 자석 링 — 가까이 대면 자석이 먼저 끌어당겨요 / 힌지 두 개 — 접으면 손바닥만 한 원반이 돼요 / 다이얼 락 — 테이프 없이 조여 붙이고 풀어서 떼요 |
| SP01 제목 | **3초 만에 붙여 놓고 / 흔들어 보면 믿게 돼요** [약속] |
| SP01 설명 | 손바닥으로 꾹 눌러 공기를 빼고, 실버 다이얼을 TIGHT까지 돌려요. / 손을 떼고 잡아 흔들어 보세요. 그대로라면 설치 끝이에요. / 매끈하고 단단한 평면이나 유리에 붙이고, 굴곡·요철·가죽 면은 피해 주세요. |
- 얻는 것: 메인이 무엇을 파는지 제목에서 말한다. 만족 1·2위와 떼는 장면이 첫 화면에 온다. 주행 보장으로 읽힐 수 있는 `흔들어도 그 자리`가 빠진다.
- 잃는 것: 가장 큰 불안을 받는 자리가 메인에서 SP01로 내려간다. `광고 말고 손으로 확인하세요`가 빠진다. "착"이 메인 영역에 세 번 이어진다.

## 4. 네 축에서 어느 입장이 뽑혔나 (채택 조합 기준)
| 축 | 뽑힌 입장 | 문장 |
|---|---|---|
| ① 첫 화면과 품목 비중 | 강렬 | 제목은 결과·선언, 품목은 보조문으로 |
| ② 문제 제기의 세기 | 강렬 + 담백 | 타겟 카드·위험소구는 강렬(잃는 것을 직접), 타겟 헤더는 담백(사소한 장면) |
| ③ 말 걸기 | 담백 | `거치대는 달려 있는데 / 폰은 컵홀더에 있어요.` 관찰 한 줄. 질문형은 페이지 전체에 0회 |
| ④ 비교 | 강렬 | 기준을 먼저 세우고 결론까지 |

- 자리별 출처(채택 22자리 + 재작성 반영): 강렬 9, 담백 6, 선명 3, 재작성 3(메인 보조문·SP02 제목·설계 베이스), v6.3 유지 1(SP03 설명). v6.3 제목은 하나도 남지 않았다.
- 1차 검수 1위 기준으로는 강렬 15 / 선명 4 / 담백 2 / v6.3 1이었고, 2차에서 겹침·기법 한도로 일곱 자리가 차순위로 내려가며 담백이 늘었다.
- 작성자별 페이지 평가(구매욕구/자연스러움): 선명 4/4, 강렬 5/4, 담백 3/5.

## 5. 통합에서 조정한 것
1. **종결 체**: 합쇼체로 쓰인 7자리(타겟 헤더, 후기 헤더, 설계 제목, SP01 제목, SP02 설명, SP03 설명, 차 밖 헤더)를 해요체로 바꿨다. 뜻은 바꾸지 않았다. SP01 제목은 `뺍니다` → `빼요`로 힘이 조금 빠진다(6절 선택 3).
2. **핵심어 보충**: `맥세이프 거치대`가 본문에 한 번도 없어서 비교 카드의 우리 쪽 열 이름을 `NORVEC 다이얼` → `NORVEC 맥세이프 거치대`로, 사양 '구조' 줄에 `맥세이프 거치대`를 넣었다. 메인 보조문과 합쳐 3회.
3. **재작성 반영**(2차 검수자 판정): 메인 보조문, 위험소구 둘째 작은 캡션, SP02 제목, SP02 설명 덧줄, 설계 베이스. SP03 제목은 재작성안보다 기존 채택이 낫다고 판정되어 유지.
4. **Q&A**: '운전 중에 떨어지지 않나요?'를 넣고 '충전도 되나요?'를 Q2에 합쳤다.

## 6. 광고주 확인·선택

**선택**
1. **메인을 믿음으로 열 것인가, 만족으로 열 것인가** — 채택 `돌려 조이면 끝! / 흔들어도 그 자리` 대 대안 `착 붙고 꽉 조인다 / 맥세이프 차량 거치대`.
2. **`흔들어도 그 자리`의 수위** — 손으로 흔들어 확인한다는 뜻으로 썼지만 메인에 혼자 서면 "주행 중에도 안 떨어진다"로 읽힐 수 있다. 붙지 않는 면이 있고 더운 날 느슨해질 수 있는 제품이므로, 이 문장이 1점 리뷰의 "초강력이라고 해서 샀는데"를 부를 위험이 있다. 그대로 쓸지, 대안 메인으로 갈지.
3. **SP01 제목** — `테이프 대신 / 공기를 빼요.`(구조) 대 `3초 만에 붙여 놓고 / 흔들어 보면 믿게 돼요`(확인 동작).
4. **종결 체** — 이번 조합은 해요체다. 합쇼체로 돌리려면 강렬 쪽 13자리를 바꿔야 한다.
5. **느낌표** — 메인 제목, 설계 헤드, SP01 설명, SP03 제목 네 곳.
6. **위험소구 둘째 컷** — 장면이 바뀌어 이미지를 새로 만들어야 한다.
7. **접이 제목** — 접어 두기(28건)가 제목급에 없다. SP03 제목을 접이로 바꾸면 옮겨 붙이기가 빠진다.

**[수위] 보장으로 읽힐 수 있는 문장**
- 메인 `흔들어도 그 자리` / 후기 ③ `덜컹거려도 화면이 크게 안 흔들려요` / SP03 `떼어 낸 자리는 깨끗해요` / Q5 `남지 않아요`

**[확인] 제품 사실**
1. `3초` — 누르고 돌리는 데 실제로 걸리는 시간.
2. 압착면에 점착 젤이 전혀 없는지 — `테이프 대신`, `녹을 접착이 없고`, `더위에 녹는 부분이 없어요`가 여기에 달렸다. 리뷰에는 "표면에 닿는 부위(끈끈이)"라는 말이 있었다.
3. 장기 부착 뒤 테두리 자국 유무.
4. 앞유리 부착을 권해도 되는지(시야·법규).
5. 메탈링 동봉 여부와 붙이는 법, 무거운 폰·폴드 거치.
6. 헤드 회전(세로↔가로)이 실물에서 부드러운지.
7. 다이얼 표기(TIGHT/OPEN)와 릴리즈 탭 명칭.

## 8. 이 판의 한계
- **작성자 가림이 완전하지 않았다.** 강렬만 해요체로 써서 검수자가 체로 같은 작성자를 알아봤을 수 있다. 강렬 쏠림이 입장 때문인지 체 때문인지 가릴 수 없다. 다음 런에서는 풀을 만들기 전에 체를 하나로 맞추는 편이 낫다.
- **검수 브리프에 누락이 있었다.** `3초` 같은 체감 표현 허용과 진공 압착 원리를 빠뜨려 1차에서 21안이 잘못 탈락했다. 정정을 보내 재판정했고, 설계·SP01·메인 보조문·아이콘·SP01 설명·비교 카드의 상위 3안이 바뀌었다.
- 재작성은 작성자 1명, 판정은 2차 검수자 1명이 했다.
- 점수는 에이전트의 판단이다. 채택과 대안 중 무엇이 더 파는지는 광고 소액 테스트로만 알 수 있다.
