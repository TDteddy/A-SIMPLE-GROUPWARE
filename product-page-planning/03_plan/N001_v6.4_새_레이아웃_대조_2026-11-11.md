# N001 v6.4 ↔ 새 레이아웃(14영역 기본안) 대조 (2026-11-11)

> v6.4는 옛 13영역 틀로 쓴 카피다. 새 규격(`01_guide/레이아웃_NORVEC_기본안_14영역.md`)에 비추면 어디가 맞고 어디를 다시 써야 하는지 적는다. **v6.4 본문은 고치지 않았다.** 다음 판(v6.5)의 작업 목록이다.

## 1. 구조가 달라 다시 써야 하는 영역
| 새 영역 | v6.4 | 어긋나는 점 | 필요한 일 |
|---|---|---|---|
| 01 브랜드 소개 | 없음(옛 틀에서는 맨 뒤 고정 영역) | 맨 앞으로 왔다. 슬로건 8~20자, 설명 30~60자 | 승인된 공용 원고가 있는지 확인. 없으면 새로 만들지 않고 보류 |
| 03 메인 | `돌려 조이면 끝! / 흔들어도 그 자리` | 규격의 N001 방향은 **'화면을 보기 편한 위치와 방향으로 맞추는 사용 경험'**이다. v6.4는 고정의 믿음을 앞세웠다. `흔들어도 그 자리`는 주의('절대 떨어지지 않음' 류의 약속 제외)에 걸릴 수 있다 | 메인을 각도·눈높이 방향으로 다시 쓴다. 대안 메인 `착 붙고 꽉 조인다`도 방향이 다르다 |
| 04 타겟·사용 상황 | 지금 쓰는 방식 4장(송풍구·그립형·거치대 없이·부착형)과 각자의 불편 | 규격은 **상황 하나 + 그 상황에서 하려는 일 하나**다. N001 방향은 '출발 전 내비 준비', '책상에서 화면을 곁에'. 실제로 확인되는 상황이 둘이면 두 장 | 카드를 상황 축으로 다시 쓴다. 타사 방식의 불편은 이 영역에서 빠진다(셀링포인트·비교로) |
| 05 위험소구 | 제목 + 캡션 4개, 수치 없음 | 규격은 근거(숫자·단위·조건·출처)를 요구하고, 없으면 소비자용 원고를 보류한다. 필수 안내 두 줄(출발 전 거치·설정 / 변경은 주차 후)이 들어가야 한다 | 공공 안전자료를 확보하거나, 영역을 보류로 표시. 필수 안내 두 줄 추가 |
| 06 구매 후기 | 재구성 후기 5장 + 고지 | 규격은 **실제 원문 발췌만**. 외부 판매처 후기를 자사 후기처럼 쓰지 않는다. `덜컹거려도 화면이 크게 안 흔들려요` 같은 표현은 검증 없이 재사용하지 않는다 | 자사 후기가 생길 때까지 공개용은 보류. 지금 5장은 내부 시안의 '미검증 예시'로만 둔다 |
| 12 라이프스타일 | 헤더 + 주방·촬영·책상 캡션 3줄 | 규격은 큰 사진과 짧은 제목, 보조문은 원칙적으로 생략. 주방은 설치 가능 여부를 확인한 뒤에 채택 | 캡션 3줄을 뺀다. 확인된 환경(차량·책상)만 |
| 14 Q&A·주의 | 문답 5개 | 기본은 FAQ 3개·주의 4개. 우선 질문에 **'무거운 기기는 어느 범위까지 확인됐는가'**가 있다(v6.4에 없음). 케이스·링 조건을 축약하지 않는다 | 질문을 다시 고르고 무거운 기기 문항을 넣는다(실물 확인 필요) |

## 2. 구조는 맞고 손만 보면 되는 영역
| 새 영역 | v6.4 | 손볼 곳 |
|---|---|---|
| 07 연구개발·설계 | 제목 + 부품 3개 | 부품명을 규격의 역할 분담(자석 헤드·관절·흡착 베이스)에 맞출지 확인. 베이스 `단단히 붙습니다`는 조건이 붙어 있어 괜찮다 |
| 08 SP01 설치 | `테이프 대신 / 공기를 뺍니다.` | 본문이 길다(아래 3절). 설치 순서 전체는 제품정보로 넘긴다 |
| 09 SP02 각도 | `힌지 두 마디가 / 화면을 내 눈높이로 올립니다` | 주의: '어떤 자세에서도 눈높이에 맞는다'는 보장으로 읽히지 않게. 본문에 가로·세로와 기울기의 **실제 범위** |
| 10 SP03 접이 | `내 차에서 풀어 / 아빠 차에 다시 착!` | 규격의 소구는 **정리·보관**이다. v6.4 제목은 옮겨 붙이기다. 접이 제목(차점 `접어 두면 / 대시보드가 다시 넓어집니다`)으로 바꾸는 편이 규격에 맞다 |
| 11 비교 | 2열·4항목 | 기본은 **3항목**(설치면 고정 방식 / 휴대폰 고정 방식 / 접이 구조). '더운 날' 행을 빼거나 화면 검토. `떼면 자국, 재부착 불가` 같은 일반화는 근거가 필요하다 |
| 13 제품정보 | 헤더 + 설치 4·분리 3 | 정보 3행, 단계당 20~45자. 상품정보고시를 하위 표로 |

## 4. 요약
- 제목급 문장은 여섯 영역에서 그대로 쓸 수 있다(설계, SP01, SP02, 비교, 타겟 헤더, 라이프스타일 헤더).
- **다시 써야 하는 것**: 메인(방향이 다름), 타겟 카드(축이 다름), SP03 제목(소구가 다름), 셀링포인트 본문 셋(길이), Q&A 구성.
- **보류해야 하는 것**: 후기(실제 후기 없음), 위험소구(근거 자료 없음), 브랜드 소개(승인 원고 확인 전).
- 리뷰 응답(불안을 앞에서 답한다)은 새 규격의 "주장에 영향을 주는 조건은 그 주장 가까이에"와 같은 방향이라 유지된다. 다만 받는 자리가 좁아진다.
