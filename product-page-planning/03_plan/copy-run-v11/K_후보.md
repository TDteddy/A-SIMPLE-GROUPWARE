# N001 상세페이지 문구 후보 — 읽어 봐 주세요

차량용 휴대폰 거치대의 쿠팡 상세페이지에 들어갈 문구 후보입니다.
제품: 대시보드 같은 평평한 면에 대고 **다이얼을 돌려 조이면** 바닥이 흡착되고, 위쪽 **자석**에 휴대폰(맥세이프)을 대면 붙는 거치대. 관절로 높이·기울기·가로세로를 맞추고, 안 쓸 때는 납작하게 접습니다. 충전 기능은 없습니다.

`/`는 줄바꿈입니다. 제목은 큰 글씨 두 줄로 들어갑니다.

## 03 메인 — 페이지 맨 위. 사진: 휴대폰이 붙어 있는 거치대 전신

제목
- M1: 타면 붙이고 / 내리면 뗍니다.
- M2: 집게 벌리는 일, / 오늘로 끝.
- M3: 끼우지 말고 / 그냥 붙이세요.
- M4: 한 손으로 1초, / 거치 끝.
- M5: 한 손으로 붙이고 / 한 손으로 뗍니다.
- M6: 조일수록 단단한 / 휴대폰 자리.
- M7: 내려다보던 내비가 / 눈높이로 옵니다.

제목 아래 작은 글씨 두 줄
- MS1: 집게를 벌릴 필요 없이 대기만 하세요. / 내릴 때는 그대로 떼어 가면 됩니다.
- MS2: 자석이 휴대폰을 잡고, / 다이얼이 거치대를 단단히 붙듭니다.
- MS3: 다이얼로 조여 붙여 덜컹거려도 든든합니다. / 송풍구는 가리지 않습니다.

## 04 사용 상황 — 사진 카드 네 장(운전 중 내비 / 노트북 옆 / 주방 / 침대 옆 협탁)

제목
- T1: 이런 순간, / 손이 모자랍니다.
- T2: 손은 바쁜데 / 화면은 봐야 할 때.
- T3: 휴대폰 둘 곳이 / 마땅치 않을 때.
- T4: 휴대폰 둘 곳, / 아직도 찾으십니까?

카드 아래 한 줄 (앞의 말은 카드 제목)
- 운전할 때 — Ua: 내비를 눈앞에 세워 둡니다. / Ub: 눈높이에서 내비가 안내합니다. / Uc: 길 안내가 눈앞에 섭니다.
- 일할 때 — Wa: 알림은 노트북 옆에서 한눈에. / Wb: 노트북 옆에 세워 두고 알림 확인.
- 요리할 때 — Ca: 젖은 손 대신 눈으로 레시피를. / Cb: 젖은 손으로 화면을 안 만집니다. / Cc: 레시피 영상을 눈앞에 띄웁니다.
- 쉴 때 — Ra: 누워서도 화면은 눈높이 그대로. / Rb: 들고 보느라 팔 아플 일 없이. / Rc: 침대 옆에 세워 두고 편하게.

## 05 운전 중 휴대폰의 위험 — 어두운 배경. 아래에 `3초 / 83m / 벌점 15점` 숫자 카드가 붙습니다

제목
- R1: 한눈판 3초, / 차는 83m를 달립니다.
- R2: 내려다본 3초, / 차는 83m를 달립니다.
- R3: 손에 든 휴대폰 3초, / 차는 83m를 달립니다.

큰 사진(휴대폰을 손에 든 채 앞차 브레이크등을 마주한 순간) 위 두 줄
- B1: 손에서 내려놓는 순간 / 운전이 편해집니다
- B2: 휴대폰은 거치대에, / 시선은 도로에
- B3: 휴대폰 자리는 / 출발 전에 정해 두세요

사진 캡션
- (휴대폰을 들고 운전하는 사진) C1a: 한 손 운전, 반쪽짜리 핸들링 / C1b: 한 손엔 휴대폰, 한 손엔 핸들 / C1c: 한 손으로만 잡은 핸들
- (거치대에서 휴대폰이 떨어지는 사진) C2a: 방지턱마다 툭 떨어지는 휴대폰 / C2b: 덜컹할 때마다 떨어지는 휴대폰
- (휴대폰을 쥔 손, 경광등 불빛) C3a: 손에 든 휴대폰은 단속 대상입니다 / C3b: 손에 들면 벌점 15점입니다

## 06 후기 영역의 제목
- V1: 먼저 써 본 분들의 / 솔직한 이야기
- V2: 써 본 분들은 / 이렇게 말합니다.
- V3: 사기 전 걱정, / 써 본 분들의 답.

## 07 구조 설명 — 사진: 제품 정면 도해, 부품 세 개 확대, 자석이 휴대폰을 끌어당기는 장면

제목
- D1: 흡착과 자석, / 두 번 잡습니다.
- D2: 바닥은 다이얼로, / 휴대폰은 자석으로.
- D3: 자석으로 붙이고 / 다이얼로 조입니다.
- D4: 다이얼이 조이고 / 자석이 잡습니다.

부품 설명 한 줄씩
- 자석 헤드 — Ha: 대는 순간 끌어당기는 링형 자석 / Hb: 휴대폰을 끌어당겨 잡는 자석
- 관절 — Ja: 높이·기울기·방향을 맞추는 축 / Jb: 화면 높이와 방향을 맞춥니다
- 흡착 베이스 — Ba: 다이얼을 돌려 조이는 흡착판 / Bb: 다이얼로 조여 바닥에 붙습니다

맨 아래 어두운 배경의 큰 글씨 두 줄
- E1: 덜컹거려도 / 단단하게.
- E2: 방지턱에서도 / 든든하게.
- E3: 흔들리는 길에서도 / 단단하게.

## 08 설치 — 사진: 다이얼을 손으로 돌리는 장면

제목
- S1: 돌리면 끝나는 / 5초 설치.
- S2: 붙이고 돌리면 / 설치 끝.
- S3: 꾹 누르고 / 꽉 조이면 끝.
- S4: 돌리면 꽉, / 설치는 그걸로 끝.

본문 두 줄
- SBa: 평평한 면에 대고 다이얼만 돌리세요. / 테이프 자국 없이 떼어 다시 붙입니다.
- SBb: 평평하고 매끈한 면에 대고 돌리세요. / 테이프가 없어 자국이 남지 않습니다.

## 09 화면 방향과 기울기 — 사진: 세로·가로로 돌린 휴대폰, 기울기 조절

제목(쉼표 뒤에서 줄이 바뀝니다)
- A1: 세로로도 가로로도, 내 눈높이에 딱.
- A2: 세로로도 가로로도, 화면은 내 쪽으로.
- A3: 가로로도 세로로도, 내 눈에 맞게.

본문 두 줄
- ABa: 관절을 돌리면 세로·가로가 바뀌고, / 힌지를 꺾으면 기울기까지 맞춰집니다.
- ABb: 관절을 돌려 세로·가로를 바꾸고, / 위아래로 꺾어 기울기를 맞추세요.

## 10 접기 — 사진: 납작하게 접힌 거치대

제목
- F1: 안 쓸 땐 접어서 / 납작하게.
- F2: 접어 두면 / 대시보드가 깔끔.
- F3: 쓱 떼고 접으면 / 손바닥 안에 쏙.
- F4: 접으면 납작하게 / 자리를 비켜 줍니다.

본문 세 줄
- FBa: 헤드와 관절을 접으면 낮은 원형으로. / 대시보드 위가 깔끔해집니다. / 떼면 가방 주머니에도 쏙 들어갑니다.
- FBb: 헤드와 관절을 접으면 납작해집니다. / 쓰지 않을 때도 튀어나오지 않습니다. / 떼면 가방 주머니에 쏙 들어갑니다.

## 11 비교 — 송풍구에 끼우는 집게형 거치대와 이 제품을 나란히 놓은 표

제목
- P1: 집게형 거치대와 / 이렇게 다릅니다.
- P2: 끼우는 거치대와 / 붙이는 거치대.
- P3: 끼우는 대신 / 붙이는 거치대.

표 안의 값
- 집게형 쪽: X1 송풍구에 끼워 바람을 가림 / X2 집게를 벌려 끼움 / X3 튀어나온 채 그대로
- 이 제품 쪽: Y1 평평한 면에 다이얼 흡착 / Y2 자석에 대면 바로 부착 / Y3 접어서 납작하게

## 12 차 밖에서 쓰는 모습 — 사진: 대시보드 / 휴대폰을 붙이는 손 / 책상 / 조명 옆
제목
- L1: 차에서 책상까지, / 붙이는 곳이 자리.
- L2: 차에서만 쓰기엔 / 아깝습니다.
- L3: 내 휴대폰 자리, / 차에도 책상에도.
- L4: 차 안에도 책상에도 / 깔끔하게 섭니다.

## 14 Q&A의 답
- Q1(케이스를 끼운 채로 붙나요?): 맥세이프 호환 케이스는 그대로 붙습니다. 일반 케이스는 바깥쪽 평평한 면 가운데에 메탈링을 붙여 사용합니다. 가죽이나 미끄러운 실리콘 케이스는 링이 잘 붙지 않아 권하지 않습니다.
- Q2(휴대폰 충전도 되나요?): 충전 기능이 없는 거치 전용 제품입니다. 충전은 케이블을 따로 연결해 주세요.
- Q3(제 차 대시보드에도 붙나요?): 먼지와 물기가 없는 평평하고 매끈한 면에 붙습니다. 요철이 있거나 가죽으로 된 면은 흡착 보조패드를 먼저 붙여야 하고, 굴곡진 면에는 맞지 않습니다. 설치할 자리의 표면을 먼저 확인해 주세요.
