### AK-5 유형명 — '양면테이프 접착식' → '부착형' (2026-11-10)

**왜 '부착형'이 맞나**
1. 열 머리는 **시장 통용 유형명**이어야 한다(D14-1). 거치대 시장은 유형을 송풍구형 / 부착형(대시보드에 붙이는 것) / 흡착·압착형 / 컵홀더형으로 부른다. '양면테이프 접착식'은 유형명이 아니라 **기구 설명**이고, 비교표 안에서 그 방식을 깎아내리는 느낌(E3)도 준다.
2. 세 열이 **같은 어미(~형)로 평행**해야 훑힌다. 송풍구형 / 부착형 / 압착형.
3. 열 머리는 썸네일이 함께 있으므로 기구 설명(양면테이프·다이얼 락)은 필요 없다. 짧을수록 한 화면에 든다.

**보편 지침 제안(L-15에 추가, 컨펌 대기) — 비교표 유형명 명명**
| 원칙 | 내용 |
|---|---|
| 통용명 | 열 머리는 그 카테고리에서 소비자·판매처가 쓰는 **유형명**으로(리뷰·경쟁 상세·오픈마켓 카테고리에서 확인, D14-1). 작성자가 만든 설명명은 쓰지 않는다 |
| 평행 | 모든 열을 **같은 어미**(~형 / ~식 중 하나)로 맞춘다 |
| 길이 | 2~4자. 기구 설명·평가어(양면테이프·초강력)는 붙이지 않는다. 설명은 썸네일과 범례가 맡는다 |
| 층위 구분 | 유형명의 '부착형'과 동작어의 '부착'(휴대폰을 헤드에 붙임, D10-2)은 다른 층위다. 유형명은 '~형' 고정 명칭으로만 쓰고 본문 동작어와 섞지 않는다 |
| 우리 열 | 우리 제품도 유형명으로(압착형). 제품명·브랜드·'이 제품' 강조어는 열 머리에 넣지 않고 색으로만 구분 |

**적용**: 08 열 머리 `송풍구형 / 부착형 / 압착형`, 범례의 '접착식' → '부착형(양면테이프)', 마무리 '압착형'. 03 카드 4의 '접착식' → '부착형'으로 통일.

### AK-6 첫째 열(기준) 재점검 (2026-11-10)

**왜 안 맞았나**
1. **극성이 섞였다.** "송풍구 바람을 막지 않나", "평평한 자리가 없어도 되나"는 부정 의문이라 ○가 "막지 않는다"는 이중 부정이 된다. 기호를 훑는데 머리로 뒤집어야 한다.
2. **질문문이 길다**(10~12자, '~나' 종결이 반말처럼 읽힘). 기준은 한눈에 잡히는 명사여야 한다.
3. **기준이 §A-0의 불편 순서와 안 맞았다.** 가장 큰 전환 집단(송풍구형)의 불편(바람·히터 열 19건)이 셋째 행에 있고, 소수 집단(부착형) 대비인 '받은 날'이 첫 행이었다.
4. '평평한 자리가 없어도 되나'는 **이 제품의 조건을 묻는 형태**라 비교 기준이라기보다 자기 단서처럼 읽혔다. 같은 사실을 긍정형 '거친 면·곡면 설치'로 쓰면 송풍구형 ○ / 우리 ✕가 자연스럽게 읽힌다.

**지침 보강(L-15에 추가, 컨펌 대기)**
| 항목 | 제안 |
|---|---|
| 기준 형태 | **명사형 2~6자**(당일 사용·자리 이동). 질문문·부정 의문 금지 |
| 극성 | 모든 행에서 **○ = 좋다/된다**로 통일. "~않나", "~없어도"로 뒤집지 않는다 |
| 순서 | §A-0의 **다수 집단 불편 빈도순**(송풍구 바람 19 → 자리 이동 17 → 당일 → 설치면 조건) |
| 축 일치 | 모든 기준이 비교 축(차에 고정하는 방식)의 결과여야 한다. 휴대폰 부착 방식·자력 같은 다른 축 기준은 넣지 않는다 |
| 조건 행 | 우리가 ✕인 행도 긍정 명사형으로(거친 면·곡면 설치) |

**적용**: 송풍구 비움 / 자리 이동 / 당일 사용 / 거친 면·곡면 설치. 범례 간소화.

### AK-7 '당일 사용' 제거와 우리 열 전부 ○ (2026-11-10)

**점검**
1. '당일 사용'은 **부착형 사용자(소수)에게만 닿는 기준**이다(D11-1 다수 집단 원칙). 송풍구형·거치대 없는 사람에겐 당연한 말이라 행 하나를 낭비한다.
2. 내가 앞서 "우리 열에 ✕ 최소 1"을 공정성 장치로 넣었지만, 비교표의 역할(A2 08: "왜 이 제품·옵션인가")은 **선택 이유를 보여 주는 것**이다. 조건·한계는 가이드가 요구하는 대로 **보존하면 되지, 표 안의 ✕로 보여 줄 필요는 없다**. 표 아래 조건 한 줄과 09-1이 그 역할을 맡는다.
3. 다만 **거짓 ○는 만들지 않는다**. 기준은 우리 제품이 사실로 ○인 것 중에서 고르고, 다른 열에서 차이가 나는 것으로 고른다(모든 열 ○인 행은 무의미).

**지침 수정(L-15 수정, 컨펌 대기)**
| 항목 | 수정 |
|---|---|
| 기준 선택 | **우리 제품이 사실로 ○인 기준** 중에서, 다수 집단의 불편과 맞고 다른 열에서 차이가 나는 것 3~4개. 소수 집단에만 닿는 기준(당일 사용)은 넣지 않는다 |
| 우리 열 | 전부 ○여도 된다. "✕ 최소 1" 규칙은 **삭제** |
| 조건 보존 | 우리 제품의 조건·한계는 **표 아래 작은 글자 1줄**(어디서 확인하는지 포함)로. A3-08 "제한과 다른 방식이 맞는 조건 보존"은 이 한 줄과 09로 충족 |
| 금지 유지 | 종합 우열 행, 타사 흐림 처리, 익명 비하, 모든 열이 ○인 무의미 행, 사실과 다른 ○ |

**적용**: 행 = 송풍구 비움 / 각도 범위 / 자리 이동 / 떼면 자국 없음(우리 열 전부 ○, 각 행에서 다른 열과 차이). 범례 간소화. 조건 한 줄: "압착형은 매끈한 평면 기준입니다. 거친 면은 보조패드, 곡면은 설치 불가 — 09에서 확인해 주세요."
- '떼면 자국 없음'은 끈적 잔여물 기준(접착제 없음). 눌린 자국 가능성은 09·11에 그대로.

### AK-8 '각도 범위' 행 제거 — 정도 기준은 ○✕에 맞지 않는다 (2026-11-10)

**점검**
1. 각도 범위는 **정도의 문제**다. 송풍구형도 각도는 조절되고 범위가 좁을 뿐이라 △는 끼워 맞춘 판정이고, 부착형 ○도 제품마다 달라 사실로 단정할 수 없다. ○✕는 **있다/없다, 된다/안 된다**가 분명한 사실에만 맞는다.
2. 범위 차이는 이미 07-2 KEY(`원하는 높이와 각도 그대로`)가 체감형으로 말한다. 표에서 또 판정하면 근거 없는 수치 비교(E2)처럼 읽힌다.
3. 빈 행은 고정 방식의 **이분 사실**로 채운다: `접착제 없이 설치`(송풍구형 ○ / 부착형 ✕ / 압착형 ○). 설치 시점의 차이(접착제)와 해제 시점의 차이(자국)를 나눠 담는다.

**지침 보강(L-15에 추가, 컨펌 대기)**
| 항목 | 제안 |
|---|---|
| ○✕ 적합 기준 | **이분 사실**(있다/없다, 된다/안 된다, 쓴다/안 쓴다)만. 정도·세기·속도·범위처럼 **연속량**인 기준은 ○✕ 표에 넣지 않는다 |
| 정도 차이의 자리 | 07 KEY·설명에서 체감형으로(D20-2). 표에서는 비교하지 않는다 |
| △의 사용 | △는 "조건이 붙어서 된다"일 때만(다른 송풍구로만). "조금 된다"의 뜻으로 쓰지 않는다 |
| 검수 질문 | 각 셀에 "이 판정이 어떤 제품을 가져와도 같은가?"를 묻는다. 제품마다 다르면 그 행은 뺀다 |

**적용**: 행 = 송풍구 비움 / 접착제 없이 설치 / 자리 이동 / 떼면 자국 없음. 우리 열 전부 ○, 각 행 이분 사실.

### AK-9 표 아래 글 — 무엇이 이미지에 들어가나 (2026-11-10)

질문: 범례·마무리·조건 세 줄은 이미지에 들어가는 소비자 카피인가, 부연인가.
| 줄 | 판정 | 처리 |
|---|---|---|
| `○ 된다 · △ 다른 송풍구로만 · ✕ 안 된다` | ○✕의 뜻은 자명 → ○·✕ 풀이는 **부연**. △만 설명이 필요 | `△ 다른 송풍구로만` 한 조각만 남김(△가 없으면 범례 자체를 뺀다) |
| `평평하고 매끈한 자리가 있다면 압착형이 맞습니다.` | 비교의 **결론**(A2 08 "자사 선택 이유로 마무리") + 조건이 문장 안에 있음 | 유지. 이미지에 들어감 |
| `압착형은 매끈한 평면 기준입니다. 거친 면은 보조패드, 곡면은 설치 불가 — 09에서…` | 마무리 문장이 이미 조건을 말했고 09-1이 상세를 맡음 → **부연**(D17-2 "앞 문장이 이미 뜻을 전했다면 근거 문장을 붙이지 않는다") | 삭제 |

**지침 보강(L-15에 추가)**: 비교표 이미지에 들어가는 글은 **KEY + 표 + (△가 있을 때만) △ 주석 + 결론 1문장**까지. 기호 뜻풀이·조건 반복·"어디서 확인하라" 안내는 넣지 않는다. 결론 문장에 조건을 담아 A3-08의 조건 보존을 충족한다.
