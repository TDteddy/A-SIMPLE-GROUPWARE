# 디선제압 — "이렇게 기획한다고? 그럼 내 상세페이지는 뭐였지?" (odAkQ91k9II, 7.5만회, 8:56)
분석 도구: Higgsfield video_analysis (장면별 음성·화면)

## 핵심 주장
- 상세페이지에서 가장 막히는 것은 디자인·사진·카피가 아니라 **기획**. 디자인은 기획 전달을 10~20배 증폭하는 역할.
- 레퍼런스 수집법: 네이버쇼핑 > 쇼핑BEST > 베스트상품 > 많이 구매한 상품 → 카테고리별 1위 상세 → GoFullPage(크롬 확장)로 전체 캡처 → Figma에 나란히 배치해 "높은 곳에서" 패턴을 본다. 단순 캡처·모방은 초보.
- 1위 상세페이지 공통 패턴 = **머리(Head) → 몸통(Body) → 증명(Proof)**
  - 머리(첫인상·설득의 지름길): 짧은 배너/영상/혜택(반품보장·할인·묶음·리뷰포인트) → 썸네일에서 본 그 상품을 즉시 노출 → 사회적 증거(1위·리뷰수·평점·판매량). 이유: 사람은 객관 분석보다 다수 의견으로 판단.
  - 몸통(뼈대): 고객 관점 질문("이런 고민 있으시죠?")으로 기준점을 심고 → 결핍(불편 경험)과 원인 → 우리 제품으로 해결. = 행동 버튼(WHY)을 심는 구간.
  - 증명: 강점1·2·3(Check 1/2/3)을 하나씩 근거로 증명. 전환율은 이 패턴을 얼마나 잘 쓰는지에 달림.
- 예외: 브랜드 인지도가 높으면(애플·삼성) 설득 구조가 덜 필요. 무명 셀러일수록 구조를 강하게.
- 저관여 상품(모니터 받침대 예): 비교검색 적음 → 첫 화면에 사용 장면·크기감을 직관적으로 보여주는 짧은 영상/이미지가 핵심.
