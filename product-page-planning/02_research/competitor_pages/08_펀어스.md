# 08 펀어스(Funus) — 펀어스 차량 휴대폰거치대 맥세이프 자석 차량용 핸드폰 대시보드 거치대 (티타늄)

- 판매처: 펀어스 (쿠팡, 브랜드 직판 — "온라인 공식 판매처 인증 마크" 배너)
- 가격 / 리뷰: 20,300원 / 리뷰 324건 (옵션: 티타늄, 블랙)
- 분석 소스: 상세 이미지 001~014 (14장, 높이 237~4,534px, 총 약 29,000px) + 갤러리 9장 (640×640)
- 분석 방법: 1300px 단위 분할 30개 세그먼트 + 갤러리 9장 전수 열람
- 비고: **3M VHB 접착 베이스** 제품 — 우리 N001(흡착식)과 고정 방식이 다름. 가격대 3.4배, 브랜드형 상세페이지.

## 1. 제품 구조

| 항목 | 내용 (상세페이지 표시 기준) |
|---|---|
| 고정 방식 | **접착식**. 원형 금속 베이스(직경 50mm) 밑면에 3M VHB 양면테이프(빨간 라이너, `3M VHB™` 반복 인쇄)로 대시보드에 부착. 베이스 가장자리에 카본 패턴 링. 흡착·다이얼 없음. |
| 예비 테이프 | "예비용 3M 보호필름" / "예비용 3M 양면테이프" (명칭 혼용) 1매 동봉. |
| 암·관절 | 베이스 힌지(1) + 헤드 힌지(2)의 **"듀얼 조인트 메커니즘"**. 암은 "이음새 없는 일체형 금속 지지대"(단일 바). 복수가/N001 같은 3관절 다단 접이가 아닌 2관절. |
| 회전 | "360° Adjustable Rotation — 정확한 시야 확보를 위한 정교한 360° 회전 구조". 베이스 회전 여부는 명시 없음(헤드 회전으로 추정). |
| 헤드 형태 | **링형 자석 헤드** (직경 58mm), 링 내측 하단에 `Funus` 로고 탭(마감 플레이트). |
| 자석 | "N52 고강도 자석 내장", "하이파워 자력 구조". 갤러리 g02에 자석 배열을 보라색 발광 세그먼트로 도식화. |
| 충전 | 없음 (무충전). 언급 없음. |
| 접힘 | "사용 하지 않을 시에는 시야 방해 없는 슬림 사이즈로 변신!" — 헤드를 베이스 위로 눕혀 접음. 접은 높이 수치 없음. |
| 구성품 | 01. 마그네틱 호환 맥세이프 링 / 02. 예비용 3M 양면테이프 / 03. LCD 클리닝 와이프 / 04. 본체 : 맥세이프 거치대 |
| 색상 | 티타늄(건메탈 톤) / 블랙 |
| 크기 | `58 x 50 x 70mm` (헤드 지름 58 / 베이스 지름 50 / 높이 70) |
| 소재 | `아연 합금 등` |
| 사용 장면 | 차량 대시보드(세로·가로), 센터콘솔, 룸미러 뒤(앞유리 상단), 트레이, 모니터 하단 책상, 책상 모서리, 욕실 타일. |

## 7. 비주얼 톤

- **배경**: 섹션별로 **블랙 / 화이트 / 다크 네이비** 교차. 히어로·불만·컬러·DETAIL·IN THE BOX는 검정, POINT 01~05 텍스트부와 상세스펙은 흰색. 복수가보다 명암 변화가 많음.
- **타이포**: 굵은 고딕 헤드 + **코랄/오렌지(#FF6B4A 계열) 강조어**, 영문 라벨(Powerful Magnetic Hold 등) 혼용. `POINT 01~05` 검정 캡슐 배지. 히어로에 적색/주황 띠 배너. 텍스트 양이 복수가보다 많고 문장형.
- **사진 vs 실사**: **실사 비중 높음**. 실제 차량(제네시스/기아 계열 내장재, 앰비언트 라이트, 콘솔 다이얼)에서 촬영한 사용자 시점 사진 다수(스마트폰 촬영 품질, 반사·노이즈 있음). 제품 누끼와 히어로는 렌더/합성. 폰 화면은 카카오맵·유튜브·Lexus 광고 등 실제 캡처.
- **차량 장면**: 대시보드 세로/가로, 센터콘솔, 룸미러 뒤 앞유리, 수납 트레이 — **차량 장면 10컷 이상**. 차량 외 장면(책상 2, 욕실 1)은 보조.
- **사람 손/인물**: 006(손+아이폰 15 Pro, 흰 배경), 006(대시보드에 누르는 손), 009(폴드 든 손·팔찌 낀 여성 손), 002(스톡: 운전석에서 떨어진 폰 줍는 여성 — 얼굴 노출, 스톡 이미지로 추정).
- **문제 제기 비주얼**: 사고차량 흑백 배경 위 말풍선 — 공포 소구(fear appeal).
- **브랜드 노출**: `Funus` 로고 상단, 헤드 링 안쪽 `Funus` 각인, 공식판매처 배지. 브랜드형 톤.
- **제품 각인**: 헤드 탭 `Funus`만. TIGHT/OPEN 류 조작 표시 없음(접착식이라 불필요).

## 8. 우리 기획안에 참고할 점 / 피해야 할 점

### 참고할 점
1. **문제 제기 → 공감 → 솔루션 구조**(002): 집게형 거치대의 불만("빠져요", "조금씩 내려앉아")을 먼저 보여주고 자석식으로 전환. 우리도 도입부에 "집게형/접착형의 불편" 프레임을 쓰되, 인용문은 실제 리뷰 출처를 명기.
2. **주행 상황 3종 프레임**(급정거·방지턱·급회전): 소비자 불안 지점을 정확히 짚음. 우리는 같은 프레임에 **실제 주행 테스트 영상/GIF 또는 하중 시험값**을 붙여 근거를 갖춘 버전으로.
3. **실사 차량 사진 다량**: 20,300원 가격 정당화의 핵심. 특히 룸미러 뒤·콘솔 등 **다양한 부착 위치** 제안은 흡착식인 우리에게도 유효(단, 앞유리 부착은 도로교통법상 시야 방해 이슈 있으니 주의).
4. **맥세이프 지원/미지원 분기 도해**(009): 갤럭시 사용자용 링 증정 + "애플 제품은 링 없이 바로" — 호환 안내 포맷으로 그대로 참고할 만함.
5. **IN THE BOX 번호 라벨 + SIZE INFO 치수 도해 + 상세스펙 표 + 사용 전 확인 5항목**: 하단 정보 블록의 표준 구성. 우리도 동일 순서로 배치.
6. **「사용 전 확인해주세요」의 24시간 대기·고온 경고**: 접착식 전용이지만, 우리 흡착식도 "흡착 후 레버/다이얼 잠금 확인", "고온 시 흡착력 저하 가능", "보조패드 사용 조건" 등으로 변환해 넣을 것.
7. **공식판매처 배너**: 브랜드 보호·AS 신뢰 장치. 우리도 브랜드명+AS 연락처 명기 섹션 필요.
8. **폴더폰 장착 사진**: 대형 기기 호환 어필. 우리도 실제 하중 테스트(예: 폴드/맥스 기종 실측)를 넣으면 차별화.

### 피해야 할 점
1. **절대·최상급 표현**: `흔들림 ZERO`, `완벽한 고정`, `어떤 환경에서도 변함없는`, `모두 압도적`, `초강력`, `모든 순간을 지배` — 입증자료 없이 사용 시 표시광고법(부당한 표시·광고) 위반 소지. 우리는 "흔들림 최소화", "자체 시험 기준 ○kg 유지" 등 한정·수치형으로.
2. **"방수·방습" 주장**: 금속 자석 링/접착 거치대에 방수 등급(IP) 없이 표기. 우리는 사용 금지.
3. **출처 없는 고객 불만 인용**: 말풍선 4개가 실제 후기인지 불명. 우리는 실제 리뷰 캡처 + 출처 표기, 또는 "일반적인 불편 사례" 명시.
4. **"맥세이프" 상표 무고지**: 전 섹션에서 "맥세이프"를 보통명사처럼 사용, "맥세이프 거치대"라는 제품명까지. Apple 상표 고지 없음. 우리는 "MagSafe 호환" 표현 + 하단 "MagSafe는 Apple Inc.의 상표입니다" 고지, Apple 로고 사용 금지(006 아이폰 사진에 Apple 로고 노출됨 — 피할 것).
5. **"정품 3M" 강조 시 품번 미기재**: 3M 명칭 사용은 3M 상표 가이드 이슈도 있음. 우리는 흡착식이므로 해당 없음. 대신 "에폭시/실리콘 흡착면" 등 소재는 실제 사양 확인 후 표기.
6. **주의사항과 본문의 모순**: `금속 표면 권장`(주의) vs `대시보드·욕실·헬스장 어디나`(본문), `내열 압도적` vs `고온 노출 피하세요`. 우리는 본문 주장과 주의사항을 교차 검토해 일관성 유지.
7. **타 채널 고지문 재사용**(014의 네이버 블로그 언급): 신뢰 저하. 우리는 쿠팡 전용 고지문 작성.
8. **POINT 02(각도)에 이미지 없음**: 핵심 기능인 각도 조절을 텍스트로만 처리. 우리는 관절별 가동 범위 도해 필수.
9. **KC·무게·하중·모델명 미표기**: 우리는 사양표에 포함.
10. **스톡 인물 사진**(얼굴 노출 여성 운전자): 라이선스 불명. 우리는 자체 촬영 또는 손만 노출.
