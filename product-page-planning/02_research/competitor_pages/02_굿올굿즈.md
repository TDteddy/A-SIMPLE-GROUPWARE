# 02 굿올굿즈 — 상세페이지 분석 리포트

- 상품명: 굿올굿즈 강력흡착 맥세이프 차량용 거치대 USB케이블, 클래식블랙
- 가격/판매단위: 3개 38,700원 (개당 약 12,900원), 리뷰 90건
- 분석 소스: 상세 이미지 001~011 (780px 폭, 총 11장, 005/006/010은 세로 긴 이미지로 분할 열람), 갤러리 이미지 gallery_001~010
- 비고: 우리 N001과 동일 물리 제품(다이얼 TIGHT/OPEN 링, 링 자석 헤드, 폴딩 암). 렌더 이미지 자체가 YZ(10번)와 동일한 제조사 원본 렌더를 공유함.
- 참고: 007/008/009(point 01~03)는 헤드카피만 있는 타이틀 이미지로, 뒤따라야 할 시연 이미지(아마 GIF/동영상 또는 별도 이미지)가 수집본에 없음. 이미지 순서(001 문제제기 → 002~004 체크포인트 → 005 리뷰 → 006 브랜드 히어로 → 007~009 포인트 → 010 케이블·스펙·디테일 → 011 패키지·주의)는 수집된 파일 번호 순서를 그대로 따름.

## 1. 제품 구조

### 고정 방식
- 진공 흡착 패드 + 다이얼(회전 링) 조임 방식. 베이스 측면 링에 `◀TIGHT ||||||||| OPEN ▶` 각인 (렌더·실사 공통 확인).
- 베이스 바닥에 흡착 패드 분리용 작은 탭(돌기) 있음 (렌더에서 베이스 좌하단에 보임).
- 동봉된 "흡착 보조패드"가 구성품에 포함되며, 매끄럽지 않은 면에는 보조패드 선부착 후 사용하라고 안내.

### 다이얼 조작 설명
- 설치 헤드카피: "5초 만에 끝내는 초간편 설치 / 붙이고 돌리면 끝!" (point 01, 텍스트만 있고 시연 이미지는 수집본에 없음).
- Caution 항목: "부착면에 대고 다이얼을 끝까지 돌려 진공 흡착이 되었는 지 확인 후 사용해 주세요."
- 즉 조작 설명은 "붙인다 → 다이얼을 끝까지 돌린다" 2단계. 해제(OPEN) 방향 설명은 상세에 별도 없음(각인으로만 표시).

### 암·관절·회전
- 헤드카피: "360도 회전 다관절 방식 / 한 손으로 원하는대로" (check point).
- 갤러리 009(도해 렌더): 하단 힌지 `180°`, 암 중간 축 `360°`, 상단 힌지 `180°` 화살표 표기.
- 가로/세로 전환: 상세 텍스트에 "가로/세로" 라는 단어는 등장하지 않음. 암 중간 축 360° 회전으로 헤드가 회전한다는 도해와, 갤러리 006(흰 원기둥 위 4대의 다양한 포즈 렌더 — 접힌 상태, 세워서 폰 세로 거치, 옆으로 눕힌 헤드, 암을 수평으로 뻗은 상태)로만 암시. 리뷰 02 사진에 폰이 가로로 거치된 실사가 있음("각도조절 자유롭게 잘 되고").
- 접힘: "W 62mm x H 40mm (접었을 때) / W 62mm x H 156mm (폈을 때)" — 접힌 상태 렌더(헤드가 베이스 위에 납작하게 포개짐) 다수.

### 헤드 형태
- 가운데가 뚫린 링(도넛) 형태의 자석 헤드. 헤드 전면 상단에 ▲ 정렬 마크, 측면에 `OPEN ⟷` 소형 각인(렌더상). 리뷰 실사(05, 06, 07)에서 헤드 링 전면에 삼각형 마크·소형 각인 확인.
- 헤드 뒤에 짧은 폴(암)이 힌지로 연결.

### 충전 여부
- 거치대 자체 무선충전 없음. 대신 "3 in 1 멀티헤드 USB 케이블"(USB-A → 라이트닝/마이크로USB/C-type, 120cm, 나일론·구리)을 번들로 제공해 "충전" 키워드를 흡수.

### 구성품
- Spec 표: "거치대 본품 1개, 흡착 보조패드, 메탈링, 설명서, 3 in 1 USB 충전케이블"
- Package 섹션: "맥세이프 거치대 1개 + 3in1 USB 충전케이블 1개"
- 리뷰 07 실사: 거치대 + 별도 검정 메탈 링(맥세이프 링) 확인 ("맥세이프 링도 여분으로 있고").
