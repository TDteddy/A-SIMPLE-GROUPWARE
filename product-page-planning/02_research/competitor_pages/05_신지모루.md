## 1. 제품 구조

| 항목 | 내용 (상세페이지 근거) |
|---|---|
| 고정 방식 | 진공 흡착(오목 챔버) + 회전식 다이얼 잠금 레버("M-다이얼 에어락"). 바닥은 PU 겔패드. 보조로 "흡착 강화 필름" 동봉. 접착제식 아님(“일회적인 접착형 패드가 아닌”). |
| 다이얼 조작 설명 방식 | 소비자 언어로 3단계로 분해: STEP 1 진공 흡착 구조(오목 챔버가 공기 배출) → STEP 2 정밀 밀착 패드(PU 겔패드 + 나노 드롭 코팅) → STEP 3 완벽 고정 잠금(20개 톱니 핀). 조작 자체는 사용가이드에서 "회전식 잠금 레버를 ‘딸깍’ 소리가 날 때까지 돌려 단단히 고정". 다이얼 상판에 자물쇠 열림/잠김 아이콘과 회전 방향 호(弧) 각인이 있음(seg_04, gallery_003). 분리 시 "흡착 패드 하단부의 손잡이(탭)를 들어 올려 진공 상태를 해제". |
| 암 길이·관절 수 | 단일 직선 암(약 5~6cm로 추정, 수치 표기 없음). 관절 2개: 베이스 힌지(180° 틸트) + 헤드 힌지(360° 회전). "Z 폴딩(바디+헤드)"으로 완전히 접힘. 암 자체는 길이 조절/신축 없음. |
| 회전 방식 | "360° 회전 헤드, 180° 틸트 바디". 힌지는 "마이크로컷 내부 삽입형 힌지" — 육각 볼트·너트가 양쪽에 삽입된 도해(seg_15). |
| 헤드 형태 | 링(도넛) 형태 자석 헤드, 중앙이 투명 창(비어 있음). 외주에 도트 패턴 미끄럼방지 표면. 네오디뮴 "3,000G". |
| 충전 여부 | 없음. 명시 문구: "*단순 맥세이프 방식의 자력 거치가 가능한 헤드로 별도의 무선 충전 기능은 제공하지 않습니다." |
| 구성품 | 제품 본체 1개, 흡착강화 필름 1개, 먼지 제거용 물티슈 1개, 메탈 플레이트(메탈 링) 1개. |
| 색상 | 블랙 단일. |
| 무게/크기 | 114g, 65*42(mm). |

## 8. 우리 기획안(N001)에 참고할 점 / 피해야 할 점

### 8-1. 다이얼/에어락 메커니즘을 소비자 언어로 푸는 방식 (가장 중요한 벤치마크)
- 기술어를 쓰되 **즉시 일상어로 번역**: "오목한 챔버가 공기를 제거해 진공 상태로 밀착시키고, 잠금장치로 한 번 더" — 원리(진공) + 보강(잠금)을 "한 번 더"라는 말로 이중 안전감 전달.
- **3단 STEP 구조**: 흡착 구조 → 패드 소재 → 잠금 톱니. 각 STEP은 한 문장 + 클로즈업 렌더 1장. 우리도 "① 밀착 ② 다이얼 압착 ③ 잠금 유지" 식 3단으로 쪼개면 이해도가 올라감.
- **조작 결과를 감각어로 고정**: "‘딸깍’ 소리가 날 때까지 돌려" — 사용자가 언제 멈춰야 하는지를 소리로 알려줌. 우리 제품도 멈춤 신호(딸깍/저항감/표시선)를 명확히 쓰면 좋음.
- **비교 렌더 1쌍**: "진공 챔버 적용" vs "낮은 지탱력 / 평평한 흡착 패드", "높은 밀착력" vs "불안정한 밀착력". 경쟁 제품을 명시하지 않고 구조 차이만 대비. 모방 가능하되 근거 없는 "압도적" 수식은 피할 것.
- 다이얼 상판에 **자물쇠 열림/잠김 아이콘 + 회전 방향 호** 각인 → 설명 없이도 조작법 전달. 우리 제품 사진에서도 이 각인/표시가 있다면 클로즈업 필수.
- 분리법을 반드시 세트로 제시: "잠금 레버를 먼저 풀고 → 패드 하단 탭(손잡이)을 들어 올려 진공 해제". 분리 안내 누락 시 패드 파손 클레임으로 이어지므로 필수.

### 8-2. 설치면 조건 표현 방식 (참고)
- 긍정 표현은 넓게("대시보드, 모니터, 앞 유리 원하는 곳 어디든"), 제한은 각주·주의사항에 **구체적 재질 열거**로: "일정 수준 이상의 심한 곡면, 가죽, 패브릭, 요철 있는 곳에는 흡착이 불안정할 수 있습니다", "부착 표면의 형태와 재질에 따라 부착력이 상이할 수 있습니다".
- 보조패드(흡착 강화 필름)는 "불안정한 표면이나 손상을 우려하실 경우 … 먼저 부착 후 사용을 권장" — 필수가 아니라 선택 권장으로 톤 다운. 우리도 보조패드를 "필요 시" 옵션으로 두면 "어디든" 메시지와 충돌하지 않음.
- 온도 한계를 숫자로(-20°C / 90°C) 명시 — 여름 대시보드 탈락 클레임 방어. 우리도 실측/제조사 스펙이 있으면 숫자로 넣는 것이 신뢰도 높음.

### 8-3. 참고할 구조적 장점
- 각 성능 주장 바로 아래 "*각주"로 한계를 붙이는 패턴(자력 → 무선충전 없음 / 힌지 → 태블릿은 실내 권장 / 패드 → 온도·세척). 과장과 면책을 같은 화면에 두어 표시광고법 리스크를 낮춤. 그대로 채택 권장.
- "무선 충전 기능은 제공하지 않습니다"를 자력 섹션에 명시 — 우리(N001)도 충전 없음이므로 동일 위치에 동일 수준으로 명시해야 "맥세이프" 키워드로 인한 충전 오인 방지.
- 사용 가이드를 실사 손 사진 5컷으로 — 렌더 중심 페이지에서 실사가 신뢰를 보강.
- 메탈 링 동봉으로 "모든 기종 호환" 확장. 우리도 동봉 시 같은 논리 사용 가능. 단, 메탈 링은 비(非)맥세이프 기기 전용임을 명확히.
- 폴더블·태블릿 거치 장면으로 힌지 강성 소구 — 우리 폴딩암의 "고개 숙임 없음"을 보여줄 때 동일 장면 구성 참고.
- 차량 외 일상 장면(책상·욕실·기내·주방) 5컷 → 흡착식의 장점인 "탈부착 자유"를 범용성으로 확장. 참고 가치 높음.
- 갤러리 썸네일 10장에서 메커니즘 스토리 완결(다이얼→진공→패드→톱니). 우리도 썸네일 2~6번을 메커니즘 컷으로 배치.

### 8-4. 피해야 할 점 / 리스크 표현
- **상표 표기**: "맥세이프"를 상품명·헤드카피에 일반명사처럼 사용("맥세이프 장착", "맥세이프 360도 …"). "Made for MagSafe/Apple" 로고·인증 표시는 없음. 각주 "단순 맥세이프 방식의 자력 거치" 정도의 완화만 있음. Apple 상표 가이드상 "MagSafe 호환(compatible with)" 명시 없이 제품명에 넣는 것은 리스크. 우리는 **"맥세이프 호환"** 또는 "MagSafe® 호환(MagSafe는 Apple Inc.의 상표)" 각주 권장. 렌더에 iPhone·iPad·삼성 폴더블 실루엣 사용도 상표/디자인 리스크 — 우리는 기기 브랜드 식별 요소 제거.
- **절대·최상급 표현**: "흔들림 ZERO", "흔들림 제로", "완벽한 진공 상태", "완벽 고정 잠금", "완벽거치", "미세한 흔들림조차 허락하지 않습니다", "압도적인 고정력", "극한의 주행 환경에서도", "차원이 다른 강력함" — 모두 시험 근거 없음. 표시광고법(부당한 표시·광고) 상 "완벽/제로/압도적" 류는 실증 요구 시 입증 불가. 우리는 "흔들림을 줄이는", "단단히", "안정적으로" 수준으로 톤 다운하거나 자체 시험(진동·하중) 결과를 첨부.
- **3,000G 자력**: 측정 조건 없는 수치. 우리도 자력 수치를 넣으려면 "표면 자속밀도 측정값(자사 측정, 측정 조건)" 각주 필수. 수치 없이 "N52 네오디뮴 ○개" 식 구조 사실 표기가 안전.
- **"모든 기종 호환 / 모든 차종 호환 / 모든 위치 부착"**: 전칭(全稱) 표현 뒤에 각주로 제한 → 모순 소지. 우리는 "대부분의 평평한 대시보드·유리" 등 한정어 사용.
- **"일반적인 접착 방식의 거치대 대비"** 비교 광고: 비교 대상·기준 불명확. 우리는 비교 시 "자사 기존 제품 대비" 또는 "일반 흡착판(잠금 없음) 구조와의 구조 비교"로 한정하고 성능 수치 비교는 피함.
- **"힌지가 헐거워질 수 있으나 불량이 아닙니다"**: 소비자분쟁해결기준상 품질보증 책임을 일방적으로 배제하는 문구로 읽힐 수 있음. 우리는 "장기간 사용 시 조임 조절이 필요할 수 있으며, A/S 문의 가능" 식으로 완화.
- "나노 드롭 코팅", "마이크로컷" 같은 **근거 없는 기술 용어**는 신뢰도는 높이지만 실증 요구 시 설명 불가. 우리는 실제 공정명이 아니면 사용 지양.
- KC/전기 인증 미표기는 비전기 제품이라 무방하나, 본체 수입자·A/S 정보가 상세페이지에 없음(물티슈 포장에만 존재). 우리는 전자상거래법 고시 항목(제조사/수입자, A/S 연락처)을 사양표에 포함.
- 정착(안정화) 대기 시간 안내가 없음 — 겔패드 흡착도 저온·먼지 상황에서 초기 밀착 시간이 필요하므로, 우리는 "부착 후 ○분 대기 권장" 또는 "부착 직후 강하게 당기지 말 것" 추가하면 차별화 겸 클레임 방어.

### 8-5. 한 줄 결론
신지모루는 "진공 챔버 + 다이얼 락 + PU 겔패드"라는 동일 원리를 3-STEP 렌더 스토리와 풍부한 면책 각주로 설득력 있게 풀었다. 우리는 이 **구조(히어로 → USP 그리드 → 메커니즘 3단 → 비교 렌더 → 내구/세척 → 자력 → 호환 → 힌지/가동범위 → 설치 장면 → 가이드 → 주의 → 사양)**를 차용하되, "완벽/제로/압도적/모든" 류 절대 표현과 근거 없는 수치를 걷어내고, MagSafe를 "호환" 표기로 바꾸며, 설치면 조건·보조패드·분리법·정착 대기 안내를 더 정직하게 쓰는 것으로 차별화해야 한다.
