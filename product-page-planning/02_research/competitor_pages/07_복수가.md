# 07 복수가 — 맥세이프 차량용 대쉬보드 에어락 360 무한진공흡착 핸드폰 거치대

- 판매처: 복수가 (쿠팡)
- 가격 / 리뷰: 5,920원 / 리뷰 138건
- 분석 소스: 상세 이미지 001~014 (각 780×1560, 14장) + 갤러리 썸네일 10장 (492×492)
- 분석 방법: 1300px 단위로 분할한 28개 세그먼트 + 갤러리 10장 전수 열람
- 비고: **우리 N001과 구조가 사실상 동일한 직접 경쟁 제품** (다이얼 압착 흡착 베이스 + 접이식 암 + 링 자석 헤드, 무충전)

## 1. 제품 구조

| 항목 | 내용 (상세페이지 표시 기준) |
|---|---|
| 고정 방식 | **돌려 잠그는 흡착(다이얼 압착) 베이스**. 베이스 외륜에 `◀ TIGHT IIIIIIII OPEN ▶` 각인, 흡착판 가장자리에 분리용 당김 탭(pull tab). 헤드카피 "돌려 잠그는 흡착 베이스 / 전원 연결 없이 수동으로 고정해요". 접착(3M) 방식 아님. |
| 흡착면 | "에폭시 처리 흡착면" — 물 세척 후 재사용 가능하다고 안내. |
| 보조 패드 | 구성품에 "흡착보조패드" 포함 (요철 설치면용 원형 패드로 추정, 용도 설명은 없음). |
| 암·관절 | 베이스 상단 힌지(1관절) + 암 중간 힌지(2관절) + 헤드 힌지(3관절)의 접이식 금속 암. 베이스 위 원판이 회전하는 구조로 보임(이미지 006의 주황 화살표). 암 길이 약 11~12cm(펼친 높이 15.6cm − 접은 높이 4cm 추정). |
| 회전 | "가로·세로 전환과 관절 각도 조절" — 헤드에 `OPEN` 표시와 회전 화살표 아이콘. 상품명에 "360"이 있으나 본문에는 각도 수치 없음. |
| 헤드 형태 | **링형(도넛형) 자석 헤드**, 중앙이 뚫려 있음. 헤드 상단에 `OPEN` + 회전 아이콘, 하단에 ▲ 마크 각인. |
| 자석 | "링형 네오디뮴 자석", "N52 · 공급사 표기 기준". |
| 충전 | 없음 (무충전). 본문에 "전원 연결 없이" 명시. |
| 구성품 | 거치대 본품 1개 + 맥세이프링 + 흡착보조패드 + 알콜솜(Wet 1 / Dry 2, 'Wipos' 브랜드) + 설명서(중국어 "真空磁吸支架" 표기). |
| 색상 | 검정 / 흰색, "각 1개 판매", "두 색상은 같은 규격입니다." |
| 크기 | 접었을 때 약 4cm, 일자로 펼쳤을 때 약 15.6cm (공급사 표기 기준). 무게·지름 미표기. |
| 사용 장면 | 차량 대시보드 / 책상 / 주방 조리대 (3개 장면). |

## 5. 설치 방법·주의사항 원문

**설치 절차 도해: 없음.** 다음 문장이 전부.

- 설치면 조건: `대시보드의 적합한 설치면에 거치해요` / `주방의 적합한 설치면에 거치해요` / `부착 전 설치면 상태 확인` / `케이스와 표면 조건에 따라 부착 상태가 달라질 수 있습니다.` / `실제 부착 상태는 설치면·환경에 따라 달라질 수 있습니다.`
- 보조패드: 구성품명 `흡착보조패드`만 표기. 사용 조건(요철면/가죽면 등)·부착 방법 설명 없음.
- 정착 대기(24시간 등): **없음** (흡착식이므로 해당 없음으로 처리한 듯).
- 고온: `흡착판의 내한·내열 설계 / 공급사 표기 범위 -40℃~90℃` — 직사광선 회피 등 행동 지침은 없음.
- 세척: `에폭시 처리 흡착면 / 깨끗한 물로 세척해 재사용해요` / `공급사 안내 기준 · 흡착면 세척` — 세제 사용 여부, 건조 방법 없음.
- 재사용: `재사용해요` 1회. 횟수 없음.
- 케이스: `맥세이프 호환 조건 확인` — 맥세이프 미지원 폰용 `맥세이프링` 동봉, 부착 위치 안내 없음.
- 탈착: `클립을 벌리지 않고 붙이고 떼어요` (집게형 대비 메시지). 당김 탭 사용법 미설명.
- 어린이·자석·카드 손상 경고: 없음.

## 8. 우리 기획안에 참고할 점 / 피해야 할 점

### 참고할 점
1. **구조 동일 경쟁자**: 다이얼 압착 + 접이식 암 + 링 헤드 조합을 5,920원에 판매 중. 우리 N001은 구조만으로는 차별화 불가 → 근거 있는 수치(하중 시험, 흡착면 소재, 자석 수량/자력 측정)와 실사 장면으로 차별화 필요.
2. **"공급사 표기 기준" 한정 표기 패턴**: 수치마다 출처 한정을 붙이는 방식은 표시광고법 리스크를 낮추는 실용적 장치. 다만 "시험 조건 자료 미제공"을 그대로 노출하는 것은 신뢰를 깎음 → 우리는 실제 시험(자체 또는 외부)을 하고 조건을 공개하는 것이 상위 포지션.
3. **섹션 템플릿의 일관성**: 헤드 2줄(강조 1단어) + 서브 1줄 + 기준 소자 + 렌더 1컷. 스크롤 리듬이 좋고 모바일 가독성 높음. 참고 가치 있음.
4. **접은 높이/펼친 높이 비교 도해**(013): 접이식 암 제품에 꼭 필요한 컷. 우리도 "접었을 때 4cm" 류 수치 제공 필요.
5. **세척 재사용 장면**(010): 흡착식의 핵심 차별 포인트(접착식 대비). 우리도 반드시 포함.
6. **"클립을 벌리지 않고"**(002): 집게형 거치대 대비 프레임 — 자석 거치대 공통 메시지로 유용.
7. **면책 카드**(014): "케이스와 표면 조건에 따라 부착 상태가 달라질 수 있습니다" — 우리도 동일 수준의 고지 필요.
8. **빈 영역(기회)**: 설치 순서 도해, 보조패드 사용 조건, 하중 수치, 실사 차량 사진, 브랜드/AS/KC 표기가 모두 없음 → 우리가 채우면 즉시 차별화.

### 피해야 할 점
1. **상품명의 "무한진공흡착", "에어락 360"**: 본문에 근거 없음. "무한"은 절대적 표현으로 표시광고법상 입증 불가 → 사용 금지.
2. **"N52"를 근거 없이 표기**: 등급만으로 자력이 보장되지 않음. 쓰려면 자석 개수·치수·실측 흡착력과 함께.
3. **"-40℃~90℃"를 "시험 조건 자료 미제공" 상태로 표기**: 수치 제시 후 근거 부재 고지는 모순. 우리는 시험 없이는 온도 수치 자체를 쓰지 않는 편이 안전.
4. **"맥세이프" 단독 표기**: Apple 상표 고지("MagSafe는 Apple Inc.의 상표입니다") 없이 "맥세이프링", "맥세이프 호환 조건" 사용. 우리는 "MagSafe 호환(Compatible)" + 상표 고지 문구 삽입.
5. **100% CG 렌더**: 실제 제품 마감·크기감 확인 불가 → 리뷰 불만 소지. 우리는 실사 비중 확보.
6. **구성품 설명서가 중국어 표지**: 품질 인상 저하. 우리는 한글 설명서 또는 한글 QR 안내.
7. **사양표·KC·원산지·제조사 부재**: 전안법/전자상거래법상 필수 고지(원산지, 제조자, AS 책임자) 누락 → 우리는 사양표 섹션 필수.
8. **주방/책상 장면 비중 과다**: 카테고리 "차량용"과의 괴리. 우리는 차량 장면 중심으로.
