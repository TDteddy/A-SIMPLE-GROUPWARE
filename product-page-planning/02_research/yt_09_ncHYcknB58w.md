## 체크리스트 (구성 요소)
1. **Above the fold는 기기별로 다름**(2:15~3:29): 내 화면 기준 설계는 흔한 실수. 개발자도구로 여러 폭(iPhone SE/12 Pro/Galaxy) 미리보기, 크로스브라우저(Chrome vs Safari) 테스트. "**스크롤이 많을수록 구매 가능성↓**".
2. 첫 화면 필수: **이미지·제목·가격·CTA**(3:29~4:03) + 깔끔한 내비게이션, 브레드크럼(4:03~4:34).
3. 메인 이미지 좌측 + 클릭 가능한 보조 이미지(4:34~5:15).
4. 제목에 실제 검색 키워드 반영(5:15~5:38).
5. **사회적 증거 = 리뷰 별점**, 별점 클릭 시 리뷰 섹션으로 점프(5:38~6:10). 화면: ★5, 1,397 reviews, 고객 사진 리뷰.
6. **짧고 강한 설명** — "한두 문장 이상 안 읽는다", 옆에 배지(수상·친환경)(6:10~6:46).
7. **가격을 장바구니 버튼 안에** 표시, 정가 취소선($48→$36)으로 할인 인지(6:46~7:15).
8. 옵션(색·사이즈), **눈에 띄는 별색 CTA 버튼**, 무료배송·쉬운 반품 신뢰신호(7:15~7:45). 버튼 바로 아래 **배송기간(3~5일)** + 신뢰 배지 3개, 접이식 드로어(상세설명·성분·반품정책)(7:45~8:32).
9. 아래쪽 섹션은 **고객 질문에 답하는 블록** — WHY(왜 써야 하나) / HOW(사용·세척 쉬움, 4단계 일러스트) / BRAND(지속가능성 카운터)(8:32~9:17).
10. 모바일(10:34~12:33): 상단 배치 주의, 캐러셀은 썸네일 대신 점(dots), 이미지 바로 아래 제목·가격만으로 첫 뷰포트 충분(예: Gymshark, Allbirds), **스티키 장바구니 버튼** 강력 추천, 가독 텍스트·이미지 스케일·자연스러운 흐름.
- 9:53~10:34: EverBee Store 광고(스폰서성 내용).
