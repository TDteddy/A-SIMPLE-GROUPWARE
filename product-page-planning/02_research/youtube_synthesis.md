## 1. 공통 원칙 (3편 이상 반복)
1. **고객은 다 읽지 않는다 / 첫 화면에서 판단** (02·05·07·09·10): 스크롤하다 멈칫한 순간, 1~3초, above the fold.
2. **첫 화면 = 고객 문제/약속을 담은 한 줄 + 그것과 짝지은 이미지** (03·05·06·07·10). 일반론 카피("누구에게나 좋아요") 금지.
3. **디자인보다 기획, 예쁨보다 구조** (01·02·03·04·06): 디자인은 기획 전달 도구.
4. **공감(문제) → 해결(제품) → 증명(근거) → 행동(CTA)** 흐름 (01·05·06·07·08·10). AIDA·PAS와 사실상 동일.
5. **사회적 증거·신뢰 요소는 필수** (01·05·07·08·09·10): 리뷰수·별점·판매량·인증·권위·Before-After.
6. **타깃을 좁게, 구체 상황으로** (03·05·08): "피곤한 사람"이 아니라 "육아로 지친 엄마".
7. **반론·불안을 먼저 꺼내 해소** (08·10·12·13): 고객 속마음을 문장으로 쓰고 증거로 답.
8. **명시적 CTA + 지금 살 이유** (05·07·08·10): 한정·얼리버드·특가, 페이지 끝에도 CTA.
9. **숫자·아이콘으로 핵심 요약** (05·06·08·09).
10. **테스트하고 개선** (03·07·10): 헤드라인 교체, A/B, 영상 추가.

## 2. 서로 다른 주장 (가이드에서 조건부로 처리)
- **길이**: 와디즈/스토리형(06·08)은 긴 서사 vs 쿠팡형(06)·Shopioso(09)·Cattoni 저가(10)는 짧게. → 결정 변수 = 플랫폼·가격·관여도(01: 저관여는 직관 영상 우선, 10: 저가일수록 짧게).
- **첫 화면 내용**: 01은 혜택 배너+사회적 증거 먼저, 07·05는 공감 헤드라인 먼저, 09는 상품·가격·CTA(구매 박스) 먼저. → 국내 오픈마켓은 구매 박스가 따로 있으니 상세 상단은 '공감 헤드라인+증거', 자사몰은 09 방식.
- **순서 고정 여부**: 08은 6단 순서 고수, 05·03은 순서 유연(신뢰를 위로 올려도 됨).
- **꾸밈**: 06(풀리오)은 고퀄 3D·포인트컬러 / 02는 색 배제·장식 최소. 공통분모 = 강조 수단은 1개만.
- **공감 vs 브랜드**: 07·01은 "인지도 높은 브랜드는 예외" 단서.
- **Need/Want 톤**(07): 문제해결형은 빨강·검정·긴급, 감성형은 아이보리·따뜻한 말 — 다른 영상엔 없는 축.

## 3. 상세페이지 기획 가이드 규칙 (22개)
1. 기획 착수 전 **타깃 1명**을 "상황·고민·망설이는 이유"까지 한 문단으로 쓴다. (03·05·08)
2. 상품 장점 목록에서 **필살기 1개**를 고르고 페이지 전체에서 강조·확대·반복한다. (04)
3. **비교 대상(흔한 경쟁품·기존 방식)**을 정해 "그건 ~해서 불편, 이건 ~" 대비 구도를 만든다. (04·13)
4. 첫 화면 헤드라인은 **고객의 고민/결과 약속 한 줄**, 기능명·일반론 금지. (05·07·10)
5. 헤드라인과 **같은 메시지의 이미지**(사용 장면·Before-After·문제 상황)를 짝짓는다. 제품 단독컷만으로 시작하지 않는다. (05·07)
6. 첫 화면에서 **WHAT(무엇)·WHY(왜 필요)·HOW(어떻게 얻나)**가 스크롤 없이 보이게 한다. (09·10)
7. 첫 화면 또는 바로 아래 **사회적 증거**(판매량·리뷰수·평점·1위)를 숫자로. (01·06·09)
8. 상단 직후 **핵심 3가지를 아이콘+숫자**로 요약한다(긴 글 읽지 않는 고객용). (05·09)
9. 본문은 **문제 제기 → 원인 → 해결(제품) → 증명** 순. 제품은 해결책으로 등장시킨다. (01·06)
10. 강점은 **Check 1/2/3** 식으로 하나씩, 각각 근거(시연·수치·인증)와 묶는다. (01·03)
11. **고객 속마음(반론)**을 그대로 문장으로 적고("떨어지지 않을까?"), 시연·후기로 답한다. 가능하면 초반에. (08·10·13)
12. 신뢰 근거는 **구체 수치·실험·인증·권위**로. "튼튼해요" 대신 "과속방지턱 주행 테스트". (03·08·12)
13. **색은 제품 색 + 포인트 컬러 1개**, 밑줄·박스 강조는 1~2곳만. (02·06)
14. **헤드라인은 짧게, 모바일 스크롤 중에도 읽히는 큰 글씨**, 텍스트-이미지 교차, 짧은 문단. (02·06·09)
15. 이미지는 **헤드라인을 안 읽어도 내용이 추측되게** 직관적으로. 움직임·기능은 GIF/짧은 영상. (01·02·12)
16. 혜택은 **가격·구성 비교 숫자**로 '이득'을 느끼게(정가 취소선, 동봉 구성). (06·08·09·12)
17. **지금 살 이유**(한정·런칭특가·얼리버드)를 상단·하단에 반복. 허위 한정 금지. (07·08)
18. 페이지 **마지막에 CTA**와 배송·교환·반품 신호를 다시 둔다. (09·10)
19. **플랫폼별 버전**: 쿠팡=짧고 큰 글씨·정보 위주 / 스마트스토어·자사몰=구조+포인트컬러+수치 / 와디즈=질문형 스토리. (06)
20. **가격·관여도에 따라 길이 조절**: 저가·저관여는 짧게+사용 장면 영상, 고관여는 반론·증거를 더. (01·10)
21. 제작 전 **카테고리 1위·리뷰 많은 상세 3~5개를 전체 캡처해 나란히** 놓고 구조 패턴을 추출한다(모방 X). (01·02·06)
22. 출시 후 **헤드라인·첫 이미지부터 A/B 교체**, 반응 데이터로 개선. (03·07·10)

## 4. 차량용 거치대 카테고리 인사이트 (11·12·13)
### 소비자가 보는 기준 (빈도순)
1. **고정력/낙하 여부** — 상하·좌우 흔들림, 과속방지턱·비포장, 주행 중 폰 낙하(11·12·13 모두 최대 관심).
2. **내 차 호환** — 송풍구 폭(약 5cm 이상 필요 사례), 가죽 대시보드, 설치 위치(중앙/하단), 차종(아반떼↔카니발).
3. **폰/케이스 호환** — 맥세이프 여부, 일반 케이스 시 낙하, 메탈플레이트·링 필요.
4. **한 손 거치·탈착**, 가로/세로 전환.
5. **시야·각도** — 화면 높이, 관절·회전, 유리 부착 시 시야 방해.
6. **설치 되돌림 가능성** — 양면테이프는 각도 실패해도 반품 불가.
7. 무선충전(유무·와트), 소재·디자인 고급감, 브랜드 인지도.
### 불만·실패 패턴
- 차종 미호환으로 반품(11에서 17개 중 약 5개 반품·1개 폐기), 송풍구 처짐·날개 파손, 메탈플레이트 탈락 낙하, 송풍구가 바람을 막음, 흡착 자국, 센서식 자동 개폐 오작동(13), 거치 전용이라 충전 불가(13).
### 방식별 비교 (영상 근거 종합)
| 방식 | 장점 | 단점 | 영상 평가 |
|---|---|---|---|
| **진공흡착(석션)** | 테이프 부담 없음·재부착, 케이스 무관 거치, 흔들림 적음, 롱암은 각도 자유 | 흡착 자국, 유리 부착 시 시야, 설치 각도 고려 필요 | 11: "가성비 최고·기본 거치대" 최종 추천 |
| **자석(맥세이프)** | 한 손 착탈, 가로 전환 쉬움, 깔끔한 디자인 | 맥세이프 케이스/철판 필요, 일반 케이스 낙하, 메탈플레이트 탈락 | 12·13 호평, 11은 케이스 제약 지적 |

| **대시보드(양면테이프)** | 위치 고정 | 각도 실패 시 되돌릴 수 없음·반품 불가 | 최하 평가 |

### 숏폼 광고 후킹·구성 (12 기준, 초 단위)
- 0~2초: 타깃 호명("○○ 거치대 찾는 분 끝까지") + 주행 중 '착' 붙는 실시연. 13도 말 없이 착 붙는 손 클로즈업 6초로 시작.
- 2~5초: 브랜드/패키지.
- 5~42초: **기능 1개 = 4~7초**, 한 줄 멘트 + 그 기능만 보이는 클로즈업(구성 2종 동봉 → 케이스 호환 링 → 15W 충전 83% 화면 → 아연합금 → 3관절·360° → 송풍구 조임).
- 47~56초: **최대 불안(낙하)**을 손으로 흔들기 → 실제 주행으로 증명 → 로고 엔딩.
- 리뷰형(11) 후킹: 손실회피("잘못 사면 돈 주고 쓰레기 산다") + 17개 물량. 실패 장면(폰 떨어짐, 쓰레기통)이 신뢰를 만든다.
- 상세페이지 전환 시사점: 상단 GIF는 '한 손 착 붙임 + 방지턱 주행 고정' 2컷이 최우선, 이어 "내 차에 맞나?" 호환 체크(설치 위치·차종 사진), 케이스 호환, 설치/제거 자국.
