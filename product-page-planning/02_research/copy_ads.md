## (A) 카피 공식 카드

| 공식 | 구조 | 언제 쓰나 | 상세페이지 섹션 대응 | 예문 [작성 예시] | 출처 |
|---|---|---|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | 범용. 광고 1컷, 상세 전체 흐름 둘 다 가능. 인지 단계가 낮은 고객용 | 히어로(A) → 핵심 기능(I) → 사용 장면·후기(D) → 구매·혜택 배너(A) | "과속방지턱에서 폰 날아간 적 있죠?(A) 차량용 맥세이프, 자력부터 다릅니다(I). 매일 출근길 3초 탈착(D). 오늘 출고 + 1년 A/S(A)" | [S1][S2] 기원은 E. St. Elmo Lewis로 흔히 알려졌지만 다른 설(A. F. Sheldon)도 있음 |
| **PAS** | Problem → Agitate → Solve | 불편이 뚜렷한 문제 해결형 제품. 숏폼 광고, 상세 첫 화면. 문제는 하나만, 짧게 | 문제 제기 컷 → 불편 확대(사고·짜증 장면) → 제품 등장 | "송풍구 거치대, 여름엔 처지고 겨울엔 폰이 뜨겁죠(P). 내비를 놓치면 차선까지 놓칩니다(A). 쿨링팬 맥세이프 거치대로 붙이고, 식히고, 충전하세요(S)" | [S3][S4] |
| **PASTOR** | Problem → Amplify → Story → Transformation(+Testimonial) → Offer → Response | 긴 상세페이지·랜딩. | **BAB** | Before → After → Bridge | 변화가 눈에 보이는 제품. 비포/애프터 이미지나 영상. PAS보다 긍정 톤 | 비포 컷 → 애프터 컷 → "이 제품이 그 사이를 잇는다" | "Before: 컵홀더에 폰 던져두고 내비 곁눈질 / After: 눈높이에 딱, 충전까지 / Bridge: 맥세이프 대시보드 거치대" | [S7][S8] |
| **FAB** | Feature → Advantage → Benefit | 스펙 비교 섹션, 기능 아이콘 영역. 기능 나열을 고객 이점으로 바꿀 때 | 스펙 카드마다 "그래서 뭐가 좋은데?"를 붙임 | "N52 자석 36개(F) → 일반 자석보다 접지력이 높다(A) → 비포장 캠핑장 길에서도 폰을 다시 잡을 일이 없다(B)" | [S9][S10] |
| **4U** | Useful · Urgent · Unique · Ultra-specific 점검표 | 헤드라인 검수용(작성 공식이라기보다 채점표). 광고 제목, 썸네일 문구 | 히어로 헤드라인, 광고 1줄 카피 | "11월 출고분만: 3초 탈착 + 15W 충전 거치대, 무상 교체 1년" | [S11][S12] 출처는 Bly/Masterson(Mark Ford) 등으로 갈림 |

| **4P** | Picture → Promise → Prove → Push (Promise를 먼저 두는 변형도 있음) | 장면을 먼저 그려야 하는 생활용품. 증거가 있는 제품 | 사용 장면 이미지 → 약속 문구 → 테스트·인증·후기 → CTA | "새벽 고속도로, 한 손으로 '탁'(Picture). 붙이는 순간 고정, 충전 시작(Promise). 요철 구간 주행 영상, KC 인증(Prove). 오늘 주문 시 내일 도착(Push)" | [S15][S16] 헨리 호크 시니어 기원설은 1차 확인 못 함 |
| **Star-Story-Solution** | Star(주인공) → Story(그의 문제·여정) → Solution(제품) | 브랜드 스토리, 창업자·고객 사례, 롱폼 세일즈페이지 | 고객 사례 섹션, 브랜드 소개 | "영업 12년 차 김 과장(Star). 하루 6시간 운전, 거치대만 4번 바꿨다(Story). 다섯 번째가 마지막이었던 이유(Solution)" | [S17][S7] 단계 정의는 2차 자료 기준 |
| **JTBD 기반 카피** | "~할 때(상황), ~하고 싶다(동기), 그래야 ~할 수 있다(결과)". 기능적·감정적·사회적 Job 3층 | 히어로 카피를 "제품 설명"이 아니라 "고객의 Job"으로 바꿀 때. 세그먼트별 광고 소재 | 히어로 = 가장 중요한 Job 1개. 아래 섹션 = 보조 Job | "출근길 아이를 내려주고 바로 내비를 켤 때 → 한 손으로 3초 → 지각 걱정 없이 출발" | [S18][S19][S20] |
| **Schwartz 인지 5단계** | Unaware → Problem-aware → Solution-aware → Product-aware → Most aware | 광고 타깃·지면별로 헤드라인 유형을 고를 때(아래 표 참고) | 광고 소재 vs 상세 첫 화면 메시지를 고객 인지 단계에 맞춤 | 아래 표 | [S21][S22][S23] 『Breakthrough Advertising』(1966년 출간설이 다수) |

### Schwartz 인지 단계별 헤드라인 선택 [작성 예시]

| 단계 | 고객 상태 | 헤드라인 전략 | 차량 거치대 예시 [작성 예시] | 주 지면 |
|---|---|---|---|---|
| Unaware | 문제를 모름 | 스토리·호기심·정체성으로 시작. 제품명 숨김 | "운전 중 폰을 본 시간, 하루 평균 몇 초일까?" | 숏폼 브랜딩 |
| Problem-aware | 불편은 알지만 해결책 모름 | 문제를 고객 언어로 정확히 명명하고 공감 | "과속방지턱마다 떨어지는 거치대, 이제 그만" | Meta/TikTok 콜드 타깃 |
| Solution-aware | "자석 거치대" 같은 해결책은 앎 | 차별 메커니즘 제시 | "자석만 세다고 끝? 코일 정렬이 안 맞으면 충전이 멈춥니다" | 검색광고, 비교 콘텐츠 |
| Product-aware | 우리 제품을 앎, 망설임 | 증거·비교·리스크 제거 | "1만 리뷰가 말하는 '안 떨어짐', 30일 무료 반품" | 리타깃팅 |
| Most aware | 살 생각 있음 | 가격·혜택·마감 | "오늘까지 2+1, 내일 도착" | 장바구니 리타깃, 쿠폰 |

### 한국 실무 공식(숫자·대비·질문·고객 언어 인용·"~대신 ~"·"~하지 마세요")

국내 자료에서 확인된 원칙: 반복되는 리뷰 표현이 헤드라인 후보, 브랜드 언어보다 고객 언어 우선[S24], 헤드카피는 직관적이고 호기심을 일으켜 스크롤을 유도하고 리뷰 표현을 녹이면 좋다[S25], 기능 문구마다 "그래서 고객에게 어떤 이점?"으로 바꾸기[S25], 숫자형·질문형 틀[S26][S27]. "숫자 7이 클릭률이 가장 높다"는 말은 출처가 불분명한 **[주장]**입니다[S27].

| 유형 | 구조 | 예문 [작성 예시] |
|---|---|---|
| 숫자형 | 구체 수치 + 결과 | "3초 탈착, 15W 충전, 360° 회전" |
| 대비형 | A vs B / 전 vs 후 | "송풍구는 처지고, 흡착은 녹고. 그래서 자석+클립" |
| 질문형 | 고객 상황을 묻는 질문 | "좌회전할 때마다 폰 잡으세요?" |
| 고객 언어 인용형 | "후기 원문" + 출처 표시 | "'비포장 캠핑장 길에서도 안 떨어졌어요' – 실제 구매자 후기" |
| ~대신 ~ | 기존 대안 부정 + 대체 | "흡착판 대신 자석으로, 여름에도 그대로" |
| ~하지 마세요 | 금지·경고형 | "거치대, 자력만 보고 사지 마세요" |
| 실수 지적형 | "이 N가지 실수" | "차량용 무선충전 거치대 살 때 하는 실수 3가지" |
| 조건 한정형 | "~라면" | "아이폰 12 이후 쓰는 분이라면 케이스부터 확인하세요" |

## (D) 광고 크리에이티브 패턴

### D-1. 후킹 3초 원칙

- TikTok 크리에이티브 가이드: 첫 3초에 콘텐츠 제안(핵심)을 보여주고 6초 안에 후킹을 끝내라[S57][S58]
- "성공한 TikTok 광고의 63%가 첫 3초에 핵심 메시지를 전달" **[주장]**(2차 블로그가 TikTok 출처라고 인용, 원문 미확인). 60%·71% 등 서로 다른 수치가 돌고 있음[S57][S59]
- "첫 3초를 본 사람의 65%가 10초 이상 시청" **[주장]**. "85%가 무음 시청" **[주장]**[S60]
- Meta 관련: 첫 3초에 메시지와 브랜드를 앞에 배치, 첫 프레임부터 자막, 로고 애니메이션·느린 페이드·"안녕하세요 저는~" 오프닝 금지. "첫 3초에 브랜드 노출 시 브랜드 관심 44%↑" **[주장]**[S61][S62]
- 테스트 방법: 본문과 CTA는 고정하고 첫 3초만 바꿔 컨셉당 3~5개 훅 변형을 만든다[S60]
- 국내: 초반 2~5초 안에 후킹. 시청자는 광고라고 인지하는 순간 넘긴다. 틱톡은 다듬은 광고보다 사용자가 찍은 듯한 영상이 반응이 높다[S63][S64]

## (부록) 리뷰 마이닝 → 카피 전환 방법

### 원칙 (Copyhackers / Joanna Wiebe 등)
- 카피는 머릿속이 아니라 리뷰 데이터가 쓴다. 고객이 좋아하는 것, 싫어하는 것, 걱정하는 것, 기대·동기를 수집[S72][S73]
- 원문 표현을 요약 없이 표에 그대로 붙인다[S74]
- 리뷰를 읽기 전에 타깃·맥락부터 정의[S73]
- 대표 사례: 재활센터 헤드라인 "If you think you need rehab, you do"를 책 리뷰에서 가져옴. "다듬은 버전보다 400% 높았다" **[주장]**(2차 뉴스레터, 원문 미확인)[S74]
- 단일 리뷰 복붙보다 **반복되는 표현·주제·불안**을 찾는 것이 핵심이라는 반론도 있음[S74]
- 국내: 자사+경쟁사 리뷰를 모두 보고 만족/불만 포인트를 정리해 상품에 맞는 것만 반영. 광고 같은 리뷰만 있으면 신뢰가 떨어지니 약한 불만이 섞인 현실적 리뷰 풀이 자연스러움[S25]

### 6단계 실행 절차 (조사 내용 종합 + [작성 예시])
1. **수집**: 자사 + 경쟁사(신지모루·ESR·앵커 등) 쿠팡·네이버 리뷰, 특히 별점 1~3점(불만 = 경쟁사 약점), 4~5점(구매 이유)
2. **태깅**: 표에 원문 그대로 붙이고 [문제/욕구/불안/결과/비교대상/사용상황] 태그
3. **빈도 집계**: 반복 표현 상위 10개 추출(예: "안 떨어짐", "뜨거움", "송풍구 처짐", "한 손으로")
4. **인지 단계 배치**: 문제 표현 → Problem-aware 광고 훅, 비교 표현 → Solution-aware, 결과 표현 → Product-aware 리타깃팅
5. **헤드라인 변환 템플릿**
   - 불만 리뷰 → "~하지 마세요"/"~대신 ~": "여름에 흡착판이 녹아 떨어졌어요" → "흡착판 대신 자석+클립, 여름에도 그대로"
   - 결과 리뷰 → 인용형: "비포장 캠핑장 길에서도 안 떨어졌어요" → 헤드라인에 그대로 + "실구매자 후기" 표시
   - 상황 리뷰 → JTBD형: "아이 등원시키고 바로 내비 켤 때 좋아요" → "등원길, 한 손으로 3초"
   - 비교 리뷰 → 대비형: "예전 거 송풍구 날개 처졌는데 이건 괜찮아요" → "송풍구 처짐, 무게가 아니라 구조 문제였습니다"
6. **검증**: 4U 점수로 1차 거르고, 첫 3초 훅만 바꾼 A/B 테스트로 최종 선택(앞의 D-1 방법)

주의: 리뷰 원문을 광고에 인용할 때는 실제 구매자 리뷰임을 표시하고, 표시광고법·추천보증 심사지침(경제적 대가 표시) 준수 여부를 법무 확인 필요(이번 검색 범위 밖, 일반 주의사항).
