# 실제 상세페이지 문장 표본 — 검증과 정리 (2026-11-11)

> 원자료: 광고주 제공 `노르벡 13섹션 원문 문구집`(xlsx). 쿠팡 11개 상품의 상세페이지 이미지 문구를 13영역으로 분류해 전사한 것. 180블록, 본문 약 2만 4천 자.
> 이 문서: 원자료를 검증하고, 카피를 쓸 때 참고할 수 있게 **영역별 문형과 관찰**로 정리한 것. 원문 전체는 싣지 않고 짧은 발췌만 실었다(타사 저작물이므로 xlsx는 저장소에 넣지 않았다).
> 성격: **관행의 표본이지 모범 답안이 아니다.** 강제 규칙이 아니라 참고다.

## 1. 검증 결과

### 1-2. 확인하지 못한 것
- **원본 이미지와의 대조는 하지 못했다.** 이미지는 수집자 PC에 있고 쿠팡은 이 환경에서 열리지 않는다. 전사가 글자 단위로 맞는지는 자료의 자체 표기를 믿는 수밖에 없다. 작은 글씨와 숫자(고시, 주의사항)는 자료 스스로 재검수를 권한다.
- **'카테고리 상위권'이라는 선정 근거**를 확인하지 못했다. 순위 증거는 자료에서 제외돼 있다. 수상 문구가 원문에 있는 것은 제습제 하나다.
- 판매자의 효능·수치·인증 주장은 자료도 검증하지 않았다고 밝힌다.

### 1-3. 판정
**카피 참고용 표본으로 쓸 수 있다.** 분류 기준이 일관되고, 원문과 메모가 분리돼 있고, 한계가 스스로 적혀 있다. 숫자와 고시 문구를 그대로 가져다 쓰는 용도로는 쓰지 않는다.

## 2. 표본의 성격 — 읽기 전에 알 것
| 구분 | 상품 | 블록 |
|---|---|---|
| 쿠팡 자체 브랜드(코멧·탐사) | 필터 샤워기 25, 배변패드 16, 이불 압축팩 16, 고양이 스크래쳐 16 | 73 |
| 대형 제조사 | 물먹는하마 제습제 28, 크리넥스 키친타올 8(부분) | 36 |
| 중소 판매자 | 루아즈 자이로볼 18, 올릭 싱크대 휴지통 11, 생활도감 혀클리너 20, 기본에 세정티슈 11(부분), 맥스틸 충전기 10(부분) | 70 |

- **쿠팡 자체 브랜드가 40%다.** 같은 틀(`LOWER PRICE / BEST VALUE`, `한눈에 보는 … LINE UP`, 패키지 리뉴얼 안내, 브랜드 문구)이 네 번 반복된다. 표본 전체의 인상이 이 틀에 끌려간다.
- **거치대·차량 액세서리는 없다.** 문제해결형 구성이 비슷한 생활용품이다. 문장의 결과 영역별 관행은 참고가 되지만 카테고리 어휘는 여기서 얻을 수 없다.
- **영역별 편차가 크다.** 셀링포인트 47, 비교 24, 제품정보 23, Q&A 21, 고시 16, 설계 13, 타겟 12, 메인 10, 브랜드 6, **위험소구 4, 공신력 2, 정품 인증 1.** 위험소구와 공신력은 표본이라 하기 어렵다.
- **후기 영역 표본은 없다.** 플랫폼 구매 리뷰는 수집에서 제외됐고, 판매자가 상세 안에 후기를 재구성해 넣은 사례가 11개 상품에 하나도 없다.
- 가장 공들여 쓴 페이지는 **혀클리너(생활도감)와 휴지통(올릭)**이다. 둘 다 중소 판매자다. 자체 브랜드 페이지는 짧고 틀에 박혀 있다. 잘 팔리는 것과 잘 쓴 것은 같지 않다.

## 3. 영역별 실제 문형

### 02 메인
- 기본형은 **제품명 + 효익 한 줄 + 라벨 3개**다. 10개 중 9개가 메인 블록에 품목명을 넣었다. 품목 없이 효익만 쓴 것은 자이로볼 하나(`하루 1분 투자로 손목 근육 강화`)이고, 그것도 바로 아래에 영문 품목명이 있다.
- 효익 한 줄: `간편한 압축팩으로 여유로워지는 수납 공간!` / `제습엔 언제나! 물먹는하마` / `도톰한 입체 흡수층으로 매일 깨끗하게` / `초고속 듀얼 충전으로 편안하게 스마트폰 충전 #완전정복`
- 라벨 3개: `고흡수 SAP 함유 / 엠보싱 처리 / 위생 방수막`, `습기 제거 / 냄새 방지 / 곰팡이 방지`. 전부 **명사형 기능명**이다.
- 메인에서 본문 문장을 쓴 것은 세정티슈 하나: `물과 세제 없이 닦기만 하면 손쉽게 깨끗해져요.`

### 03 타겟·사용 상황
- **`이런 분들께 / 이럴 때 추천` 체크리스트가 표준이다**(샤워기, 배변패드, 휴지통, 키친타올). 항목은 "~하고 싶은 분", "~할 때"로 끝나는 구.
  - `요리 동선 줄이고 싶은 분 / 깔끔한 주방을 유지하고 싶은 분 / 원룸·소형 주방 공간 활용이 필요한 분`
  - `패드를 자주 교체할 때 / 얇지만 강력한 흡수력을 원하실 때`
- 질문으로 여는 형: `매일 사용하는 배변패드 바로바로 갈아주기에는 비용이 부담스러우셨나요?`, `양치질을 깨끗하게 하는데도, 입 속이 텁텁하거나 입냄새가 사라지지 않나요?`
- 쓰는 장소 나열: `옷장, 서랍장, 신발장 등 닫혀서 공기의 순환이 어려운 곳에는…`, `화장실, 방안, 거실 등 다양한 정리함으로`
- 쓰는 장면 여덟 가지를 번호로(키친타올): `01 야채나 과일의 물기를 제거할 때 … 08 식재료를 신선하게 보관할 때`

### 04 위험소구 (4블록뿐)
- `우리가 매일 쓰는 '수돗물' 과연 안심할 수 있을까요?`(샤워기)만 불안을 정면으로 건드린다. 이어지는 "세균이 피부로 쉽게 흡수됩니다"는 근거 없는 건강 주장이다. **따라 쓰지 않는다.**
- 나머지 셋은 **재산 손실**이다: 곰팡이로 옷이 상한다(`추가적으로 발생하는 지출을 예방해 줍니다!`), 소파·벽지 뜯김.
- 읽히는 것: 상위 생활용품 상세에서 위험소구는 **드물고 약하다.** 대부분은 불편을 타겟·셀링포인트 안에서 말하고 넘어간다.

### 05 공신력 (1개 상품)
- 플랫폼 수상뿐이다: `생활용품 습기제거제 부문 4연속 베스트셀링 선정 상품` + **집계 기간과 선정 기준을 각주로** 붙였다.
- 제품 안의 시험 근거는 셀링포인트 안에 각주로 들어간다(아래 07).

### 06 설계
- **층·단계를 화살표로 나열**: `부직포 → 펄프 → 고흡수성수지(SAP) → 펄프 → 펄프 → 방수 폴리에틸렌 필름`, `1차 필터: 세디멘트필터 / 2차 필터: 볼 필터 / 3차 필터: 칼슘볼 필터`
- **구조 → 그래서**: `2.8cm 10개의 스크래퍼가 각기 다른 길이로 설계되어 굴곡진 혀에 잘 밀착되기 때문에, 혀에 가해지는 압력을 효과적으로 분산시킵니다.`
- 두 줄 대비 제목: `05 바람은 새지 않게, 압축은 강력하게 / 2중 잠금으로 강력한 압축`
- 자부심을 건네는 제목은 표본에 없다. 전부 기능 설명이다.

### 07 셀링포인트 (47블록, 가장 두꺼움)
- **`POINT 01` 번호 라벨**을 11개 중 8개 상품이 쓴다. 제목은 대부분 **명사구**다: `무타공 초간편 설치`, `편리한 양방향 오픈`, `90일 동안 지속되는 제습력`, `높은 내구성 (튼튼한 골판지 소재)`.
- 요약 목록을 먼저 보여 주고 하나씩 푼다: `주요 특징: 손쉬운 설치 / 절수효과 / 3단계 필터링 / …`, `핵심 POINT! 01 … 07 …`
- **`~하면 끝` 문형이 실제로 많다**: `밀고 돌리면 끝`, `걸기만 하면 끝!`, `열고 쏙- 넣고 닫으면 정리 끝!`, `조립시켜 주면 끝~`
- **숫자 세 개 나란히**: `설치 3초 / 공간 차지 0 / 동선 낭비 0`
- **동작 순서를 화살표로**: `요리 → 손질 → 바로 버리기 한 번에 끝납니다.`
- **불편 나열 → 그래서 필요한 건**(휴지통 BEFORE/AFTER): `음식물 쓰레기 버릴 때마다 허리 숙이기 불편하셨죠? / 봉투를 문고리에 걸어두기엔 보기 싫고 지저분하고··· / 바닥에 두면 공간 차지 + 위생 걱정 / 그래서 필요한 건 공간은 차지하지 않으면서, 바로 옆에 있는 휴지통`
- **의태어**: `한 손에 쏙-`, `기름기도 쏙! 물기도 쏙쏙!`, `좁은 공간에도 쏙쏙!`, `캣닢가루를 솔솔 뿌려보세요`, `언제나 보송보송함을`
- **TIP 한 줄**: `TIP 다시 새것처럼! 스크래쳐 앞면을 모두 사용하셨다면 뒤집어서 사용해 보세요.`
- **수치 주장에는 각주**: `90일* 동안 강력하게 제거합니다. *옷장용에 한함/국가공인기관 제습력 테스트 결과 기준(25℃, 상대습도 80%). 해당 제습력은 사용자 환경에 따라 그 결과가 달라질 수 있습니다.`

### 08 비교·선택
- **고르는 기준을 먼저 가르친다**: `습기제거제 구매 전 꼭 확인하세요! CHECK 01 비드 타입의 염화칼슘인지 확인하세요!`, 혀클리너 `꼼꼼하게 살펴보아야 할 3가지: 1 헤드 크기 / 2 확실한 백태 제거 / 3 편안한 손잡이`. 기준을 세운 뒤 "우리는 그 기준을 채운다"로 잇는다.
- **일반 제품과 구조로 견준다**: `일반 샤워기: 살수판 구멍의 크기가 커서… / 코멧 샤워기: 살수판의 미세한 구멍을 통해…` 타사 실명은 없다.
- 공감 질문으로 기준을 연다: `양치 중에 혀를 닦다가 헛구역질 하신 경험이 있으신가요?`
- 자사 라인업 비교(`한눈에 보는 … LINE UP`, `초심자용 VS 숙련자용`)가 이 영역의 절반을 차지한다. 우리에게는 해당 없다.
- 비교 수치에는 각주: `흡수력 1.5배 UP* *자사 안심 키친타월 대비`

### 09 제품정보·사용법
- **`STEP 01~` 번호 + "~해주세요"**: `01 고무링을 연결부위에 끼워주세요. … 04 샤워기 조립 완성!`
- 제목에 쉬움을 넣는다: `초간단 설치방법`, `누구나 손쉬운 세디멘트 필터 교체 방법`
- 괄호로 주의를 끼워 넣는다: `(무리한 힘은 샤워기 파손으로 이루어지니 주의해주세요.)`
- 교체·관리 시점을 눈으로 알게 한다: `화살표(▶) 표시선까지 물이 차오르면 새것으로 교환하세요.`, `사용 전 필터 / 1~2개월 사용 / 2~3개월 사용`
- 구매 전에 영상을 보게 한다: `구매 전 사용방법 영상을 확인해 주세요`(자이로볼)

### 11 Q&A·주의
- **질문은 고객의 말투, 증상 그대로**: `Q. 자이로볼 작동이 안돼요.`, `Q. 헛도는 느낌이 들어요.`, `Q. 솜이불을 압축한 후에 이불 솜의 복원이 잘 안돼요.`, `Q. 가죽 시트인데 닦아도 되나요?`
- **고객의 말을 받아 되묻는 제목**: `샤워기에서 물이 샌다구요? 설치 전 반드시 고무패킹의 결합 여부를 확인해주세요!`, `첫 사용시 물줄기가 삐뚤게 나간다구요?`
- **"불량이 아닙니다" + 원인 + 조치**: `샤워기에서 물이 샐 경우 불량이 아닙니다. 고무패킹이 바닥면과 빈틈없이 평평하게 밀착되도록 결합해주세요.`
- **한계를 먼저 말한다**: `Q 완전한 진공 상태로 밀폐되나요? A 본 제품은 진공 용도가 아닌 압축 용도이기 때문에 완전한 밀폐가 되지 않습니다.` / `자이로볼은 충분한 연습이 필요합니다. 바로 정상적으로 작동하는 경우는 매우 드문 일이므로…` / `고가의 천연 가죽 및 세무 가죽 시트 등에 사용하지 마세요.`
- 주의사항은 `~하십시오` 또는 `~하세요`의 번호 목록. 마케팅 문장과 체가 다르다.

### 12 브랜드
- 한두 줄이다. `프리미엄 제품을 프리미엄 없는 가격으로`(탐사), `"Better habits, Better life"를 실현하기 위해 최선을 다할 것을 약속 드립니다.`(생활도감)

## 4. 가로질러 보이는 것

### 4-1. 종결 체 — 실제로는 섞어 쓴다
마케팅 영역(02~09, 12)에서 센 종결 수.

| 상품 | ~니다 | ~어요/해요 | ~세요 | 비고 |
|---|---|---|---|---|
| 혀클리너 | 28 | 0 | 3 | 합쇼체 일관 |
| 충전기 | 14 | 0 | 0 | 합쇼체 일관 |
| 스크래쳐 | 12 | 0 | 3 | 합쇼체 |
| 자이로볼 | 12 | 0 | 6 | 합쇼체 |
| 샤워기 | 17 | 3 | 8 | 섞임 |
| 제습제 | 13 | 1 | 16 | 섞임. `유지해 줍니다!`와 `느낄 수 있어요!`가 한 문단에 |
| 압축팩 | 8 | 2 | 10 | 섞임. `줄여줍니다`와 `막아줘요` |
| 배변패드 | 8 | 1 | 1 | 합쇼체 |
| 휴지통 | 4 | 0 | 4 | 합쇼체 + 명사 종결 |
| 세정티슈 | 3 | 2 | 3 | 섞임 |
| 키친타올 | 0 | 5 | 1 | **해요체 일관** |

- **합쇼체가 다수**이고, 해요체로 일관한 것은 크리넥스 하나다. 세 상품은 한 페이지 안에서 섞는다.
- "합쇼체든 해요체든 한 안 안에서 통일"이라는 우리 지침은 실제 관행보다 **엄격한 쪽**이다. 그대로 두어도 손해가 없다.
- 권유는 체와 상관없이 **`~하세요 / ~해보세요`**가 가장 흔하다. 느낌표가 자주 붙는다.

### 4-2. 제목은 명사구, 본문은 서술
셀링포인트·설계 제목은 거의 다 명사구다. 서술문 제목은 질문형일 때만 나온다. 우리 가이드의 "KEY 명사형 기본"과 같다.

### 4-3. 질문형 제목 일곱 개의 쓰임
- 타겟을 여는 질문 2(`부담스러우셨나요?`, `과연 안심할 수 있을까요?`)
- 이유를 묻는 질문 2(`왜 필요할까요?`, `왜 사용해야 할까요?`)
- **고객의 말을 되받는 질문 3**(`궁금하시다구요?`, `삐뚤게 나간다구요?`, `물이 샌다구요?`)
세 번째 형은 유튜브 자료에 없던 것이다. 고객이 실제로 하는 불만을 제목으로 올리고 곧바로 원인과 조치를 말한다.

### 4-4. 흔한 수식어는 정말 흔하다
180블록에서 `강력` 17회, `안심` 17회, `깔끔` 13회, `편리` 9회, `간편` 9회, `뛰어난` 7회. `뛰어난 내구성을 자랑합니다`, `일상의 편리함을 더해보세요` 같은 문장이 상위 상품 페이지에 그대로 있다.
- **제품명을 바꿔도 성립하는 문장이 실제 상세의 다수다.** 유튜브 카드의 치환 테스트로 보면 대부분 떨어진다.
- 그래서 이 표본은 "이렇게 써야 팔린다"가 아니라 **"다들 이렇게 쓴다"**를 보여 준다. 다들 이렇게 쓰는 곳에서 장면과 고객의 말로 쓰면 달라 보인다는 근거로 읽는 편이 맞다.

### 4-5. 주장에는 각주가 붙는다
`*`가 19번, `※`가 12번 나온다. 기간·수치·비교 우위에는 조건(기준 제품, 시험 조건, "사용자 환경에 따라 달라질 수 있습니다")을 작은 글씨로 단다. 센 문장과 조건을 **한 화면에 같이** 두는 방식이다.

### 4-6. 영문 장식 라벨
`CONVENIENT COMPRESSION PACK`, `Features`, `HOW TO USE`, `CHECK POINT`, `LINE UP`, `KEY POINT`. 영역을 나누는 표지로 쓴다. 뜻을 전하는 글이 아니다.

## 5. 지금까지의 지침·참고 카드와 대조

### 표본이 뒷받침하는 것
| 우리 쪽 | 표본의 근거 |
|---|---|
| 메인 아이콘 라벨 3개 | 메인의 표준 구성. 명사형 기능명 |
| `돌려 조이면 끝!`, `3초` | `~하면 끝`, `설치 3초`가 실제로 쓰이는 관용이다 |
| 의태어(착, 쓱, 쏙) | 쏙·쏙쏙·솔솔·쓱쓱·보송보송이 본문에 나온다 |
| Q&A 질문을 고객 말투로(S11-3) | "~안돼요", "~들어요", "~되나요?" |
| 조건·한계를 숨기지 않기(C1-7) | "불량이 아닙니다", "완전한 밀폐가 되지 않습니다", "사용하지 마세요" |
| 비교에서 기준을 먼저 세우기(강렬 입장) | `구매 전 꼭 확인하세요! CHECK 01`, `살펴보아야 할 3가지` |
| 일반 제품과 구조로 견주기, 타사 실명 없음 | `일반 샤워기 / 코멧 샤워기` |
| 제목 명사형 기본 | 셀링포인트·설계 제목 대부분 |
| 사용법은 동작 순서로 | `STEP 01~04`, `요리 → 손질 → 바로 버리기` |

### 표본과 어긋나는 것 — 판단이 필요한 자리
1. **메인의 품목명.** 표본 10개 중 9개가 메인 블록에 품목명을 둔다. v6.4 채택 메인 `돌려 조이면 끝! / 흔들어도 그 자리`는 제목에 품목이 없고 보조문에 있다. 관행과 가까운 쪽은 **대안 메인 `착 붙고 꽉 조인다 / 맥세이프 차량 거치대`**다.
2. **"~고민 있으시죠?" 식 도입.** 유튜브의 쇼호스트·UX 라이터는 추측이고 상투라고 했지만, 표본에서는 `이런 분들께 추천`과 `~셨나요?`가 **표준**이다. 상투라는 것과 통한다는 것이 같이 사실일 수 있다. 담백 입장의 "추측형 질문을 쓰지 않는다"는 관행과 다른 선택임을 알고 쓴다.
3. **위험소구의 비중.** 표본은 위험소구를 거의 쓰지 않는다(4블록). 우리는 한 영역을 통째로 쓴다. 차량용은 시선·안전이라는 실제 위험이 있어 사정이 다르지만, 생활용품 상위 상세의 관행은 아니다.
4. **흔한 수식어.** 유튜브 카드는 버리라고 하고 표본은 가득 쓴다. 우리 방침(보이는 말로 꾸민다)은 유튜브 쪽이다. 표본을 근거로 "강력한, 편리한"으로 돌아갈 이유는 없다. 다만 그런 말이 있다고 해서 페이지가 안 팔리는 것도 아니라는 점은 적어 둔다.
5. **종결 체.** 4-1대로 관행은 합쇼체 다수다. v6.4는 해요체다. 지침상 문제는 없다.

### 표본에서 새로 얻은 것
- **고객의 불만을 되받는 제목**(`물이 샌다구요?`). 우리 Q&A나 SP01 설명에 쓸 수 있다. 예: 리뷰의 "떨어져요"를 받아 원인(붙이는 면)과 조치를 말하는 자리.
- **"불량이 아닙니다" + 원인 + 조치**의 3단. 더운 날 느슨해지는 것, 곡면에 안 붙는 것에 그대로 맞는다.
- **각주로 조건을 다는 방식.** [수위] 표시가 붙은 문장(`흔들어도 그 자리`, `떼어 낸 자리는 깨끗해요`)을 살리면서 조건을 같은 화면에 두는 방법이다. 예: `*매끈하고 단단한 평면에 다이얼을 끝까지 조였을 때`.
- **구매 전에 사용 영상을 보게 하는 줄**(자이로볼). 설치가 낯선 제품이 "사용 미숙" 불만을 줄이려고 쓴다.
- **TIP 한 줄.** 본문과 별도로 요령 하나를 준다. "더운 날엔 다이얼 한 번 더"가 이 자리에 맞는다.
- **숫자 세 개 나란히**(`설치 3초 / 공간 차지 0 / 동선 낭비 0`).

## 6. 따라 쓰지 않을 것
- 근거 없는 건강·질병 암시: `세균이 샤워기를 통해 피부로 쉽게 흡수됩니다`, 타겟 체크리스트의 `여드름성 피부염이 있어요 / 탈모와 두피 각질이 심해졌어요`.
- 원문 안에서 서로 어긋나는 수치(자이로볼 8000rpm의 14kg과 18kg, 충전기 USB-A 출력).
- `절대로`, `보장합니다`(`안정적인 초고속 충전 환경을 보장합니다`), `걱정 NO` 같은 단정.
- 출처가 없는 집계(`접수건은 '90% 사용 미숙'입니다`).
- 영문 장식 라벨과 자체 브랜드의 틀 문구(`LOWER PRICE / BEST VALUE`).
