# Vocabulary and Rewrite Patterns

This is a practical replacement dictionary. Apply it with judgment; do not perform blind global replacements.

## Register

| Avoid as default | Prefer |
|---|---|
| `합니다` | `해요` |
| `됩니다` | `돼요` only if passive exception applies; otherwise active verb |
| `가능합니다` | `할 수 있어요` |
| `불가합니다` | `할 수 없어요` or condition-based positive form |
| `필요합니다` | `필요해요` |
| `요청드립니다` | `요청해요`, `알려주세요`, or action-specific copy |
| `확인 바랍니다` | `확인해주세요` / `확인해요` depending on surface |

## Passive to active

| Passive/stiff | Active/friendlier |
|---|---|
| `설정됐어요` | `설정했어요` |
| `변경됐어요` | `바꿨어요` |
| `전송됩니다` | `보낼게요`, `보내요`, `보냈어요` |
| `등록됐어요` | `등록했어요` |
| `선택됐어요` | `선택했어요` |
| `높아졌어요` | `올랐어요` |
| `낮아졌어요` | `내렸어요` |
| `결제될 예정이에요` | `결제일이에요`, `나가는 날이에요` |
| `환불 처리됐어요` | `환불했어요`, `돌려받았어요` |

## Negatives to positive conditions

| Negative-first | Positive-first |
|---|---|
| `가입할 수 없어요` | `[조건]하면 가입할 수 있어요` |
| `혜택을 받을 수 없어요` | `[남은/가능한] 혜택을 받을 수 있어요` |
| `사용할 수 없어요` | `[조건]하면 사용할 수 있어요` |
| `업데이트 전에는 쓸 수 없어요` | `최신 버전이 필요해요` |
| `인증하지 않으면 진행할 수 없어요` | `인증하면 계속할 수 있어요` |

Keep negative wording if the user truly cannot proceed. Add the reason.

## Honorific altitude

| Too formal | Toss-style default |
|---|---|
| `해지하시겠어요?` | `해지할까요?` |
| `사용하시겠어요?` | `사용할까요?` |
| `가지고 계시나요?` | `있나요?` |
| `내고 계시나요?` | `내고 있나요?` or subject-led rewrite |
| `여쭤볼게요` | `확인할게요`, `물어볼게요` |
| `고객님께` | `고객님에게` |
| `김토스님께` | `김토스님에게` |

## Subject-led question rewrites

When removing honorifics makes a question awkward, make the target information the subject.

| Form-field question | Subject-led version |
|---|---|
| `어떤 목적으로 대출받으시나요?` | `대출 목적이 무엇인가요?` |
| `어떤 이유로 신고하시나요?` | `신고 이유를 선택해주세요` |
| `매달 얼마씩 내고 계시나요?` | `매달 보험료는 얼마인가요?` |
| `어디에 거주하고 계시나요?` | `사는 곳이 어디인가요?` |

## Noun stacks to verbs

| Stiff noun stack | Verb/cause form |
|---|---|
| `잔액 부족으로` | `잔액이 부족해서` |
| `이자 환불` | `이자를 돌려받기` |
| `카드값 결제 예정` | `카드값 나가는 날` |
| `정보 입력` | `정보를 입력하기` |
| `계좌 개설` | `계좌 만들기` where product context allows |
| `신분증 확인 전까지` | `신분증이 확인되기 전까지` if passive is clearer |
| `혜택 대상 안내` | `받을 수 있는 혜택 안내` / direct benefit copy |

## Button labels

| Weak label | Better label |
|---|---|
| `확인` | `확인하기` or a named action |
| `제출` | `보내기`, `신청하기`, `등록하기` |
| `진행` | `계속하기`, `시작하기` |
| `취소` as dialog dismiss | `닫기` |
| `동의` | `동의하기` |
| `업데이트` | `업데이트하기` if space allows |

## Words to inspect, not always ban

These terms often signal stiffness, but may be necessary in financial products:

- `정책`, `약관`, `법`, `금리`, `연체`, `해지`, `만료`, `종료`, `인증`, `실명 확인`, `후원금`

If the term is legally or financially exact, keep it and simplify the surrounding sentence.
