# 한국 커머스 표시광고 리스크 규칙

> AI-assisted drafting을 위한 실무 체크리스트입니다. 최종 법률 의견이나 플랫폼 승인 보장이 아닙니다.

## 0. 전 품목 공통 원칙
### 금지 또는 고위험 표현
- 최고, 최저, 1위, 유일, 국내 유일, 완벽, 완전, 무조건, 100%, 즉시, 확실한, 부작용 없음
- 치료, 완치, 회복, 재생, 교정 보장, 병원 갈 필요 없음
- 검증된, 인증받은, 특허받은, 임상으로 입증된: 증빙 없으면 금지
- 누적 판매량, 리뷰 수, 만족도, 재구매율: 출처와 기준 시점 없으면 금지

### 수치·인증·비교 표현
| 표현 유형 | 허용 조건 | 위험 처리 |
|---|---|---|
| 수치 성능 | 시험성적서, 측정 조건, 기준 시점 필요 | 없으면 정성 표현으로 낮춤 |
| 인증/KC/식약처/기관명 | 인증서 번호와 대상 제품 일치 필요 | 이미지 배지 사용 금지 |
| 1위/최다/최저가 | 조사기관, 기간, 범위, 기준 필요 | 대부분 삭제 권장 |
| 경쟁 비교 | 동일 기준의 객관 비교 필요 | 타사 비방, 비교우위 단정 금지 |

## 1. 일반식품
일반식품은 질병 예방·치료, 신체기능 개선, 건강기능식품 오인 표현을 피한다.

| 유형 | 예시 | 대체 방향 |
|---|---|---|
| 질병/증상 연결 | 위장, 변비, 혈당, 불면, 피로, 염증 | 맛, 원료, 섭취 장면, 포장 편의성 |
| 기능 개선 | 면역력, 수면 개선, 디톡스, 붓기 관리 | 일상 음료, 산뜻한 맛, 휴대성 |
| 효과 약속 | 7일 후 변화, 먹으면 가벼움 | 개인 취향과 섭취 상황 중심 |
| 원료 효능 전가 | 원료 A가 좋으니 제품도 개선 | 원료명과 풍미만 설명 |

필요 고지 예시:
```text
본 제품은 일반식품이며, 건강기능식품 또는 의약품이 아닙니다.
질병의 예방이나 치료를 위한 제품이 아닙니다.
```

## 2. 건강기능식품
건강기능식품은 인정받은 기능성, 섭취량, 주의사항 범위 안에서만 표현한다.
1. 건강기능식품 표시 여부와 인정 기능성 원문 확인
2. 기능성 원료, 함량, 일일섭취량, 섭취 시 주의사항 확인
3. 기능성을 질병 치료나 즉시 효과로 확장하지 않기
4. “개선 보장”, “치료”, “약 대신” 표현 금지

필요 고지 예시:
```text
건강기능식품은 질병의 예방 및 치료를 위한 의약품이 아닙니다.
개인에 따라 섭취 결과가 다를 수 있습니다.
```

## 3. 화장품
| 고위험 | 대체 방향 |
|---|---|
| 치료, 재생, 염증 완화, 여드름 치료 | 피부를 깨끗하게 보이도록, 산뜻한 사용감 |
| 세포, 진피, 콜라겐 생성 보장 | 보습감, 윤기, 매끄러운 피부 표현 |
| 미백/주름개선 기능성 | 기능성 심사/보고 범위 안에서만 |
| 즉각 리프팅, 영구 개선 | 일시적 사용감, 메이크업 효과 등으로 제한 |

## 4. 운동기구/자세/마사지 제품
의료기기 오인, 통증 치료, 체형 교정 보장을 피한다.

| 금지 방향 | 안전 방향 |
|---|---|
| 허리통증 치료, 목디스크 완화 | 일상 스트레칭, 긴장감 완화 느낌, 사용 편의 |
| 척추 교정, 골반 교정 보장 | 바른 자세를 의식하는 데 도움 |
| 재활, 치료, 전문 의료 효과 | 홈트레이닝, 운동 보조, 루틴 형성 |
| 누구나 효과 | 사용 습관과 개인차 표시 |

## 5. 생활화학제품/위생용품
살균, 항균, 탈취, 유해물질 제거, 무독성 표현은 근거가 필요하다.
- 살균율, 항균율: 시험기관, 시험 조건, 대상 균주 필요
- 무독성, 인체무해: 절대적 안전 표현으로 위험
- 친환경, 생분해: 인증 또는 시험 근거 필요
- 아이/반려동물 안전: 대상, 조건, 주의사항을 함께 표시

## 6. 전자제품/가전/3C
- KC, 전파인증, 배터리 안전, 정격전압, 호환성 확인
- 방수 등급은 IP 등급과 조건을 함께 표시
- 충전 속도, 사용 시간, 소음, 전력량은 측정 조건 필요
- 모든 기기 호환, 완전 방수, 폭발 없음 같은 절대 표현 금지

## 7. 유아/반려동물 제품
안전성 표현은 소재, 시험, 인증 기준이 있어야 한다. 전연령, 무조건 안전, 먹어도 안전, 알러지 없음은 위험하다.
