# 한국 커머스 플랫폼별 이미지·문구 기준

## 공통 운영 기준
- 대표이미지는 3초 안에 제품, 대상 고객, 핵심 이점이 보여야 한다.
- 이미지 내 문구는 모바일 390px 기준으로 읽혀야 한다.
- 가격, 배송, 구성, 사은품, 할인 조건은 오해 없이 분리한다.
- 플랫폼 로고, 인증 배지, 리뷰 캡처는 권한과 근거가 없으면 쓰지 않는다.
- 광고, 협찬, 제휴, 파트너스 수익 고지는 필요한 경우 명확히 노출한다.

## 네이버 스마트스토어
| 영역 | 기준 |
|---|---|
| 상품명 | 검색 키워드와 실제 상품 속성 중심, 과장어보다 명확성 우선 |
| 대표이미지 | 제품 식별성, 썸네일 가독성, 과도한 배지/문구 자제 |
| 상세페이지 | 상품정보 제공고시, 배송/반품/교환, 옵션 혼동 방지 |
| 리뷰/랭킹 | 출처·시점 없는 만족도/리뷰 수/1위 표현 금지 |

## 쿠팡
| 영역 | 기준 |
|---|---|
| 썸네일 | 상품 실물과 구성 오해 방지, 과한 합성 주의 |
| 구성 | 개수, 용량, 세트, 사은품 조건을 분명히 표시 |
| 배송/가격 | 와우/무료배송/할인 표현은 실제 조건과 일치해야 함 |
| 파트너스 | 외부 콘텐츠라면 수익 발생 고지 필요 |

## 11번가, G마켓, 옥션
가격, 쿠폰, 카드 할인, 배송비 조건을 이미지에서 단정하지 않는다. 옵션별 가격 차이를 명확히 표시한다.

## 카카오쇼핑
선물 맥락이 강하면 포장, 메시지카드, 배송일, 교환 가능 여부를 분리한다.

## 오늘의집
공간 이미지와 실제 제품 크기/색상 차이를 주의한다. 전후 비교는 같은 조건에서 촬영된 자료가 있을 때만 사용한다.

## 자사몰
브랜드 톤과 전환 CTA를 강화할 수 있지만, 법적 기준은 동일하게 적용한다. 리뷰, UGC, 인플루언서 인용은 사용 동의와 출처를 확인한다.

## SNS 광고 소재
Hook은 짧게 쓰되 질병·외모불안·과도한 공포를 자극하지 않는다. 협찬, 광고, 제휴, 파트너스 고지는 숨기지 않는다.

## 플랫폼별 출력 힌트
| 목적 | 권장 출력 |
|---|---|
| 스마트스토어 | 검색 키워드형 제목 + 대표이미지 5장 + 모바일 상세페이지 |
| 쿠팡 | 썸네일 가독성 + 구성/옵션 명확화 + 빠른 구매 판단 |
| 오늘의집 | 공간 연출 + 사이즈/설치/관리 정보 |
| SNS | 짧은 Hook + 이미지 1~3장 + 고지문 |
| 자사몰 | 브랜드 스토리 + 근거 + CTA + FAQ |
