# 한국어 고위험 표현과 대체 방향

## 절대화 표현
| 고위험 | 대체 방향 |
|---|---|
| 최고, 최상, 최저, 1위, 유일 | 인기 있는, 대표적인, 선택받는, 합리적인 |
| 완벽, 완전, 100%, 무조건 | 꼼꼼하게, 충분히, 상황에 따라, 개인차 있음 |
| 즉시, 단번에, 하루 만에 | 간편하게 시작, 꾸준히 사용, 빠르게 준비 |
| 부작용 없음, 누구나 안전 | 사용 전 주의사항 확인, 대상/조건 명시 |

## 효능·의료 오인 표현
| 고위험 | 대체 방향 |
|---|---|
| 치료, 완치, 회복, 재생 | 관리, 사용감, 루틴, 도움을 줄 수 있음 |
| 통증 완화, 염증 개선 | 불편함을 줄이는 사용 환경, 편안한 사용감 |
| 면역력, 혈당, 수면, 붓기, 디톡스 | 맛, 소재, 휴대성, 섭취/사용 장면 |
| 교정, 체형 변화 보장 | 바른 자세를 의식, 운동 보조, 습관 형성 |

## 근거 필요한 표현
| 표현 | 필요한 자료 |
|---|---|
| KC 인증 | 인증번호, 대상 모델 |
| 식약처 인정 | 품목/기능성/신고 또는 인정 정보 |
| 항균 99.9% | 시험성적서, 시험 조건, 대상 균주 |
| 누적 판매 10만개 | 집계 기준, 기간, 판매처 |
| 만족도 98% | 조사 대상, 기간, 문항, 표본 수 |
| 특허 | 특허번호와 권리 범위 |

## 이미지 내 문구 길이 기준
- 대표이미지: 5줄 이하, 한 줄 8~12자 권장
- 상세페이지 모듈: 제목 1줄 + 보조문 1~3줄 권장
- 고지문: 작게 넣더라도 모바일에서 확대 시 읽혀야 함
- 배지: 실제 인증/수상/플랫폼 지위가 아니면 장식 배지로 오해시키지 않기
