# 한국 커머스 시각 카피 기획 SOP

## 언어 규칙
기본 출력은 한국어다. 사용자가 영문 자료를 주더라도 최종 운영안은 한국 커머스 운영자가 바로 쓸 수 있는 한국어로 정리한다.

## 언제 사용하나
상품 대표이미지, 상세페이지, 상품 카드, 이미지 내 문구, 판매 포인트, 광고 소재, 플랫폼 심사 리스크, 생성형 이미지 프롬프트가 필요한 경우 사용한다.

대표 트리거:
- “스마트스토어 대표이미지 5장 기획해줘”
- “쿠팡 상세페이지 문구랑 이미지 구성을 잡아줘”
- “이 문구 과장광고 위험 없는지 봐줘”
- “상세페이지를 모바일 기준으로 다시 짜줘”
- “이미지 생성 프롬프트까지 줘”

사용하지 않는 경우:
- 최종 법률 의견, 플랫폼 통과 보장, 심의 대행
- 증빙 없는 인증·시험성적서·특허·판매량·리뷰·효능의 창작
- 의료기기, 의약품, 건강기능식품 기능성 범위를 넘는 효능 표현
- 사용자의 명시 요청 없는 자동 등록, 광고 집행, 외부 발송

## 핵심 원칙
1. 기획 먼저. 전환 동인을 판단하기 전에는 이미지 문구를 쓰지 않는다.
2. 대표이미지와 상세페이지를 분리한다. 대표이미지는 클릭과 이해, 상세페이지는 신뢰와 구매결정을 담당한다.
3. Storyboard 확인문을 둔다. 방향 확인 전에는 최종 문구와 생성 프롬프트로 넘어가지 않는다.
4. 한국 표시광고 기준을 우선한다. 플랫폼 규정은 그 위에 더하는 추가 제약으로 본다.
5. 증빙 없는 주장은 쓰지 않는다. 수치, 인증, 1위, 누적 판매, 리뷰, 효능은 출처가 없으면 삭제하거나 중립 표현으로 바꾼다.
6. 모바일 가독성을 기준으로 삼는다. 390px 화면에서 이미지 내 문구가 읽히지 않으면 실패로 본다.

## 전체 워크플로
1. 제품 자료, 판매 채널, 증빙, 금지 표현, 목표 고객을 수집하고 결측을 표시한다.
2. 전환 동인을 판단하고 Campaign Style Lock을 고정한다.
3. `시각 기획안`을 출력한 뒤 사용자의 확인을 기다린다.
4. `대표이미지/상세페이지 Storyboard`를 출력한 뒤 사용자의 확인을 기다린다.
5. 확인 후 이미지 구성, 이미지 내 문구, 디자인 지시, 생성형 이미지 프롬프트를 작성한다.
6. 한국형 5개 항목 자가검수를 수행하고 80점 미만 항목은 해당 항목만 다시 쓴다.
7. 최종 실행안과 남은 리스크, 필요한 증빙을 함께 전달한다.

## Step 1. 입력 정보 수집
자료가 부족하면 지어내지 말고 `확인 필요`로 표시한다. 단, 방향을 결정할 수 있을 정도의 정보가 있으면 결측 표시 후 진행한다.

| 필수 정보 | 목적 |
|---|---|
| 제품명, 카테고리, 일반/특수 품목 여부 | 적용 가능한 표현 범위 판단 |
| 판매 채널 | 플랫폼별 이미지·문구 제약 반영 |
| 목표 고객과 사용 상황 | 실사용 언어와 장면 도출 |
| 핵심 기능, 소재, 구성, 가격, 규격 | Feature → Benefit 번역 |
| 보유 증빙 | 인증, 시험성적서, KC, 기능성, 원산지, 제조 정보 확인 |
| 기존 이미지/상세페이지/경쟁 상품 | 시각 출발점과 차별화 판단 |
| 브랜드 톤과 금지 톤 | 문체, 색감, 디자인 밀도 결정 |

### 전환 동인 분류
| 유형 | 예시 품목 | 시각 전략 |
|---|---|---|
| 시각/감성 주도형 | 인테리어, 패션잡화, 선물, 향 제품 | 질감, 공간감, 선물성, 분위기 |
| 문제 해결형 | 수납, 청소, 생활용품, 업무도구 | 불편 상황 → 해결 장면 → 사용 후 정리감 |
| 정보/스펙 주도형 | 전자제품, 가전, 공구, 3C 액세서리 | 수치의 의미 번역, 비교, 사용 조건 명확화 |
| 신뢰/안전 주도형 | 유아, 반려동물, 식품, 생활화학제품 | 소재·성분·인증·주의사항을 과장 없이 시각화 |
| 가격/구성 주도형 | 소모품, 번들, 대용량, 시즌 행사 | 구성, 단가, 배송, 사용량, 선택 기준 |

### Campaign Style Lock
반드시 아래를 고정한다.
- 주색, 보조색, 강조색: 최대 3색
- 대표이미지 내 제품 점유율: 권장 60~80%
- 조명/그림자/질감 표현 방식
- 폰트 계열: 굵기, 자간, 숫자 표현 방식
- 사진형/렌더형/일러스트형/카드뉴스형 여부
- 금지 항목: 무관한 배경, 과한 아이콘, 허위 배지, 읽히지 않는 작은 글씨, 플랫폼 오인 로고

## Step 2. 시각 기획안 출력
다음 내용을 출력한 뒤 멈춘다.
1. 전환 동인 판단과 근거
2. Campaign Style Lock
3. Benefit 번역표: Feature → Advantage → Benefit → Evidence
4. 한국 기준 리스크: 적용 법·플랫폼·품목별 주의점
5. 결측 정보와 현재 가정

확인문:
> 위 내용은 1차 시각 기획안입니다. 전환 동인, 고객 장면, 스타일 락이 맞는지 확인해 주세요. 확인 후 대표이미지 5장과 상세페이지 Storyboard로 넘어가겠습니다.

## Step 3. Storyboard 출력
이 단계에서는 최종 이미지 내 문구를 확정하지 않는다. 목적은 방향 오류를 빨리 드러내는 것이다.

### 대표이미지 5장 역할
| 번호 | 역할 | 핵심 기준 |
|---|---|---|
| KV1 첫 이미지 | 검색/피드에서 멈추게 하기 | 제품 크게, 핵심 이점 하나, 3초 이해 |
| KV2 문제 장면 | 고객의 불편을 보여주기 | 병·증상·효능 암시 없이 생활 불편 중심 |
| KV3 해결/차별점 | 왜 이 제품인지 설명 | 기능을 체감 이점으로 번역, 증빙 없는 수치 금지 |
| KV4 사용 장면 | 실제 사용을 상상하게 하기 | 집/사무실/여행/선물 등 구체 장면 |
| KV5 구성/구매 판단 | 옵션·규격·구성 정리 | 가격·배송·구성 오해 방지, CTA는 절제 |

각 대표이미지 Storyboard는 시각 역할, 구도, 첫 시선, 사용할 정보, 제외할 정보, 한국 기준 리스크 주의점을 포함한다.

### 상세페이지 흐름
| 모듈 | 역할 | 기준 |
|---|---|---|
| M1 첫 화면 | 이 제품이 누구를 위한 것인지 즉시 전달 | 제품+상황+핵심 이점 |
| M2 문제 공감 | 구매 이유를 만든다 | 질병·신체개선 암시 금지 |
| M3 핵심 이점 | Top 2~3 구매 이유 | 기능보다 체감 이점 중심 |
| M4 소재/성분/스펙 | 신뢰 근거 제시 | 출처 있는 내용만 사용 |
| M5 사용 장면 | 실제 사용 맥락 | 과장된 전후비교 금지 |
| M6 비교/선택 기준 | 왜 이 제품인지 정리 | 타사 비방 금지, 객관 기준만 |
| M7 구성/사용법 | 구매 전 불확실성 제거 | 규격, 사이즈, 세척, 보관, 호환성 |
| M8 FAQ | 반품/배송/주의사항 방어 | 고객센터성 정보도 명확하게 |
| M9 CTA/고지 | 행동 유도와 리스크 표시 | 광고/협찬/파트너스/품목 고지 필요 시 노출 |

확인문:
> 위 내용은 전체 이미지의 Storyboard입니다. 아직 최종 문구와 생성 프롬프트는 확정하지 않았습니다. 이미지 역할과 상세페이지 흐름이 맞는지 확인해 주세요. 확인 후 최종 실행안을 작성하겠습니다.

## Step 4. 최종 실행안
사용자가 Storyboard를 확인하면 각 이미지 또는 모듈마다 네 가지를 제공한다.
1. 화면 구성: 제품 배치, 배경, 광원, 재질, 여백, 시선 흐름
2. 이미지 내 문구: 대표이미지는 5줄 이하, 한 줄 8~12자 권장, 모바일 우선
3. 디자인 지시: 폰트, 색상, 강조 방식, 고지문 위치, 금지 요소
4. 생성형 이미지 프롬프트: 한국형 쇼핑몰 소재로 바로 쓸 수 있는 구도·질감·제약 포함

## Step 5. 한국형 5개 항목 자가검수
| 항목 | 기준 | 큰 감점 조건 |
|---|---|---|
| 표시광고 리스크 | 허위·과장·기만, 절대화, 효능, 인증, 수치 근거 | 증빙 없는 1위·최고·효능·수치·인증 |
| 모바일 가독성 | 390px 기준 문구량, 대비, 첫 시선 | 글자 과밀, 행수 초과, 제품보다 문구가 큼 |
| 구매 이유 번역 | 기능이 고객 이점으로 바뀌었는가 | 설명서식 기능 나열, 고객 장면 부재 |
| 시각 일관성 | Style Lock 유지, 제품 점유율, 색/폰트 일관 | 이미지마다 톤이 다름, 과한 장식 |
| 신뢰와 행동 | 증빙·구성·FAQ·CTA가 구매 불안을 줄이는가 | 근거 부재, 배송/구성 오해, 고지 누락 |

## 품목별 기본 리스크
자세한 규칙은 `references/compliance-rules.md`, `references/platform-rules.md`, `references/risk-words.md`를 따른다.

| 품목 | 핵심 주의점 |
|---|---|
| 일반식품 | 질병 예방·치료, 면역·수면·혈당·다이어트 등 신체기능 암시 금지 |
| 건강기능식품 | 인정받은 기능성, 섭취량, 주의사항 범위를 벗어나지 않기 |
| 화장품 | 치료, 재생, 세포, 염증, 완치 등 의약품 오인 표현 금지 |
| 운동/자세 제품 | 통증 치료, 체형 교정 보장, 의료기기 오인 금지 |
| 생활화학제품 | 살균·항균·탈취·안전성 수치 근거 필요 |
| 전자/가전 | KC, 전파인증, 성능 수치, 호환성 근거 확인 |
| 유아/반려동물 | 안전성·무독성·전연령 표현은 근거 없으면 금지 |

## 결측 자료 처리
- 증빙, 인증, 시험성적서, 승인번호, 리뷰, 판매량은 절대 만들지 않는다.
- 결측이 있어도 가능한 범위의 `가정 기반 초안`은 제공하되, 가정은 분리 표시한다.
- 고위험 품목은 효능형 문구 대신 소재, 사용 장면, 구성, 주의사항 중심으로 작성한다.
- 추가 질문은 최대 3개만 한다. 방향과 리스크를 바꾸는 질문을 우선한다.

- [ ] 시각 기획안과 Storyboard 확인문을 분리했는가?
