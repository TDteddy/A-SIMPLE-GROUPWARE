# Part A. 대시보드 기획안 가이드라인 (기준 문서 요약)

> 아래는 대시보드 원문을 구조만 정리한 요약입니다. 해석이 갈리면 원문을 우선합니다.

## A0. 공통 작성법 — 구매 이유부터 원고까지 (7단계)
> 주용도 안에서 고를 이유를 정하고, 짧게 어필한 뒤, 뒤의 영역마다 새로운 판단 정보와 근거를 더합니다. 모든 유형에 공통입니다.

| 단계 | 정할 것 | 작성할 때 확인 |
|---|---|---|
| 1 명칭과 첫 화면 결정 | 소싱명 / 일반 카테고리명 / 판매용 고유명 / 승인 상태 / 첫 화면 표현 방식 | 이미지 중심·최소 텍스트. 키카피는 확정 자사 고유명만. 판매명 미정이면 무카피 또는 확인된 매력 하나. 가칭·SKU 코드 금지 |
| 2 구매 이유 정리 | 주용도 / 고객이 하려는 일 / 구매 계기 / 기대하는 변화 / 이 방식을 고를 이유 / 구조·구성 / 근거 / 맞지 않는 조건 | 광고 말투 전의 내부 기획. 설치·일상 사용·관리·이동·보관을 실제 행동대로 구분. **반복 후기가 적거나 선별됐으면 타깃은 가설로 기록** |
| 3 위험과 단순 불편 분리 | 실제 위험 상황 / 발생 경로 / 가능한 피해 / 관련 자료 / 준비 필요성 / 제품이 맡는 범위 / SP로 옮길 편의 | 안전 주의문만으로 위험소구를 대신하지 않음. 일반 위험의 근거를 자사 제품의 예방 효능으로 바꾸지 않음. 위험이 없으면 영역 자리는 두고 미적용 사유 기록 |
| 4 주장과 근거 연결 | 소비자에게 말할 이점 / 근거의 실제 내용 / 출처와 옵션 / 뒷받침하는 범위 / 부족한 자료 / 현재 쓸 문구 | 확인된 구조에서 바로 설명할 수 있는 동작을 모두 실험 대기로 돌리지 않음. 유지 시간·하중·효과·우열은 자료에 연결 |
| 5 13영역 새 정보 배정 | 유형별 순서 / 고객 질문 / 앞에서 없던 정보 / 원고의 역할 / 증거와 미디어 / 보류 부분의 확보 요청 | 역할·근거·경계를 나누되 원고 형식을 한 문장 공식으로 통일하지 않음 |
| 6 메인 후보와 원고 작성 | 무카피·확정 고유명형·이점형 등 **다른 관점의 후보** / 근거·대표 장면 / **채택 이유** / 필요한 텍스트만 | 후보는 내부에서 검토하고 화면에 모두 노출하지 않음 |
| 7 제작과 게시 준비 | 재사용 자산 / 새 촬영·실험·편집 요청 / 확보할 원본 / 결과에 따라 바꿀 문구 / 실제 결과물 검토 상태 | 기획 완료 · 촬영/생성 완료 · 검토 완료 · 게시 완료를 나눔 |

### A0-1. 근거가 설명할 수 있는 범위 (4유형)
| 근거 종류 | 쓸 수 있는 내용 | 추가 확인 |
|---|---|---|
| 확인된 구조와 동작 | 그 동작이 가능하다는 사용 방식 | 하중·반복 수명·유지 시간은 별도 근거 |
| 실제 사용자 경험(원문) | 그 사용자의 경험을 원문 인용, 인용 범위 표시 | 한 사람의 경험을 모든 조건의 성능·대표 동기·만족률로 확대하지 않음 |
| 아직 하지 않은 실험 | 내부 제작 요청과 판정 기준 | 원본·관찰 기록·결과 확인 전까지 결과 카피와 검증 완료 표시 보류 |
| 일반 위험 자료 | 위험 경로와 준비 필요성 | 특정 제품의 성능·예방 효능을 입증하지 않음 |

### A0-2. 선택에 도움이 되는 비교표 (양식)
- 질문: 고객은 지금 **어떤 두 선택** 사이에서 고민하는가?
- 열: `선택에 영향을 주는 항목` / `방식·옵션 A의 사실` / `방식·옵션 B의 사실` / `차이가 의미하는 선택 조건`
- 공통 우열 판정 대신 "어떤 요구에는 우리 방식, 어떤 조건에는 다른 방식"으로 마무리합니다.
- 표를 읽어도 선택이 달라지지 않으면 기능 유무 나열을 줄이고 실제 과업·조건으로 축을 다시 잡습니다.

## A1. 기본 방향
- 고객의 실제 불편과 필요를 짚고, 제품이 제안하는 변화와 그 이유를 납득시킵니다.
- 모든 영역에서 문제를 반복하거나 모든 제목을 '불편하지 않으세요? / 이제 해결하세요'로 만들지 않습니다. 영역마다 역할이 다릅니다.
- **유지할 흐름**: 정품·판매처 신뢰 → 제품의 첫인상 → 나와 관련된 사용 상황 → 실제 위험과 준비 필요성 → 실제 평가와 공신력 → 설계·기술의 이유 → 개별 장점 → 비교와 선택 → 제품정보 → 상품정보고시 → Q&A·주의사항 → 브랜드 소개

**작성 전 내부에서 정할 것** (키비주얼에 다 넣는 항목이 아닙니다)
- **고객 상황**: 누가 무엇을 하려는가
- **명칭**: 소싱명, 카테고리명, 확정 자사 고유 상품명을 구분합니다. 이름이 미정이면 키카피로 쓸 이름을 만들지 않습니다
- **위험과 불편**: 실제 위험(04), 편의 개선(07 SP), 규격·옵션 고민(08·09·11)으로 나눠 배정합니다. 사실과 가설을 구분합니다
- **제품의 제안**: 그 상황을 어떻게 바꾸는가
- **근거**: 구조, 사양, 실제 사용, 시험, 후기
- **선택 이유와 조건**: 어떤 요구에 맞고 어떤 조건이 필요한가

## A2. 13개 영역 — 구매 질문·근거·경계

| 12 브랜드 소개 | 고정 | 이 브랜드가 지키는 기준은? | 승인 공용 원고, 로고, 실제 지원 약속 | 01과 SKU 기능 나열을 반복하지 않음 |

## A3. 영역별 핵심 규칙 (원문 발췌 요약)
- **02 키비주얼**
  - 이미지 중심, 최소 텍스트로 구성하며 정해진 텍스트 조합은 없습니다.
  - 표현 유형은 고유 상품명형, 무카피 화보형, 대표 이점형, 대표 기능형, 콘셉트·감성형, 기능 요약형(꼭 필요할 때만) 중에서 고릅니다.
  - '맥세이프 차량용 거치대'는 N001의 소싱명입니다. 키카피로 쓰지 않고, 일반명 앞에 NORVEC만 붙여 고유명처럼 쓰지도 않습니다.
  - 판매명이 미정이면 무카피 화보형이나 확인된 매력 하나를 담은 짧은 카피를 씁니다.
  - 오해를 막는 핵심 조건(예: 비충전)은 가까이에 둡니다.
- **03 타겟·사용 상황**
  - 직업·연령보다 행동·공간·상황을 씁니다.
  - 1인칭 바람 문장에 작성자·별점·구매 인증을 붙이지 않습니다.
  - 운전 중 조작을 권하지 않습니다.
- **04 위험소구**
  - 근거 자료는 공공 안전자료·연구를 우선합니다. 부정 리뷰는 탐색의 출발점일 뿐 인과나 발생률의 증거가 아닙니다.
  - 위험 설명 뒤에 제품을 놓았을 때 '이 제품이면 사고를 막는다'는 암시가 생기지 않는지 연속해서 읽어 확인합니다.
  - 위험 장면은 정차 차량에서 연출하거나 도식으로 만듭니다.
  - 근거가 부족하면 기획 자리는 유지하고 소비자 원고는 보류합니다.
  - 피할 것: 근거 없는 사고 확률·반응시간·자력·고정 보장, 가격 상승·품절 공포

  - 판매자 제목, 고객 원문, 집계 수치를 분리합니다.
  - 요약을 따옴표에 넣지 않고, 외부 후기를 자사 후기로 오인시키지 않습니다.

## B2. 오퍼 설계 (Part A 밖의 사업 결정 — 기획 전에 정리)
같은 본체를 파는 기성 상품은 판매처 간 차이가 **구성·가격·안내·지원**에 있습니다. 대시보드 상품마스터 `differentiation`에도 그렇게 적혀 있습니다.
