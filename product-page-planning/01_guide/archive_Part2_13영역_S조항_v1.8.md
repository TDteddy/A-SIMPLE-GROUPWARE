# Part 2. 영역별 카피 지침 (해당 영역에만 적용 · 공통 지침의 예외 포함)

> **v1.6**: 영역의 구성·순서·분량·카드 수·이미지 역할·영역별 주의는 **`레이아웃_NORVEC_기본안_14영역.md`**를 본다. 아래 S 조항에는 **카피를 쓰는 법**만 남았다. S 조항 안에 남아 있는 카드 수·글자 수·화면 구성 표현은 옛 13영역 틀의 것이므로 **레이아웃 문서와 다르면 무시한다.**

**레이아웃 문서의 '주의'와 이 가이드의 미사여구 방침이 만나는 곳** (v1.7, 광고주 지시)
- 미사여구는 자제하지 않는다. **`강력한`, `단단한`, `든든한`, `탄탄한` 같은 세기의 수식어는 허용 범위다.** 레이아웃 문서의 "근거 없이 '강력'을 확정하지 않는다"는 적용하지 않는다.
- **지양하는 것은 단정하는 어휘다[권장]**: `절대`, `무조건`, `100%`, `완벽`, `어디든`, `모든 기종`, `~없음`(`흔들림 없음`, `떨어짐 없음`), `전혀 ~않는다`, `걱정 끝`. 세다는 말은 되고 **예외가 없다는 말**은 피한다. 같은 내용을 확인 동작("조인 뒤 흔들어 보세요")이나 조건을 붙인 문장으로 쓰면 된다.
- 그대로 지키는 것: `사고 예방` 같은 안전 보장(V0-3), 확인되지 않은 부피 감소율·연구 이력·시험 수치(V0-1).
- 레이아웃 06(구매 후기)의 "후기를 창작하지 않는다 / 자료가 없으면 보류"는 **적용하지 않는다.** 재구성 후기를 쓴다(V0-2, S05-3).
- 주장에 직접 영향을 주는 조건은 Q&A에만 두지 않고 **그 주장 가까이에** 표시한다(레이아웃 14). C1-7의 "불안은 앞에서 답한다"와 같은 방향이다.

## S01. 정품 인증 (고정)
- **S01-1 [최소선]** 승인 공용 원본, 판매 주체, 실제 지원 조건만. 성능·안전 인증이나 브랜드 역사로 확대하지 않는다.
- **S01-2 [최소선]** 보증·교환 약속은 승인 전 소비자 원고 보류(오퍼 설계 결과만 반영). 표준 템플릿의 고지문은 그대로 둔다.

## S02. 키비주얼
- **S02-1 훅과 결과 [최소선]** — 쓰기 전에 둘을 찾는다. 훅 = 사진에 보이고 경쟁 상품이 따라 말하기 어려운 것 하나. 결과 = 그 훅 때문에 사용자에게 생기는 생활의 변화 하나. 하나만 있으면 설명서(훅만)나 아무 상품의 말(결과만).
- **S02-2 점검 셋 [최소선]** — ① 스왑 2중: 같은 구조 경쟁품 / 다른 구조 대체품이 그대로 써도 되는가 → 둘 다 '아니오' ② 읽는 사람의 지금이 떠오르는가(있다면 동작으로) ③ 결과 쪽에 체감형 과장 하나.
- **S02-3 형식 [권장]** — 훅+범주 / 훅→결과 / 결과+범주 / 질문 중 상품에 맞게. 범주 명사에 구조어를 붙여 식별을 높일 수 있다. KEY 한 줄이 훅·결과를 다 못 담으면 SUB 1줄.
- **S02-4 초점 어휘 [최소선]** — 장소·부위·타 제품 명사를 KEY에 쓰지 않는다. 차이는 동작으로(끼우지 않고 / 벌리지 않고 / 내려다보지 않고).
- **S02-5 하지 않는 것 [최소선]** — 전체 설득의 압축판, 기능·위험·옵션 모으기, 소싱명 키카피, 보장·최상급·측정값, 느낌표. 오해를 막는 핵심 조건(비충전·설치면 기준)은 가까이에 작은 라벨로(슬롯이 없으면 09·11로).
- **S02-6 이미지 [최소선]** — 텍스트 띠 아래 사진. 텍스트가 사진 위에 올라가는 슬롯이면 제품은 하단 40~55%에, 상단은 빈 배경(C6-2). 점유율은 띠를 뺀 면적 기준 70~80%.

- **S02-V 변형** — ① 선언형(`거치대 고민, 오늘로 끝`) ② 장면형(시동 전 3초의 한 컷 + 한 줄) ③ 감각형(`착.` 한 단어 + 범주) ④ 질문형(`아직도 끼우세요?`) ⑤ 무카피 화보 + 아이콘 3 ⑥ 정체성형(`정돈된 차의 한 자리`). 메인은 반드시 톤 3칸(V4)으로 써 보고 고른다.

## S03. 타겟·사용 상황
- **S03-1 축 [최소선]** — 카드의 축은 사용 상황이 아니라 '지금 그 일을 어떻게 하고 있는가'(행동표의 집단). 상황(출근·등하원)은 사진 캡션으로만. 직업·연령보다 행동·공간·상황.
- **S03-2 헤더 [최소선]** — 미사용자까지 포괄하는 질문(`운전할 때 휴대폰은 어디에 두세요?`). 사용자만 부르는 헤더("이런 거치대 쓰시나요?")는 쓰지 않는다.
- **S03-3 카드 [권장]** — 사진 + KEY 라벨(`○○ 쓰시는 분`) + 서브 한 줄(겪는 것, 완결된 합쇼체 문장, 리뷰 빈도 1위 표현). 3~4장, 미사용 집단 필수. 카드 안에서 이 제품의 해결을 말하지 않는다(편의 07, 조건 09). 표준 템플릿의 2×2 격자면 제목은 3~6자 명사로 줄이고 "~하시는 분"은 서브 앞에.
- **S03-4 어휘 예외** — 방식을 호명하는 영역이라 방식 명사·유형명을 쓸 수 있다(C2-3의 예외). 1인칭 바람문·별점·구매 인증·주행 중 조작 권장은 금지.
- **S03-5 이미지** — 카드마다 장면 사진 1장(8:9 안팎), '거치대(대상물)+손' 묶음이 피사체 60~70%.

- **S03-V 변형** — 축을 바꿔 본다: ① 지금 쓰는 방식(기본) ② 하루의 순간(출근 7시 / 하원 4시 / 주말 장거리) ③ 속마음 한마디(`또 떨어졌네`) ④ 손의 동작(벌리는 손 / 뻗는 손 / 찾는 손) ⑤ 체크리스트 한 장(`셋 중 하나라도 해당되면`). 헤더도 질문·선언·공감 중에서 고른다.

## S04. 위험소구
- **S04-1 KEY = 늘 참인 사실 문장 [최소선]** — 어떤 사용자·환경에도 참인 평서문 하나. 빈도어(마다·자꾸)·결과 단정 없이 참이 되게 문장 자체를 고른다. 신뢰 테스트: 공공 안전 기관 안내문에 실려도 어색하지 않은가. 명사형 조각·비유 금지(C3-2의 예외: 서술문이 기본).
- **S04-2 변수와 범위 [최소선]** — 제품이 바꾸는 변수가 KEY나 다음 문장에 온다. 제품의 사고 예방 효과는 말하지 않는다. 위험 쪽에는 과장을 쓰지 않고(C2-4의 예외) 독자를 위험 사용자로 규정하지 않는다. 단순 불편은 07로, 위험이 없으면 영역 자리는 두고 미적용 사유 기록.
- **S04-3 층 [권장]** — 질문 줄은 선택(짧고 비난 없이, 경험 회상형) → KEY 1문장 → 설명 1~2문장(피해 가능성은 '~수 있습니다') → 준비 한 줄(명사형 가능).
- **S04-4 법령·근거 [최소선]** — 법령 인용은 여기서 쓰지 않는다(C4-3). 안전은 행동 지시로만. 근거는 시선 이탈·반응 지연 같은 공공 자료만, 부정 리뷰는 증거가 아니다.
- **S04-5 이미지 [최소선]** — 정차 상태의 사진(선화·도식 혼용 금지, C6-4). 캡션이 올라가는 히어로는 중앙을 어둡고 비워서(C6-2). 표준 템플릿의 수치 칸은 출처 있는 사실(시선 이탈 시간, 속도×시간 산술, 법정 벌점)로만 채우고 예외 표기.

- **S04-V 변형** — ① 사실 문장(기본) ② 숫자 한 방(`2초, 28m`) ③ 장면 한 컷 + 한 줄(`그 2초에 앞차가 멈췄다면`) ④ 질문(`방금 어디를 보셨나요?`) ⑤ 대비(`내려다보는 2초 / 앞을 보는 2초`). 무섭게가 아니라 **선명하게.** 끝은 항상 "그래서 미리 자리를 정해 둔다"로 잇는다.

## S05. 공신력·리뷰
- **S05-1 선정 [권장]** — 3~5장. ① 전환 서사 ② 구체 장면 ③ 감정 판정 ④ 확산 신호 중 둘 이상. 순서는 전환 서사(가장 큰 집단) → 장면 → 확산 신호. 불만 후기는 05에 두지 않고 09 조건·11 Q&A로. 후기를 SP 순서대로 배열하지 않는다.
- **S05-2 가공 [최소선]** — 해요체 통일(반말·ㅋㅋ·이모티콘 미반영, 구어 어미·줄임말 허용 — C3-5의 예외) / 카드마다 원문의 구체 디테일 1개 이상 / 사소한 아쉬움·전제 한 줄 허용 / 문장 수·길이·순서를 일부러 다르게 / 같은 동사·결구 반복 금지 / 카피라이터식 정리 문장 금지. 점검: 이어 읽고 "한 사람이 썼나?"에 '아니오'.
- **S05-3 자사 후기가 없을 때 [유효 — v1.7에서 되살림. 레이아웃 06의 '창작 금지·보류'보다 이 조항이 우선]** — 동일 제품 공개 후기 2~4건을 섞어 재구성할 수 있다. 제외: 대가 지급·사용 전·홍보 복사 리뷰. 제거: 브랜드·판매처·수치·이벤트 문구. 유지: 평가 방향·조건. 묶음 위 고지 1줄(`같은 제품 사용자들의 공개 후기를 바탕으로 재구성한 내용입니다.`)과 기획안 부록의 합성 원천 기록은 필수. 자사 후기가 모이면 교체.
- **S05-4 헤더·표기 [권장]** — 헤더는 출처·판매처·'같은 제품'을 말하지 않고(고지가 맡는다) 수치 없는 짧은 명사형 10자 안팎, 단정형. 별점·아바타·가명·평균·"N명" 없음. 표준 템플릿에 별점이 고정돼 있으면 광고주 판단 항목으로. 표준 템플릿 카드 본문은 65~75자, 핵심 문장만 굵게, 출처 줄에 `재구성 후기 ·` 표기.

- **S05-V 변형** — ① 말풍선 카드(기본) ② 한 줄 인용 크게 + 나머지 작게 ③ 전·후 대화체(`전엔… / 지금은…`) ④ 상황 태그 묶음(#출퇴근 #등하원 #장거리) ⑤ 메신저 대화 화면. 헤더도 각도를 바꾼다(`먼저 써 본 분들의 한마디` / `바꾸고 나서 하는 말` / `왜 진작 안 바꿨을까`). 어떤 변형이든 V0-2 고지는 유지.

## S06. 연구개발·설계
- **S06-1 KEY = 자신감 서술문 [최소선]** — 구조 사진 앞에 "이렇게 만든 데는 이유가 있다"는 자신감을 합쇼체 서술문 한 줄로(C3-2의 예외). 구조 전체를 가리키고 아래 부품 소제 전부가 KEY를 받아야 한다. 점검: 소제를 하나씩 가리키며 "KEY가 이것도 받는가" / 07로 옮기면 어색한가(어색해야 정상) / 사진을 건네는가(안내만 하면 실패).
- **S06-2 KEY에 넣지 않는 것 [최소선]** — 부품·동작 하나(그 부품의 SP가 된다), 02 훅의 반복, 목차 안내문(`세 부위가 하는 일`), 의인화·업무 어휘(하는 일·담당), 배제 대상·소재 명사, 이점어, 제품 요약.
- **S06-3 예외 [권장]** — 스왑 테스트 면제(차별화가 아니라 이해·신뢰). 개발·설계 어휘 허용(C2-4). 자체 개발 이력·연구소·특허·시험 수치는 날조 금지. 평범한 구조를 위험 해결 증거로 쓰지 않는다.
- **S06-4 부품 소제 [권장]** — `부품명 — 하는 일(동작 명사형)`(차에 고정 / 각도 조절 / 휴대폰 부착). 이점어는 설명 줄이나 07로. 소제끼리 문법을 맞춘다. 설명은 C3-3.
- **S06-5 이미지 [권장]** — 전체 정면 1장(지시선 라벨이 부품명을 맡는다) + 부품당 접사 1스크린. 표준 템플릿의 고정 하단 블록은 C7-3.

- **S06-V 변형** — ① 자신감 서술문(기본) ② 숫자 선언(`부품 셋, 이유 셋`) ③ 디테일 집착(`다이얼 한 칸까지 따졌습니다`) ④ 질문(`왜 다이얼일까요?`) ⑤ 분해 순서 스토리(붙이고 → 세우고 → 댄다). 소제도 명사형·동사형·결과형 중에서 고른다.

## S07. 셀링포인트
- **S07-1 SP 하나 = 차이 하나 [최소선]** — SP 한 칸은 행동표 집단 하나와의 차이 하나. 두 이점을 한 KEY에 묶지 않는다. 서로 다른 장점 1~4개, 4개 채우기·반복 금지. 없는 기능을 성능 우위로 추론하지 않는다.
- **S07-2 스왑은 정도·범위로 [최소선]** — "경쟁품에도 있다"로 끝내지 않고 같은 정도·범위·조건으로 되는가를 묻는다. 범위 차이는 숫자 없이 결과 어휘(원하는·그대로·넉넉한).
- **S07-3 KEY 어휘 [권장]** — 06 소제로 쓴 부품명을 07 KEY에 다시 쓰지 않는다(훅은 동작·효과로). 조작 노력 어휘·몸의 동작어 금지(C2-3). 동작명만 써 놓지 않는다.
- **S07-4 구조 [권장]** — POINT 번호 + KEY 1줄 + 이미지가 기본. 설명은 없어도 된다(C3-1 안에서의 축소). 쓸 때는 KEY에 없는 새 정보 한 줄까지. 구조는 06, 조건은 09, 안전은 11로 보낸다. 표준 템플릿 SP 수가 다르면(예: 3) 남는 SP는 02 아이콘·06 설명·08 표로 흡수하고 영역을 추가하지 않는다(C7-1).
- **S07-5 이미지 [권장]** — 점유율 70% 이상. 동작은 GIF 한 장(C5-2). 표준 템플릿이 무지 배경 스튜디오 컷이면 같은 스타일로, 제품은 텍스트 아래(C6-2).

- **S07-V 변형** — SP마다 **각도를 다르게** 배정한다(예: 01 결과 / 02 장면 / 03 감각 / 04 정체성). 구조도 섞는다: ① KEY+이미지(기본) ② 숫자 크게+한 줄 ③ 전·후 두 컷 ④ 질문 KEY+답 한 줄 ⑤ 한 단어 KEY+GIF. 네 SP가 같은 문형이면 다시 쓴다.

## S08. 비교·선택 가이드
- **S08-1 한 화면 [최소선]** — 비교표는 한 스크린에 전부. 열 ≤3(우리 + 대체 유형 2), 행 3~4, 열 머리 = 썸네일 + 통용 유형명(같은 어미, 2~4자). 표 아래 글 없음(범례·결론·조건 전부 제외, 조건은 09).
- **S08-2 셀 [최소선]** — ○△✕만. 이분 사실(있다/없다)에만, 연속량(세기·속도·범위)은 넣지 않는다. △는 "조건이 붙어 된다"일 때만. ○만 포인트색, △·✕는 회색(붉은 ✕ 금지). 점검: "이 판정이 어떤 제품을 가져와도 같은가."
- **S08-3 기준 행 [권장]** — 명사형 2~6자, ○ = 좋다로 극성 통일, 다수 집단 불편 빈도순, 비교 축 하나. 우리 열이 전부 ○여도 되지만 사실과 다른 ○·무의미 행은 금지. 같은 과업·단위·조건. 종합 우열 행·타사 흐림·익명 비하 금지. 같은 상품 판매처 간 비교는 가격·구성·배송·지원으로만.
- **S08-4 어휘 예외** — 표 안에서는 비교 대상의 유형명·부품명을 쓸 수 있다(C2-3은 KEY에만). 유형명('부착형')과 동작어('부착')는 층위가 다르니 섞지 않는다.
- **S08-5 표준 템플릿 2열 카드** — 같은 기준(설치 / 거치 / 이동)으로 2열 3항목에 압축. 배지는 제품 코드·유형명으로("최신형" 같은 평가어 금지).

- **S08-V 변형** — ① ○△✕ 표(기본) ② 2열 카드(전·후) ③ 하루 동선 비교(탈 때 / 달릴 때 / 내릴 때) ④ 체크리스트(`이 중 하나라도 불편했다면`) ⑤ 한 줄 판정(`끼우는 거치대 vs 대는 거치대`). 헤더는 권유·질문·선언 중에서.

## S09. 제품정보
- **S09-1 [최소선]** — 현행 출고 옵션의 치수·구성·설치·관리. 포함품과 별매 구분, 판매명·소싱명·모델명 구분. 조건·한계(설치면·호환·계절 관리)는 여기서 보존한다(07·08에서 뺀 조건이 모이는 곳).
- **S09-2 [권장]** — 스크린별 명사 KEY + 정보 행(명사형 개조식, 어미 통일). 설치 단계는 `닦고 누르고 끝까지 돌리기`처럼 쉼표 없이. 설명 줄은 C3-3. 치수 도해는 여기(크기 가늠).
- **S09-3 이미지** — 스크린당 1장: 여러 자리·경우는 도해 1장에 마커, 구성품은 플랫레이 1장, 정위치는 정답 1장(C5-2).

## S10. 상품정보고시
- **S10-1 [최소선]** — 실제 표기·판매 자료와 대조. 미확정 값은 추정하지 않고 (보류). 광고 문구·가칭·타사 인증으로 채우지 않는다. 고지 1줄(예: 충전 미지원)은 여기에.

## S11. Q&A·주의사항
- **S11-1 두 단 [최소선]** — '구매 전에'(사기 전에 묻는 것: 내 환경 → 내 기기 → 계절 → 해제·이동 → 없는 기능, 4~6개) 먼저, '사용 중에'(부정 리뷰 빈도순 3~6개) 뒤에. 전 문항 펼침(접이식 금지). 단별로 한 스크린 안에.
- **S11-2 출처 [최소선]** — 행동표 집단별 걱정 + 상품마스터 질문 + 보편성 테스트 통과. 증상 질문을 구매 전 단에 두지 않는다. 희귀 질문(1~2건) 제외. SP를 질문형으로 반복하지 않는다. (보류) 답변이 달릴 문항은 뺀다.
- **S11-3 형태 [권장]** — 질문은 소비자가 문의창에 쓰는 말로, 사용 중 질문은 증상 1인칭 허용. 답은 결론 → 조건 → 조치, 합쇼체 90자 안팎. 09와 겹치면 답을 짧게.
- **S11-4 주의사항 [최소선]** — 법령·안전 최소선만(설치 금지 위치 / 사용 전 거치·정차 후 변경 + 법령 문구 1회 / 고온·진동 재점검 / 용도 제한 / 손상·자국 기준 / 분해 금지). 책임 배제 문장 금지. Q&A와 중복 항목 제외. **법령 문구는 전 영역에서 여기 한 번뿐**(C4-3).

- **S11-V 변형** — 질문 말투를 고객의 실제 걱정 그대로 세게 쓴다(`진짜 안 떨어져요?`, `제 차 가죽인데요`). 답의 첫 문장은 걱정을 정면으로 받는 결론. 구성은 ① 두 단(기본) ② 걱정 Top 3 크게 + 나머지 작게 ③ 대화형.

## S12. 브랜드 소개 (고정)
- **S12-1 [최소선]** — 승인 공용 원고·로고·실제 지원 약속만. 01과 기능 나열을 반복하지 않는다. 표준 템플릿의 영문 슬로건은 그대로. 사진을 쓰면 접은 제품 1장 70%, 없으면 띠 높이를 줄인다(빈 스크린 금지).

## S13. 내부 제작 (소비자 본문 아님)
- **S13-1 [최소선]** — 기준 이미지, 촬영·연출·시험 구분, 오해 방지 목록, 모바일 검수 기록. 실험 GIF 요청은 8항목 양식(검증 질문·표본·환경·절차·촬영·관찰·편집·게시 조건). 결과 전 '검증 완료' 카피 금지, AI 영상으로 시험 증거 대체 금지.
