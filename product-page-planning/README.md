## 만든 방법
- 원자료: 대시보드 공유 워크스페이스 API에서 N001의 소싱, 자료수집, 상품마스터, 기획안 v2를 추출
- 유튜브: `yt-dlp`로 검색·조회수를 수집하고, Higgsfield MCP `video_analysis`로 장면별 음성·화면을 분석
  (클라우드 IP의 자막 다운로드가 봇 차단되어 대체)
- 웹 리서치: 서브에이전트 4개를 병렬로 돌려 방법론, 카피·광고, 시장·규제, 영상을 조사하고 항목별 출처를 표기
